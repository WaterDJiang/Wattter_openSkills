# 内容策略：SEO 内容生成

## 1. 适用场景

当用户目标是被传统搜索引擎发现、理解和排名时，使用本模板。不要自动叠加 9day、命理、GEO 或其他垂类规则。

## 2. 核心原则

- **搜索意图优先**：先判断用户是在找定义、比较、方法、清单、案例，还是购买/决策。
- **主题覆盖而非关键词堆叠**：围绕主问题展开相关子问题，让页面完整回答一个搜索任务。
- **E-E-A-T**：体现经验、专业、权威和可信度；不要用空泛形容词冒充可信来源。
- **可读性**：短段落、清晰 H2/H3、结论前置、必要时用表格和步骤。
- **真实叙事**：用具体场景解释抽象概念，避免“随着时代发展”式开头。

## 3. 非营销硬规则（默认强制）

走 SEO 主路径必须应用 `references/non-marketing-guardrails.md`。它优先级高于任何 profile，profile 不得解除其中的红线。

- **默认 `editorial` 模式**：文章当编辑性资料写，不是落地页。无品牌 CTA、无说服链路。
- **`promotional` 模式需用户显式要求**（“转化”“加 CTA”“引导到品牌”）才开启，且仍受红线约束。
- **红线词命中即改写**：广告法绝对化、虚假功效、稀缺紧迫、引流违规、标题党、对比贬低六类，详见护栏文件。
- **强制事实锚点**：每篇至少 1 个具名来源 + 1 个具体数字 + 1 个反例/边界。拿不到标 `[需补充]`，禁止编造。
- **结尾不卖东西**：收束到读者可自行执行的下一步或延伸问题，不放品牌 CTA（promotional 模式除外）。

交付前必过护栏《反软文自检清单》。

## 4. 写作流程

1. 明确目标读者、发布平台、业务目标。
2. 识别主关键词、3-8 个次级关键词、3-6 个真实搜索问题。
3. 判断搜索意图：informational / commercial / navigational / transactional。
4. 选择文章角度：问题解答、避坑、比较、教程、清单、案例复盘。
5. 生成结构：H1、导语、速览、主体 H2/H3、FAQ、结尾收束（非 CTA，见非营销硬规则）。
6. 自检关键词是否自然出现于标题、首段、至少一个 H2、description 和 FAQ。

## 5. 推荐结构

```markdown
# [包含主关键词的问题式标题]

[具体场景开场，第一段直接回答核心问题。]

## 先说结论

- [一句话结论 1]
- [一句话结论 2]
- [一句话结论 3]

## [H2：用户最关心的问题]

[先回答，再解释。]

## [H2：怎么做 / 怎么判断]

1. [动作]
2. [动作]
3. [动作]

## [H2：常见误区 / 对比]

| 项目 | 正确理解 | 常见误区 |
|---|---|---|

## 常见问题

### [真实搜索问题]
[50-120 字直接回答。]

## 最后

[收束：给读者可自行执行的下一步或延伸问题。不放品牌 CTA，除非显式走 promotional 模式。]
```

## 6. SEO 自检

- [ ] 标题是否包含主关键词，并且像真人会搜索的问题？
- [ ] 首段是否直接回答问题？
- [ ] 是否覆盖主搜索意图，而不是只解释概念？
- [ ] 是否自然使用主关键词和次级关键词？
- [ ] 是否包含 FAQ 或步骤，增强长尾覆盖？
- [ ] 是否有真实经验、案例、数据、来源或边界说明？

反软文自检（默认强制，详见 `references/non-marketing-guardrails.md`）：

- [ ] 删掉所有品牌名后，这篇文章还成不成立？
- [ ] 通篇有没有在“卖”东西、把读者推向购买/注册/加群？
- [ ] 标题是否同时堆了痛点词 + 方案词 + 情绪词？
- [ ] 六类红线词是否清零？
- [ ] 是否满足 ≥1 具名来源 + ≥1 具体数字 + ≥1 反例/边界？
