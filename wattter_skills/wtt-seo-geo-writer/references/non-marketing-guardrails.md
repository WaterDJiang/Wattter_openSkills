# 非营销护栏

本文件是 SEO/GEO 两条主路径的**默认强制护栏**。只要走主路径输出，就必须读取并应用本文件，优先级高于任何 profile。Profile 可以补充品牌、语气、关键词，但**不得解除本文件的红线**。

目的按优先级：
1. 平台能发布（不被审核、限流、隐形降权）。
2. 读者愿意读、愿意互动（不像软文）。
3. 搜索/AI 侧 E-E-A-T 与可引用性（不被判低质过度优化）。

## 1. 模式开关：editorial / promotional

| 模式 | 触发 | 行为 |
|---|---|---|
| `editorial` | **默认**，无需声明 | 无品牌 CTA、无说服链路、强制事实锚点。把文章当编辑性资料写，不是落地页 |
| `promotional` | 用户**显式**要求转化型/带 CTA/品牌引导时 | 允许品牌露出 + 软 CTA，但红线词仍全禁，事实锚点仍必须有 |

拿不准时默认 `editorial`。只有用户说出“转化”“加 CTA”“引导到产品/品牌”“落地页”等明确意图，才切 `promotional`，并在 Frontmatter 写明 `content_purpose: promotional`。

**结尾软化**：`editorial` 模式下结尾改成提问或开放句（如“你的场景里 X 是怎么处理的？”），把任何引导动作移出正文（放作者主页 / 平台组件 / 文末“关于作者”区），不在正文落 CTA。

## 2. 红线词表（命中即改写，默认不可绕过）

无论哪种模式，以下词汇命中即改写或删除，不得保留。无法替换的句子整句重写。

### 2.1 广告法绝对化用语

最、最佳、最优、最好、最大、第一、唯一、首个、顶级、极致、领先、领军、王牌、权威、国家级、世界级、销量冠军、冠军、100%、绝无仅有、万能、永久、绝对、堪称、无与伦比、空前、史无前例、顶尖、一流。

软文式夸大形容词同样归入此类：神器、必备、爆款、宝藏、绝绝子、网红同款、断货王、天花板、封神。

改写方向：用**可核验的具体事实**替代。例：`销量第一` → `2025 年某监测口径下月销 X 万份`（且必须有来源）；`最强大` → 直接删，或换成可证伪的功能描述；`必备神器` → 删，或换成“在 X 场景下能解决 Y”的具体描述。

### 2.2 虚假与功效承诺

保证、包（包过/包就业）、一定、必然、确保、承诺、根治、治愈、X 天见效、立马、瞬间、彻底、永不、稳赚、必赚、零风险、无风险。

改写方向：给出**条件、边界和概率**，不写绝对结果。

### 2.3 稀缺紧迫诱导（小红书、百家号高危）

限时、仅剩、最后 N 个、马上涨价、错过再等一年、倒计时、抢购、手慢无、仅此一次、今日特惠、随时涨价。

改写方向：删掉紧迫修饰，让信息本身成立。如果是真实限时活动，只在 `promotional` 模式下客观陈述活动时间，不做情绪压迫。

### 2.4 引流与卖货促动（小红书最严，掘金/CSDN 也限）

引流指令：私信我、私我、加微信、加 V、扫码、免费领、点击链接、关注公众号领、留邮箱发你、评论区扣 1/扣 666、V:xxxx、WX:xxxx、+Q、加群领。

卖货促动词：赶紧入手、下单、闭眼入、无脑入、闭眼冲、冲、囤、抢、上车、入手不亏、不买后悔。

改写方向：正文内**不得出现任何站外引流指令或促单动作**。需要引导时，只用平台官方允许的方式（如作者主页、平台内组件），并用中性表述；把购买决策留给读者，不替读者下促单结论。

### 2.5 标题党 / 震惊体（百家号、小红书审核重点）

震惊、惊呆、吓死、99% 的人不知道、看完惊了、必看、千万别、再不看就晚了、突发、曝光、内幕、真相了。

改写方向：标题改成**具体、中性、问题式**，让标题独立陈述文章要回答的问题。

### 2.6 对比贬低

秒杀、完爆、吊打、碾压、远超、比 XX 强十倍、吊打同行。

改写方向：如需比较，用**同口径客观对比**（表格 + 数据 + 来源），不做情绪化贬低。

## 3. 价值优先表达法（替代写法）

红线词只解决“不写什么”。这一节给“怎么写才不像广告”。核心：**先给价值，再谈其他**。

- **开头给洞察，不给卖货钩子**：第一段用数据、反常识或一个具体场景切入，不要用“强烈推荐”“不得不提”式开场。
- **用“我实践 / 数据显示”替代“强烈推荐”**：把推荐变成可核验的经验陈述。`强烈推荐 X` → `我用 X 做了 Y，结果是 Z`。
- **把卖点转成使用场景 / 对比 / 方法**：不罗列产品优点，而是写“在什么场景下、和什么比、怎么用”。卖点藏在场景里，不裸露。
- **格式与 emoji 克制**：emoji 仅在平台原生语境（如小红书）少量使用，不堆 🔥⚠️💯🎯 等营销 emoji；不过度加粗、不滥用分割线、不把标题做成 emoji 拼盘。格式服务于信息，不制造视觉叫卖。
- **自卖自夸一律降级**：关于自家产品 / 品牌的高调评价，必须有第三方来源或可核验数据支撑，否则删掉或改成中性功能描述。

## 4. GEO 链接自然化（最强去广告信号）

正文里堆链接、放联系方式，是被平台和 AI 双重判为广告的最强信号之一。GEO 内容尤其敏感——AI 引擎对商业自利信号会降权采信。

- **正文最多 1 条主链接**：用自然语句引入（如“详见官方文档”），不要裸链、不要链接农场式堆砌。
- **llms.txt / sitemap / Schema 只进 geo 字段**：这些机器可读索引放进 Frontmatter 的 `geo` 字段或站点配置，**不铺进正文**。正文里铺 sitemap / llms.txt 字样本身就可疑，除非文章主题就是讲解它们。
- **不放微信号 / 二维码 / 裸链 / 联系方式**：正文内一律禁止。需要联系入口时移出正文（作者主页、平台组件、文末“关于作者”区），且仅在 `promotional` 模式或平台明确允许时使用。
- **品牌提及自然化**：品牌名出现在比较、清单、行业解释中，不集中堆砌、不自我吹捧。一篇里品牌名密度过高 = 广告信号。

链接越少越自然，被引用概率反而越高。

## 5. 平台专规

四类主发布平台写最细。其他平台套用通用红线，不展开。

### 3.1 掘金 / CSDN（技术社区）

读者是开发者，软文/水文一眼识破，反噬大（举报、踩、封号）。

- **禁公众号/微信群引流**：掘金明令禁止正文引导关注公众号、加微信群、加私域；CSDN 对站外引流也限制。需要作者归属时只放在作者简介或平台内。
- **必须有技术深度**：代码、配置、实操步骤、踩坑记录至少有一项实质内容；纯概念科普易被判水文。
- **标题要具体技术问题**：如"Spring Boot 3 下 X 报错的排查"，禁夸张、禁"一文读懂""终极指南"。
- **反软文自检最严**：删掉任何产品/品牌名后，文章必须独立成立；若删掉就不成立，就是软文。

### 3.2 小红书

审核最敏感，违规高频触发隐形降权（笔记不进流量池）。

- **笔记体**：口语、第一人称、短句、分行；不是博客长文。
- **禁引流/绝对化/功效**：本文件红线全部适用且更严，尤其 2.3、2.4。
- **前两行决定展开率**：开头两行先给判断或钩子，不要铺垫。
- **话题标签而非关键词堆砌**：用 `#话题` 自然标注，不要在正文堆关键词。
- **隐形降权触发项**：频繁删改、引流词密度高、营销词集中、图片带二维码/微信号、搬运。

### 3.3 百家号

百度系审核严格，且对百度搜索 SEO 有意义。

- **标题党/震惊体直接限流**：2.5 全部适用，百家号尤其敏感。
- **广告法绝对化触发审核**：2.1 全部适用，触发后可能整篇打回。
- **原创判定要有信息增量**：拼凑、洗稿、无观点的整合会被判低质，影响分发。
- **正文质量优先于关键词**：不要为关键词牺牲可读性；百度对堆砌敏感。

## 6. 垂类补充红线（仅当加载命理 profile 时叠加）

> 本节是通用安全网。命理 profile 文件本身不修改；仅当用户已加载命理/八字 profile 时，在通用红线之上**追加**本节。

命理疗效承诺是平台违规和广告法最高危区：

- 改运、转运、化解、破解、消灾、保平安、必婚、必离、生子、招财、辟邪、化太岁（疗效式断言）、命中注定、躲过一劫。
- 任何"做了 X 就能改变命运/婚姻/财运"的因果承诺。

改写方向：命理内容只做**文化解释、自我反思、概率性趋势讨论**，不做疗效承诺。把"化太岁保平安"改成"传统民俗中认为 X，现代人可理解为 Y"。保留文化内核，去掉功效断言。

## 7. 强制事实锚点

所有主路径文章至少满足以下三项，用于把"观点稿"压成"资料稿"，同时提升 E-E-A-T 和可引用性：

- **≥1 个具名来源或引用**：官方文档、论文、公开数据、可核验的案例。不给出来源的高调断言一律降级。
- **≥1 个具体数字**：带口径和时间，如"2025 年某报告显示 X%"。不能是模糊的"大量""多数"。
- **≥1 个反例、边界或局限**：说明这个结论在什么情况下不成立。

拿不到真实数据时，标注 `[需补充数据]` 或 `[需补充来源]`，**禁止编造**。空着比编一个好——编造的事实是平台违规和 AI 采信的双重风险。

## 8. 反软文自检清单（交付前必过）

每篇文章交付前逐条问自己：

- [ ] **删品牌测试**：删掉所有品牌名、产品名后，这篇文章还成不成立？软文删掉品牌就垮。
- [ ] **卖东西测试**：通篇有没有在“卖”什么？有没有把读者推向某个购买/注册/加群动作？（`editorial` 模式应为否）
- [ ] **标题堆叠测试**：标题是否同时堆了“痛点词 + 方案词 + 情绪词”？三者同时出现基本是广告标题。
- [ ] **红线词测试**：第 2 节六类红线词是否清零（含神器/必备/爆款、卖货促动词）？
- [ ] **事实锚点测试**：强制事实锚点三项是否满足？
- [ ] **链接测试**：正文主链接是否 ≤1？有无微信号/二维码/裸链/联系方式堆砌？（见第 4 节）
- [ ] **emoji / 格式测试**：有没有堆营销 emoji、过度加粗、emoji 标题拼盘？
- [ ] **结构落地页测试**：是否是“痛点→放大→方案→CTA”的销售漏斗？编辑性内容应是“问题→事实→分析→边界”。

任一项不通过，回到改写，不要带着营销味交付。
