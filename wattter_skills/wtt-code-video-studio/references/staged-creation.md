# 按阶段和镜头交付

先从用户原话确定两个范围：**交什么**（剧本、分镜、提示词、对白/字幕、镜头视频、组装成片），**交哪部分**（全片、章节、镜头 ID 或用户指出的那一段）。没有限定时走原来的一条龙。用户给了已有稿就从该稿接手；能从标题、台词或顺序唯一定位镜头，就直接标出对应 ID。只有指向有歧义且会改错镜头时才问。无需用户填写组装单或先选五个风格。只有主题也可直接要分镜或提示词：用一句创作假设补足目标、主体和动作，直接交所需稿件。说“只做 12–18 秒”时，按现有时间轴定位并说明两个截点；还没有实测时间轴时标为内容估时。

| 这次要什么 | 直接交付 | 下次如何接上 |
|---|---|---|
| 只要剧本/某一段 | 给可读的正文、动作、对白或旁白；修改段落只列所选段落。按内容估时 | 保留段落 ID 和版次；用现成剧本拆镜 |
| 只要分镜 | 每镜给稳定 ID、来源段落、观众要看懂什么、起止画面、动作、景别/机位及其理由、声音或静默、估时和接镜点。画风可留待定 | 用户可点名导演、替换、调序或单独制作某镜 |
| 只要提示词 | 针对选中镜头给可复制正文。说明用于代码实现、静帧生图或视频模型；只输出所需一类或用户要求的组合 | 保留镜头 ID、素材参考 ID、版次和接入位置；工具语法未知时写通用提示词。交付即停 |
| 只要对白、旁白或字幕 | 按镜头与说话人给逐句文本；有锁定音频才给基于实测的时间，草排字幕标估时 | 保留话轮 ID，制作时沿用对应角色与个人旁白配置 |
| 只制作指定镜头/章节 | 只实现目标范围并在该范围内出四帧；请求该段 MP4 时，确认该段拼图后才完整导出该段 | 回交场景配置、绘制代码或已交付媒体、素材依据、首末状态及实测时长 |
| 组装全片 | 使用指定镜序和已选版本，统一画幅、帧率、字幕安全区、角色声线和声场，重点检查每个切点 | 全片真实四帧含代表性跨风格切点；镜头样片的确认只覆盖原范围 |

文本阶段无需 init、素材下载、合成声音或开启渲染。一个镜头未定时，其他镜头可照常交付。交接只记已实际产出的文件/版本、涉及的段落或镜头 ID、用户已锁定的内容和仍待定的决定。只要一段文字可直接贴正文；要接续的长项目用现有 script.md、storyboard.md、style-choice.md，提示词可按镜保存为 prompts/<镜头ID>.md。保留原稿；新会话从交接文件续做。

## 分镜后选风格

- 先用能独立成立的分镜交代本片问题与结尾，再查风格。按内容匹配目录或用户已保存的个人风格。先读候选摘要，选定才读对应 STYLE 及其完整方法；把适用于多片的规律与这支片自己的剧情、构图、道具区分开。
- 方向记录沿用 style-choice.md。记全片默认，以及逐镜覆盖的 ID / 风格与版本 / 状态 / 用户依据。同一组镜头共用一条决定。用户指定镜头覆盖优先于全片默认；已有决定照用，委托代选标 delegated。待定的文字分镜可照交；进入制作时才解决待定方向。用户要推荐时，针对未定范围一次比较五个可行方向，可把完整的混搭方案作为一个选项。
- 两种风格表现同一持续动作时，优先共用世界状态和镜头，只让笔法演变；独立影像按动作、构图或声音接。实现与密采验证见[跨风格接镜](style-continuity.md)。
- 一个换风格的理由要在镜头中看得见。写清同一主体保持什么、哪一处画面或声音带出新信息、为什么在这里切、用哪一帧核对。全片可共用角色轮廓、动线、道具或声部，逐镜分别选材质、投影、运动和镜头语法。临时换色或混搭随本片保存；用户明确要跨片复用时才进入个人风格包。
- 提示词分层取用：风格写材质、功能色、原生动作和允许变化；本镜写首态→动作→末态、视点与观看目的、声音触发或静默；需要生成素材时另写参考 ID、主体锚点、画幅和透明/分层交付要求。字幕由谁排、首末帧需接住什么明确写出。拿到返回素材后再核实内容、登记版本和使用依据。

## 可直接接续的例子：《一声回响》

剧本段落 P1：在墙前轻拍一下。声音走出去，折回来。如果把同一位置听到的声音画下来，会看到间隔开的两次到达。

| 镜头 | 分镜和画风决定 | 衔接 |
|---|---|---|
| wall | 剪纸侧视。同屏保留声源和墙，暖色波纹触墙后掉头。固定机位，让观众看清反射发生在哪里 | 末态是波回到声源附近。切向同一位置的声音记录 |
| trace | 示波器线描。固定尺度，曲线从左向右依次显出两组波，再停住供比较 | 记录第一组为原声，第二组为回声；标示意，不给虚构的测量值 |

用户说“只给第二镜的视频提示词”时，可直接交下面一段并停下：

> **trace · 视频模型提示词**　横屏，固定镜头，深绿示波器网格。一根浅绿线从左向右扫过，先出现一个短而清楚的波包，回到中线；留出一段可见间隔，再出现较小的第二个波包。两组留在同一屏，末尾停稳，观众能比较两次到达。承接上一镜声波返回声源的位置。无内嵌文字，底部留出标签空间，后期分别排“原声”和“回声”。波形为示意。

## 代码镜头怎样组装

从 Skill 根目录可直接运行以下原创无声示例。两个输出目录须尚不存在。

```sh
python3 scripts/assemble.py assets/examples/echo-shots/sequence.json ./echo-trace --shots trace
python3 scripts/assemble.py assets/examples/echo-shots/sequence.json ./echo-film
```

执行者维护一张 sequence.json，film 使用现有 code-animation/v1 全片字段，order 是稳定镜头 ID 列表。每镜提供 shots/<id>.json（原生 scene，内含 id、实际 visual 配置、时长、所需话轮）和 shots/<id>.js（ES 模块导出 draw(ctx, state)，可另导出异步 prepare(scene, timeline) 加载已登记素材）。缺少的其他镜头实现不影响只取已完成镜头。按 order 默认组装，或用 --shots 明确镜序。入口复制所选代码到受审阅指纹覆盖的 code/，输出标准 film.json 与工程工具。运行时只执行本镜的画法，字幕、声音和全局帧共用原管线。

局部镜头动画优先按 localFrame、progress 及稳定身份绘制；音乐与跨镜事件用组装后的全局帧。截取或重排已有全片音轨、节拍、纪实素材时码或循环时，先在对应范围的组装单重定位，逐切点核实原声入出点。外部模型返回的视频按原有 footage 流程登记、预抽帧并由镜头代码播放；声音按需单独接入。组装器复制所选镜头代码和配置，所选镜头在 worldShots 登记时也复制共享世界模块；素材、字体、共享代码依赖和配音需按项目实际接入。

首次把独立镜头组装成全片时，对照各镜来源清单取对应版本；同一文件名对应不同内容时按 ID 区分并修正引用。镜头有锁的素材带入原哈希和使用依据，发生替换则先走变更审阅。已生成的镜头若带字幕或配音，合片前确定保留哪一层，避免叠字或双声。

组装后按原流程登记素材、锁时、预览、四帧确认和导出。每镜自带的代码和批准有各自范围。已有锁定工程要换镜头时在其带完整历史的工作副本里修改目标 code/<id>.js 和 film.json 对应场景，保留其他镜头与素材历史；涉及资产先做候选 diff。不可用创建新工程的方式跳过已有素材变更审阅。
