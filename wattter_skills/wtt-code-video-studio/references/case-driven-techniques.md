# 按案例证据选择制作路线

用户只给主题时先查用法，再决定画风和技术；用户已指定方向则在其约束内实现。外部作品的可查信息见[案例目录](production-cases.md)，题材/镜头构想见[用法映射](use-case-mapping.md)。代码与声音仍沿[制作契约](production.md)、[素材审阅](material-review.md)和[画法适配](visual-recipes.md)。

## 先看作品是什么，再看怎样制作

- **视频**：逐帧画面或镜头编排是交付对象，可用浏览器、Remotion或外部渲染器。
- **交互作品的演示**：镜头对焦、发动机拆解、模拟器和游戏的传播视频可能是录屏。交互HTML与MP4分别交付；不能因为画面是三维就认定其库或声称已跑通离线导出。
- **原视频补画**：口播/课程/播客先核对原音轨、可靠转录及时间码，再做概念补画或画中画；不能默认为用户重新配音、改变原话或压缩原时长。新加台词才使用本机已配置的默认音色。
- **混合生成素材**：有的MV/纪录片由代理调用图像、视频模型，再叠JS动画与字幕。代码负责编排不代表每个像素由代码绘制；仅在用户给定素材或授权相应生成服务、外部上传及费用的范围内选用。默认不新增远程API调用。

## 内容动作与技术的对应

| 需要观众看见什么 | 可核实案例的启发 | 本片候选与检查 |
|---|---|---|
| 同一物件从按钮连续变成多个UI状态 | UI变形公开规格采用seek(t)、解析弹簧与多子帧；最终具体绘图库仍未知 | HTML/SVG/Canvas任选能保持容器身份的路线；每次目标变化从解析轨迹或固定步长状态求值。文字另设入退场区间，鼠标按下/拖动/松开共用时码；运动模糊留到正式输出，小样先查轮廓与阅读 |
| 手绘角色、纸面色层与歌词共同推进 | P(doom)源码确实加载p5.js/p5.brush，渲染器使用Puppeteer和FFmpeg；不能将后续混合重制当原版 | 按本片笔触/色层需求评估p5.brush或已有手绘模板，不强制换库。固定版本/seed，重放任意帧；处理笔刷延迟合成与字幕层次。水洗填充与镜头放大先做真实GPU小样，记耗时；不能靠减少笔触偷偷改画风 |
| 像素角色做一个完整短动作 | 巫师案例公开规格指定原生Canvas2D和低逻辑分辨率 | 小离屏画布、最近邻整数倍放大；姿态按离散阶段采样，镜头可独立平滑。检查预备/执行/缓冲和循环位移/速度，不把一张像素贴图平移当角色动画 |
| 沙画轮廓在历史/记忆中连续重构 | 历史沙画作者称未用Blender/Three.js，但具体库未公开 | 离屏主体/遮罩/固定沙粒或按所选机制用shader；这是本库复现建议，不能写成原作者的技术事实。节点按史实或故事因果设计，不复制原作叙事 |
| 地形、队列、烟雾与绘画质感同场变化 | 历史战役源码是自写WebGL2/GLSL、程序精灵和地形，不是Three.js | 有现成空间需求时可用Three.js；自定义体积/后处理需要WebGL。库名服从遮挡、材质、景深和运动要求，绘画滤镜不能代替造型；历史重建/示意与真实档案分开 |
| 产品界面、文字、现有素材在一条时间线上演出 | Danny Stuart第一人称记录使用Remotion/React，另一条作品混入自己的素材包 | 已有React工程可用Remotion；采用其帧时钟与真实渲染器。网页透视不自动等于物理3D，透明材质/深度遮挡另验。低清预览、字幕与声画检查继续绑定当前资产版本 |
| 参数改变后，科学模型与测量一起变化 | 镜头实验与发动机演示有高关注记录，但具体库未核实 | 交互输出先建同一规则/单位/模型；视频由可重放参数轨迹驱动，而非导出时自动乱操作。滑杆值、镜片/流路和读数同源，外观模拟不能冒充光学/流体求解 |
| 公式对象变形、证明或结构推导 | 导数案例公开任务点名Manim；不说明所有科普用它 | 可选SVG/Canvas，复杂数学对象可评估Manim。Manim为独立Python路线，使用自身真实输出和媒体检查；目前未内置适配器，不能复用浏览器报告充数 |
| 黏土、体积光、离线物理场景 | Blender案例存在公开演示，未核对具体脚本和渲染器 | Blender Python为外部代码渲染候选，明确脱离纯前端路线；用户只要前端时不切换。当前未接入自动后端，不安装或许诺一键运行 |
| 一次请求穿过实际仓库 | SQLite讲解的作者陈述包含模块地图、查询生命期和执行轨迹，具体画面库未知 | 先锁源码版本和可公开路径，按真实模块关系画图；已有运行日志才称执行实测。静态推演标明示意，不编造函数名/调用结果或把源码说明逐行变字幕 |
| 配方/工序在同一个容器里完成 | 调饮案例公开任务为HTML/JS的连续配方演示，具体库未知 | Canvas/SVG可表达用量、层次、工具和步骤；数值、液面和字幕同源。工程检查核对比例与总量，不宣称示意动画是真实流体计算 |

## 证据边界与采用记录

在现有 `style-options.md` 或 `storyboard.md` 引用案例ID，分写：**原片披露了什么 / 我们这片选什么 / 尚缺什么**。只借表现机制，正式题材、人物、音乐、镜头和资产仍按本片重做。没有合理对应不强塞热门案例。

- `source-inspected`表示本次看过指向的源码；不是运行过、验证过所有场景，也不推及其他版本。
- `author-article`是第一人称制作记录；`relayed-author`为原帖不可读时的公开转引；`index-only`只有索引描述。不同等级不能合成一个“源码确认”结论。
- 关注数是注明来源和日期的索引快照。没有数值的案例作技术/用法参考，不能补零、估算或标成全网热门；交互录屏、同曲不同版本和代码复刻分别标识。
- `reportedTechnology`是披露/可查事实，`unknownTechnology`保留未知，`suggestedEngines`仅为本库复现候选。索引的canvas/3D等标签不作为事实依据。
- 目录收录、依赖安装、适配成功、真实小样、成片审阅和用户采用分别记录。当前外部案例均为research-only；不得把它们加入本库rendered样片或自动下载其媒体。

选定新路线仍先做代表帧和风险动作测试，检验乱序重画、关键机制、阅读和帧时序，再扩片。外部渲染器/生成素材经过原素材锁和媒体验收，不新建一套绕开审阅的流程。

API核对：[p5画布与WebGL模式](https://p5js.org/reference/p5/createCanvas/)、[p5.brush](https://github.com/acamposuribe/p5.brush)、[Remotion帧驱动](https://www.remotion.dev/docs/the-fundamentals)、[Manim](https://docs.manim.community/en/stable/)、[Blender Python](https://docs.blender.org/api/current/info_quickstart.html)。这些说明可支持什么，不证明某条原片用了什么。
