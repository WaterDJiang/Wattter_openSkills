# 视频讲解与自动讲解网页

用于知识/机制讲解及带声音的自动讲解网页；编剧归[故事与时长](story-and-timing.md)，方向决定归[选择流程](style-selection.md)，生产/声音/素材归[制作契约](production.md)。不要为普通循环动画随意铺旁白，也不强迫所有故事做机械拆解。

## 画面承接讲述

每个主要信息对应可见证据：动作/状态/尺度/条件怎样改变，观众在哪看到。主体可为装置、场景、事件或关系；旁白分句不自动切镜。按本片策略选择定位/局部/回整体、体验/反事实等路线，产品讲解适合时才参考[镜头排布](video-layout.md)。

storyboard每个稳定ID记录：学习目的与旁白、景别/焦点/起止状态、语义动作触发、确切屏幕字/安全区、上一处怎样接到这里、阅读停留、声音和配音后实际帧。教学假设在相关镜头说明，不只藏片尾。四个审片时刻也从此选出。

标题、关键词、字幕各负一职，不三处重复整句话。字幕短句呈现并避让动作/标注，不能等待长打字动画才能读完整；因果、对照、数值变化读取同一模型，不靠装饰字补旁白遗漏的结论。核验尺寸、对比和字数读[视频质量](video-quality.md)。

## 同一模型，两种驱动

交互由用户参数驱动，视频由绝对帧号取模型状态/相机/文字。只要视频无需先做全交互页；需要视频+交互时复用模型和绘图层，入口分开。

- 每帧重建完整状态，固定seed，await真实素材/字体就绪；禁止累积deltaTime、自动ticker、未暂停CSS动画决定导出。
- 暂停/拖动/恢复重算同一时刻。自动讲解以音频播放位置选帧，切到手动探索先暂停讲解。
- 多部件从同一模型参数得出，不能单独减速一个部件破坏关系；慢放/回看标明含义。
- 转场保留所需位置/方向/比例参照，不能只因下一句旁白就重置模型。机械/路径内容才按专项接力规则检查。

## 配音校时与制作

实际测量音频后，镜头取动作/阅读最低时长和前导+旁白+尾停顿的较大值，编译整数帧；时间轴是执行时序源。语义触发可用已核对对齐/试听标记；字符比例字幕仅是近似。旁白变了重校受影响镜头/后续起点，硬时长不够回到内容取舍，不裁音/加速。

先按[保真](style-fidelity.md)自查画面/关键动作，再展示[四帧拼图](preview-review.md)，用户确认后才完整渲染。既定风格不重复五选，也不能跳过四帧门；当前有效defaultVoice自动沿用，不重复试音确认。有坏配置报错，继续独立的编剧/画面准备。

最终从MP4核对可读性、转场和声音时序。静态截图/等长不证明音画同步；不能试听就单列未试听。自动讲解网页另测播放/暂停/拖动/恢复，MP4不承诺点击交互。证据与结论只维护visual-review.json，不建另一份“通过”记录。
