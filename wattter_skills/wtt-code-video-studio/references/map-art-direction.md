# 地图的配色与视角

新明信片沿用本库兰州V2的**同片俯视→左斜俯视→右斜俯视→回到俯视**，增加孟菲斯微缩世界配方。相机、几何高度、面排序与功能色已接入[可运行模板](../assets/map-postcard/README.md)。用户明确指定视角/色卡时沿用，不新增开场模式选择。

真实地点先研究地理、地标和季节；通用“示例小镇”只验证绘制方法，不能换地名就称某城。用户截图仅能证明俯视/等距卡片与鲜明色块；兰州V2的连续相机是本库自写实现，不推断原作者的视频源码。

## 相机与兼容配置

```json
{
  "viewProfile": "multi-angle",
  "palette": "vivid",
  "paletteOverrides": {},
  "reveal": false
}
```

| viewProfile | 实际行为 |
|---|---|
| multi-angle（默认） | 同一几何世界在一支片内换角度，首尾相机闭合 |
| top-down | 同一空间场景固定正俯视，动态对象继续运动 |
| isometric | 同一空间场景固定35.264°仰俯角、−45°方位 |
| scroll-top-down | 保留旧1440高世界、向下匀速滚动；仅此路线使用0.55云视差和792高回绕 |

20秒默认轨迹：0–3.8秒俯视建立；3.8–6.8秒转向左侧；6.8–11.2秒左斜俯视停留并小幅移动；11.2–14.4秒转向右侧；14.4–16.8秒右侧停留；16.8–20秒回到俯视。空间坐标/高度与物件身份不变，不能旋转或斜切旧画布冒充新的建筑视角。

上例是API无参兼容行为；分发的config示例显式采用memphis、60fps、20秒、reveal:true。Memphis未指定reveal时也默认开合，前1秒中心颗粒长成画面、尾2秒收回散点；vivid/soft空间模板默认连续展示，旧scroll-top-down未指定时保留开合。参数以用户明确要求优先，不多问一轮。同地各角度单独出片须由用户提出；默认一支内连续变化。

fps与durationSeconds决定N，画面从i/N取相位；20秒60fps实际1200帧，30fps实际600帧。相机按同一归一化轨迹运动，因此提高帧率不会加倍动作。轨迹中的停留段仍有对象动作与微小相机移动，不是硬切静帧。

## 先按地图与内容定色

选色顺序：用户明确要求优先；再结合当地地貌、水色、典型建筑/材料、季节与本片氛围，决定色相关系和明度。地图底图的道路标注、行政填色和品牌UI不是当地实景颜色，不能直接照搬。没有可靠实景依据时标明原创艺术化示意，不编造采色来源。

允许同色系渐变、邻近色、对比色、中性色配一两个强调色；高饱和并非通用门槛。同色系靠明度、轮廓、空间和图案区分水/路/地/建筑。保留地方识别点，例如河水与周边地貌的关系、秋叶/常绿树差别、典型屋顶材料；不是把一张底图机械还原成照片。

模型在现有brief/地点研究中写一段配色依据：事实或艺术处理→主/辅/强调色→功能分配→可读性检查。随后写固定paletteOverrides；这是模型制作决策，不是运行时自动识图、随机选色或新配色问卷。配色理由和实图随四帧一起给用户看，改色后旧批准失效。

## 孟菲斯微缩世界

`palette:memphis` 落到清楚色块、轮廓、投影、图案、留白与动作；色卡可根据内容重新搭配。不能只修改一个标签。现有孟菲斯实现支持multi-angle/top-down/isometric三种空间路线；与旧scroll-top-down组合会报错，旧滚动仍支持vivid/soft。模板实现如下：

| 角色 | 示例色值与处理（可覆写） |
|---|---|
| 纸面 | 暖白#FDFDF9；画框居中、圆角、周围留白 |
| 描边/文字 | 深靛#25214A；主体轮廓清楚，避免全黑粗框 |
| 鲜色色组 | 黄#FFC93C、粉#FF8DB5、钴蓝#2E5BE6、珊瑚红#FF5A5F、薄荷绿#A9E6C6、天蓝#8DD3F6、淡紫#D3BEFF |
| 河/路/田地 | 默认钴蓝河、淡紫路、黄粉天蓝田地，依地方与季节证据覆写 |
| 硬投影 | 按建筑/树高度生成地面偏移多边形，深靛透明色，不用模糊滤镜 |
| 表面图案 | 农田/屋顶稳定裁切的圆点、斜条、折线；不得漂到色块外 |
| 颗粒边 | 同seed喷点侵蚀圆角画框与真实投影场地边缘；不用覆盖主体的大白圆冒充颗粒 |

七色/深靛只作参考，不要求暖冷交替或使用全部七色；同色系、低饱和也可，重点是层次与可辨识性。阴影和图案由实际ink派生，不锁深靛。建筑侧顶面仍保留体积色差，硬投影跟随同世界的地面投影，不能画在不一致的屏幕角度。复杂交叉时升级真实3D后端，不用面排序承诺任意遮挡正确。

至少两个与剧情有关的小动作，示例为6.7秒车辆在斑马线让行、12.8秒双鸟掠过；鱼游、船、风车和云另作持续动势。事件从绝对帧表导出sound-events.json，合成音效按同一frame/fps对齐。音乐五声音阶与合成风声是原创示范，不等于当地录音。

底部三行地点/意境/坐标与屏幕安全区保持。无真实地理映射时坐标固定或留空，不根据镜头旋转捏造经纬度；有来源的真实route才可动态显示。

## vivid / soft与地方色

默认vivid来自兰州V2的鲜明粉彩方向。纸白用于边框与留白，画面主体用清楚色块分工，轮廓纤细；用侧面/顶面色差表现建筑高度，不强制写实投影阴影。

| 用途 | 默认vivid |
|---|---|
| 纸白 | #FDFDF9 |
| 轮廓/主文字 | #4D6170 |
| 普通示意河流 | #65BDE4 |
| 墙面 | #F2ABC7、#B8AAE5、#91CEE5、#96D3B5 |
| 屋顶 | #F8D774、#D0C2F1、#B3DDE7 |
| 道路 / 标线 | #CDD1DF / #FFFDF0 |

| 季节 | 植被主色 | 树冠 | 农田/地块 |
|---|---|---|---|
| 春 | #9BD18B | #F6D45B、#65BF91、#F3ADC8 | #F8D45B、#92CE93、#8FCDE8 |
| 夏 | #77BE93 | #2E9E7E、#66BC8D、#A4D274 | #80C7A4、#B9DA75、#81CEE2 |
| 秋 | #A8C987 | #FFC94A、#F19B59、#63B790 | #F6CA58、#EDA36B、#A2C8D8 |
| 冬 | #C8DAD1 | #86AAA7、#A9C7D1、#D8B4BA | #DDE7E6、#B7D2DB、#E5D7C2 |

palette:soft保留柔和方向；vivid/soft/memphis是基础预设与绘法入口，不是可选颜色白名单。颜色在presentation.js的palette/seasonPalette统一解析，配置不支持的功能色或无效#RRGGBB会报错；数组覆写仍保留现有槽位：fields/trees/roofs各3色、walls4色，可填同色系相近色或重复色，不要求每槽不同。paper/ground/ink/river/grass/road/mark为单个色值；ground控制主体地面，paper控制外部留白。每次返回独立数组，不让一个项目的修改污染别的地点。

地方依据高于默认：例如兰州V2保留黄河赭金色#DDBA4E，不能所有河流统一涂蓝或秋树统一换樱粉。可在完成地点研究后设置：

```json
{"paletteOverrides":{"river":"#DDBA4E","grass":"#A8C987"}}
```

同色系示例（示意水乡，并非某真实地点的采色结论）：

```json
{"palette":"memphis","paletteOverrides":{"paper":"#F6F9F7","ground":"#E1ECE7","ink":"#244A43","river":"#527E76","grass":"#B8CDC3","fields":["#CADBD0","#A8C3B5","#90B5A4"],"trees":["#6B9683","#83AA96","#A2C3AD"],"walls":["#B4CCC1","#D0DFD7","#9FBDAE","#C1D6C9"],"roofs":["#5E8B7A","#769F8D","#8DB09D"],"road":"#D8E3DB","mark":"#F6F9F7"}}
```

保持同一几何、相机与颗粒/图案等工艺，不必换风格名才能改色。未指定功能色沿预设/季节补齐；不能只换河色就声称整幅采用了完整同色系。

这只覆写功能色，不会自动增加白塔/中山桥等地标。地标仍按该片来源核对、自绘几何，不搬运地图截图、参考成片或模型。声音按[地点声音](location-sound.md)匹配，不由鲜明色板强制套八音盒。

## 运行与验收

- 浏览器按顺序加载presentation.js、legacy-scroll.js、world.js、map.js；Node经map.js读取同一依赖。快照包含全部绘图文件、HTML、实际config及共用审片helper哈希，不能只复制入口脚本。
- 先地面底层，再按深度排序建筑面；长桥按跨拆分，保留道路—桥头—岸线连接。面排序不是通用深度缓冲，复杂交叉要换适当3D后端并验证。
- 标签在几何投影后按屏幕文字绘制，保持字号，不随地面压扁；每个关键角度看碰撞、屋顶遮挡、树冠挡标注。超长文案需要改写或排版，不无限缩小。
- 每帧来自整数帧号/固定seed，车辆/船/行人/风车/飞机/云相位独立且周期闭合；暂停、选帧和导出共用frame(i)。
- 检查俯视、两侧斜俯视及完整转角窗口；首尾相机、物件相位、未遮罩画面与最终编码视频都测循环，MAD<12/255，完整周期MAD=0。默认连续画面仍须通过这些阈值。
- 先生成带时码的四帧2×2拼图，展示并等用户明确确认；完整渲染前核对当前源码/配置/样帧与批准绑定，变化则新候选。技术通过、代理实际看帧/连续序列、独立创作、听感和用户采用分别报告。模板验证不代表任意城市的地标、构图或美术自动达标。
