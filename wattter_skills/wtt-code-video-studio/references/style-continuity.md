# 同一动作怎样换画法

先写切点两侧发生的**同一个动作**。分镜中记下一项可检查的参照，例如摆锤轴心、人物手腕与杯耳的接触点、地图投影后的河口、一个持续的音尾。记下动线、画面位置、运动相位、相机速度和声音去向。风格卡里的接镜锚点供选用；实际选择服从故事。

| 两镜关系 | 用法 | 在切点看什么 |
|---|---|---|
| 同主体、同空间，只变材质 | 一份世界状态算骨架、轨迹、相机；在其上逐步变笔触、光照、网点或描边。颜色、形状、光斑都沿同一物体坐标演变 | 轮廓与关节连续、身份可追踪、速度没有突然归零；材质变化结束后能认出目标画法 |
| 同动作、异视角或异空间 | 同一动作相位上匹配剪辑，预先对齐银幕运动方向、主体大小、视线和接触点。相机换边时先用交代镜头 | 前镜动作有去向，后镜接住其剩余部分，避免两次落地或手已松开又抓紧 |
| 图表转实景、外部模型视频、独立引擎 | 共享可传递的坐标或参考帧，用同形轮廓、穿过镜头的物体、遮挡边或特写转场。没有共同几何时用有理由的切镜；可先入下镜环境声或保留上镜音尾 | 关键对象在可比位置出现，曝光与音量受控，配音和字幕各只保留一层 |
| 剧情要求突变或对照 | 保留有意的硬切，用动作落点、静默或节拍交代变化 | 观众能理解时空或意义改变的原因 |

**不用给每个镜头加溶解。** 两次单独模拟后叠透明度会出现双影；同一张脸或同一枚齿轮最好只画一次几何。只改颜色也不一定有风格差别，至少落实各自有辨识度的一种画法。跨片段音轨与字幕仍依全片时间轴编排，转场时不重播音节。

## 可执行的同源过渡

参考[原创摆锤工程](../assets/examples/pendulum-styles/sequence.json)。在分镜工作稿同级放 shared/world.js，用纯函数 sampleWorld(frame, fps) 计算姿态、相机、锚点等世界状态。sequence.json 的 worldShots 列出共享它的镜头。镜头 ES 模块从组装后的 ./shared/world.js 重新导出**同一函数**；每个绝对帧只采样一次。draw(ctx, state) 的 state.world 是本帧结果。

接手的场景声明 `"transitionIn":{"from":"pencil","frames":19}`，并实现 drawTransition(ctx, state)。在后镜开头现有的 19 帧内，state.mix 从 0 平滑到 1，两端按前后画法画同一份动态几何；之后用后镜 draw。窗口不重叠扣时，不改变配音、字幕、总帧数。不同角色或复杂画法可在共享模块中保留同一骨架、相机与路径，再在后镜桥接笔刷、网点或着色器参数。转场函数由本片实现。

Canvas、SVG 或 Three.js 混用时，共享状态应包含世界坐标、相机投影和物体 ID；各自的绘制器只负责把状态翻译成线、面、纹理。三维到二维要对齐投影后的屏幕位置，有遮挡时同时传递深度关系。此处提供可运行的 Canvas 示例，其他引擎逐片接入。

全片默认以帧 0 起算。需单镜交付后精确接回时，在场景的 worldStartFrame 记下它在锁定世界时钟中的起帧。单取这一镜时沿该起帧直接呈现本镜画法；单看接点则同时取前后镜。完整组装时声明的起帧须与真实时长相符；若台词让前镜变长，重编时间轴并更新锚点。重排镜序若更换了前镜，先重新设计 transitionIn。老工程继续按原画法执行。

```sh
python3 scripts/assemble.py assets/examples/pendulum-styles/sequence.json ./pendulum-film
python3 scripts/asset_review.py seal ./pendulum-film
python3 scripts/pipeline.py timeline ./pendulum-film --lock
node scripts/render.cjs ./pendulum-film --preview --review-frames 41,48,57,66
```

**验接点**：同一时刻分别用前后笔法画，先核对投影后的锚点，再连续看前镜末段、过渡窗和后镜起段。回拖到同一帧应可复现；把窗口首末帧分别与该帧世界状态的纯前/后笔法比较，留意重影、笔触跳变、色阶和声音突变。四张静帧用于选版本，连续片段用于判断速度。无法共用状态的外部画面记录实际首末帧、接点和试听结果。
