# 笔式绘图仪

目录 ID：`pen-plotter`。状态：制作配方，按镜验证。

## 本镜怎么画

有限笔色、单线笔路与平行排线。按笔路长度落笔；空行程抬笔移动后再画。

素材与数据：可绘制的矢量路径与笔序。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

复用路径弧长，切换后笔尖仍在同一点。把空行程画进纸面会产生错误连线。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- motion-showreel：笔尖真实走线能让图形的构成次序可见。等高线签名——笔尖离纸越过空白，再接下一圈等高线。
