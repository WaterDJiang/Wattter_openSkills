# 安检 X 光

目录 ID：`security-xray`。状态：制作配方，按镜验证。

## 本镜怎么画

材料分层、厚度对应的透射色与移动扫描带。同一标本进入扫描区，外观渐转为层厚示意。

素材与数据：材料截面、厚度；标清模拟和色标。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

扫描线两侧共用物体轮廓和输送速度。伪彩不能解释为实物颜色或检测结论。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：透射示意能解释材料叠层。木盒里的陶片——扫描带通过木盒，陶片重叠区依厚度改变色值。
