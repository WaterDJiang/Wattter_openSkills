# 流水线图解

目录 ID：`assembly-line-diagram`。状态：制作配方，按镜验证。

## 本镜怎么画

单向工位、传送轨和有编号的载物盘。载物盘每过一站便留下该站操作的可见结果。

素材与数据：真实工序和中间态。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

锁住载物盘的前缘与带速，让新画法接着送。工站隐喻可能暗示错误的串行依赖。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：跟随同一件在制品理解工序。一封信如何分拣——同一信封依次出现邮编框、分拣标记和出口编号。
- codebase-tour：一次请求经过的模块可画成各站。一次保存去了哪里——跟随同一请求 ID 依次经过校验、写入和回执，失败分支留在真实模块。
