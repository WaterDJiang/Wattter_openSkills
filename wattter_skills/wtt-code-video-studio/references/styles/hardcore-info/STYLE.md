# 线稿剖面图解

目录 ID：`hardcore-info`。状态：制作配方，按镜验证。

## 本镜怎么画

主外轮廓、次级切线、剖面填线与引线层级。沿连续切面打开外壳，保留安装位置作参照。

素材与数据：可信结构图与零件名。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

以切面和轴心配准外观与内部图。猜测内部结构会让示意误导。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

- product-tutorial：剖面能指出外壳遮住的关键部件。保温瓶的夹层——瓶口不动，剖切向下揭出内外两壁。
