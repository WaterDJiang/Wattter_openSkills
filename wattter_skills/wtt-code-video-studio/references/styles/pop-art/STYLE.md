# 波普艺术

目录 ID：`pop-art`。状态：制作配方，按镜验证。

## 本镜怎么画

专色印版、黑边与固定在纸面的半调点。印版逐层合拢，在同构图中让一个差异跳出。

素材与数据：原创商品轮廓、功能色和印版掩模。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

共用产品边缘，让印版在原位对准。多版错位不能损害商标或文字可读性。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- brand-ad：网点套色和重复构图便于比较卖点。一只杯子的四种用途——四个同尺寸杯形依次套色，只有把手方向改变。
