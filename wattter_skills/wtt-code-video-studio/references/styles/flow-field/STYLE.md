# 流场风线

目录 ID：`flow-field`。状态：制作配方，按镜验证。

## 本镜怎么画

可追溯的向量场、连续流线与短迹。同组种子在场中积分，按帧查询轨迹，显出分流或汇聚。

素材与数据：向量数据、坐标系及时间单位；模拟单列。
可选技术：canvas2d / webgl。

## 怎样接镜和验收

传递同一流线参数和速度，不在切点重新播种。装饰流动不得冒充气象或水文测量。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- data-report：速度与方向能映射到轨迹。两个时刻的风向——同一观测网格并排显示两时刻向量，维持同尺度与种子位置以便比较。
- geographic-explainer：方向场能解释空间流动。弯道水流示意——几条标记线从同一截面出发，在弯道产生方向差。
