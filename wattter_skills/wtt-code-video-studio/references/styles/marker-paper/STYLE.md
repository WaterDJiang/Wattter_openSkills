# 马克笔白纸速写

目录 ID：`marker-paper`。状态：制作配方，按镜验证。

## 本镜怎么画

白纸、宽笔尖落墨与收笔形状。先落笔标定位点，按弧长显线，标注在结构完成后出现。

素材与数据：步骤草图与笔画次序。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

沿同一路径切换笔头宽度和墨水密度。笔画动画若遮住关键连接会妨碍阅读。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- product-tutorial：单线速写便于逐步指定操作位置。把书签折进页角——一道宽线划出折痕，折角沿它翻转。
