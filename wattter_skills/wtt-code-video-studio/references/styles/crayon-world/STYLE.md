# 蜡笔立体世界

目录 ID：`crayon-world`。状态：制作配方，按镜验证。

## 本镜怎么画

透视几何上叠附着于表面的蜡笔擦纹。相机从物体侧方经过，体块遮挡先后显形。

素材与数据：原创场景简模与统一相机。
可选技术：threejs / canvas2d。

## 怎样接镜和验收

共享投影顶点与机位，将描边逐渐换成蜡笔。屏幕噪声随帧漂移会破坏体积。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- children-story：可随人物穿行的涂画空间适合探索故事。小邮车进山——邮车绕过山脚，蜡笔着色的屋顶从山后露出。
