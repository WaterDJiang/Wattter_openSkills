# 胶片直刻

目录 ID：`scratch-film`。状态：制作配方，按镜验证。

## 本镜怎么画

暗乳剂、细刻线和局部染色。刻线密度随动作聚合，用固定种子保留有控制的线颤。

素材与数据：原创轮廓、节拍和刻痕蒙版。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

把上一镜的动作轨迹延续成刻线。随机全屏闪白会遮住动作且使观看不适。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- music-visual：刻痕和节拍能形成有形的重音。鼓刷划过纸面——同一笔扫过，划痕向外增密再收束。
