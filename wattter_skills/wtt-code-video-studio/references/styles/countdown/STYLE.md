# 实时倒计时分屏（Live Countdown Split-screen）

状态：方法配方已收录；本库尚未针对本条完成独立原创成片验证。此前6个样片只证明各自报告范围。

## 适用与核心语法

- 用途：documentary，根据本片内容决定，不按主题固定。
- 画面：同一事件多视角分屏，时钟是叙事中心。
- 原生动作：将每机时间偏移换算为同一事件秒，零点触发状态变化。
- 素材输入：用户提供或许可明确的原始影像/扫描/文件，登记日期、来源及剪辑解释依据。
- 实现路线：canvas2d / svg-html；先检查当前环境，新增依赖固定版本与许可，制作风险镜头验证后扩片。
- 必查：录播明确标识，禁止用异时影像伪装同步或实时直播。

## 特有验收与接入

共用制作与四帧审片门见[主入口](../../../SKILL.md)及[制作契约](../../production.md)；本页只补充风格机制与特有验收。
- 本条特有验收：录播明确标识，禁止用异时影像伪装同步或实时直播；确认将每机时间偏移换算为同一事件秒，零点触发状态变化已经在画面发生，不能只换色或添加风格名称。
