# 说明书插画

目录 ID：`instruction-manual`。状态：制作配方，按镜验证。

## 本镜怎么画

正交轴测、简练轮廓和单一活动件强调色。先给装配方向，移动到位后退回中性色。

素材与数据：零件、连接点与正确步骤。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

前镜的连接孔就是下一镜的定位原点。相机换侧会造成装配方向反转。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- product-tutorial：每步新增零件可以单独高亮。给台灯装底座——螺柱对准孔后进入，强调色在接触后移向下个部件。
