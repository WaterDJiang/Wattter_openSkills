# 霓虹灯管

目录 ID：`neon-tubes`。状态：制作配方，按镜验证。

## 本镜怎么画

玻璃壁、高光、气柱和局部光晕分层。沿管线依次点亮，熄灯时仍留玻璃外形。

素材与数据：可弯折的原创管线路径及点亮节奏。
可选技术：webgl / canvas2d。

## 怎样接镜和验收

复用中心线，让墨线逐渐显出管壁与光晕。过曝会吞掉字腔和拐角。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- brand-ad：灯管点亮路径能突出识别图形。夜间修鞋铺——鞋底轮廓的最后一段接上，沿同一路径亮起招牌。
- music-visual：电流点亮可跟随乐句。低音接过旋律——乐句交给低音时沿同一管弯传光，前一段管壁仍可辨认。
