# 萤火光点

目录 ID：`firefly-pointillism`。状态：制作配方，按镜验证。

## 本镜怎么画

暗底、稳定编号的点与局部亮度包络。点按距离次序点亮，中心留出负形再聚成轮廓。

素材与数据：主体轮廓、点采样与固定种子。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

保持各点身份和目标坐标，只改变发光半径。逐帧重新撒点会产生闪烁。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- allegory：光点聚散能把个体与群体的关系显形。一盏灯的回信——窗格上的光点一列列回应，汇成一扇亮窗。
