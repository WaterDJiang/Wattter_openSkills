# 剪影律动

目录 ID：`silhouette-rhythm`。状态：制作配方，按镜验证。

## 本镜怎么画

单色剪影、亮背景与清楚的肢体负形。先蓄势再把动作极值落在节拍，保持动作弧线。

素材与数据：动作关键姿态和节拍。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

保留关节姿势与重心，只让内部颜色消退。手臂和躯干重合会让动作难辨。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- music-visual：姿态极值能对应节拍。跳绳的空拍——绳圈经过脚底时角色正好腾空，轮廓间留出空隙。
