# 复古版画拼贴

目录 ID：`vintage-collage`。状态：制作配方，按镜验证。

## 本镜怎么画

有来历的印刷件、裁切白边与纸面投影。沿真实纸边推开一层旧图，露出有日期的下一件材料。

素材与数据：授权或公版原页及作者、日期和裁切依据。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

两张图按共同地标配准，借纸边作遮挡。不可用不同年代的拼贴假装同一现场。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- documentary：有出处的印刷材料可并置展示。一座车站的两张票——车站名对齐后翻开旧票边缘，让两张日期同时可读。
- cultural-story：拼贴适合串联异时材料。一座书坊的字样——把已核年代的三张书名页沿同一个字上下配准，比较版式如何改变。
