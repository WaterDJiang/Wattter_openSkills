## 适用与核心语法

- 用途：product / creative / story，根据本片内容决定，不按主题固定。
- 画面：平面着色几何与正交等距相机组成微缩世界。
- 原生动作：物体逐步生长，日照方向改变面片亮度。
- 素材输入：按本片重写主体/场景/数据；有真实参数时登记依据，教学示意明确标识。
- 实现路线：threejs；先检查当前环境，新增依赖固定版本与许可，制作风险镜头验证后扩片。
- 必查：不要混入写实纹理，阴影随同一光源变化。
