# 立体地图解说

目录 ID：`map-explainer`。状态：制作配方，按镜验证。

## 本镜怎么画

配准的高程网格、底图、路线带和随尺度分级的地名。总览中锁定转弯点，沿路线推近，用局部地形解释原因。

素材与数据：许可清楚的高程与路线、坐标投影和简化依据。
可选技术：threejs / canvas2d。

## 怎样接镜和验收

同一地理锚点投影到各镜；线宽按屏幕尺度过渡。示意路径与实测数据须分开，竖向夸张需标明。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- geographic-explainer：真实地形能解释路线为什么转向。山谷里的铁路为什么绕弯——从全线跟到弯道，剖面与同一点的高程同步出现。
