# 文字闪切

目录 ID：`text-flash-cuts`。状态：制作配方，按镜验证。

## 本镜怎么画

大字形、主体剪影与象征性空间。字卡落点对齐有含义的动作，关键词保留足够读时。

素材与数据：排版文案、可分层原创图或生图、返回图一致性。
可选技术：canvas2d / svg-html。
参考制作路线用到图像生成；本片可使用已有授权分层素材，核对角色和道具锚点。

## 怎样接镜和验收

用字孔或主体负形接镜，保留焦点。高频闪烁和过短读时会掩盖关键信息。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- product-launch：关键词与视觉反应能组织发布节奏。让房间安静一点——巨大的静字留出门形负空间，人物沿原动线走入。
- music-visual：字卡可承接乐句的停顿。休止符里的楼梯——重拍时楼梯变为竖排字，乐句停顿处只保留最后一级轮廓。
