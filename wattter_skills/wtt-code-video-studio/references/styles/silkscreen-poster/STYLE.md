# 丝印旅行海报（Silkscreen Travel Poster）

状态：方法配方已收录；本库尚未针对本条完成独立原创成片验证。此前6个样片只证明各自报告范围。

## 适用与核心语法

- 用途：story / creative / documentary，根据本片内容决定，不按主题固定。
- 画面：不透明专色平涂，阶梯色带和轻微漏白。
- 原生动作：刮墨前沿逐层显露海报，各色覆盖顺序固定。
- 素材输入：按本片重写主体/场景/数据；有真实参数时登记依据，教学示意明确标识。
- 实现路线：canvas2d / svg-html；先检查当前环境，新增依赖固定版本与许可，制作风险镜头验证后扩片。
- 必查：与透明孔版区分，不把渐变作为主要色面。

## 接到代码视频管线

- 先写本片内容主线和关键动作，再从本配方提取画法；不套用上游DEMO的故事、角色、品牌、字幕文案或镜头时码。
- 以本库film/timeline整数帧编排动作和音效，按绝对帧重建完整状态；异步资产必须await。不直接运行上游渲染命令或复制其工程时钟。
- 按用户本次要求或已配置defaultVoice生成声音；上游提及的云TTS、双语字幕、固定片长/镜头数不覆盖本库默认。风格需要无对白时纳入五方向方案展示，不能静默删除用户已要求的旁白。
- 初次素材按来源/许可登记；已锁素材变化先候选diff审阅。影像接入用footage工具；不得用假素材冒充证据或以重新下载绕过锁。
- 按主入口与用户进行一次完整方向选择；已指定/授权代选直接沿用。渲染前代表帧与动作检查，最终MP4后生成review证据，检查可读性、主体动作、焦点、转场及编码结果。
- 本条特有验收：与透明孔版区分，不把渐变作为主要色面；确认刮墨前沿逐层显露海报，各色覆盖顺序固定已经在画面发生，不能只换色或添加风格名称。
