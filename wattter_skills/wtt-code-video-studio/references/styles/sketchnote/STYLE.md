# 视觉笔记

目录 ID：`sketchnote`。状态：制作配方，按镜验证。

## 本镜怎么画

点格纸、图标、标题与连接笔画。依讲述次序落图，再用连线明确因果。

素材与数据：要点和明确的关系顺序。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

沿画布中既有图标的锚点展开下一镜。箭头若无语义会混淆因果与并列。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- personal-promo：一页图可串起作品与方法。我的三次改稿——把同一个项目的草图、反馈与完成稿画在一页，最后沿箭头回到作者的方法。
- concept-explainer：关系图能跟随讲述形成。一次展览怎样开门——布展、灯光和开门时间由三条不同含义的线连接。
