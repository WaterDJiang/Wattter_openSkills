# 小人模拟实验

目录 ID：`pip-simulation`。状态：制作配方，按镜验证。

## 本镜怎么画

用可区分的小个体和环境格显示模拟状态。从固定种子重建个体轨迹，同时画出由同一状态计算的统计。

素材与数据：明确更新规则、初态和步长。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

按稳定个体 ID 对齐前后两种画法。随意编造个体运动会使图表失真。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- interactive-lab：微观规则能展示群体结果。两个出口的队列——旅客依据相同规则选队，总人数与计数始终相符。
