# 双重曝光

目录 ID：`double-exposure`。状态：制作配方，按镜验证。

## 本镜怎么画

外轮廓遮罩与可辨认的内景曝光。轮廓保持稳定，内景缓移，沿真实地平线进入下一镜。

素材与数据：已授权肖像与地点素材或原创绘制。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

锁住眼位或地平线，让内部景物接管全幅。双层亮度会吞掉主体轮廓。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- personal-promo：人物轮廓可以承载其工作地点。修琴师的一天——修琴师侧影内出现工作台，在同一指尖位置转进调音特写。
- romance-film：同一轮廓内的地点变化表达回忆。最后一班轮渡——轮渡剪影中的岸线缓缓放大，变为下一镜的岸边。
