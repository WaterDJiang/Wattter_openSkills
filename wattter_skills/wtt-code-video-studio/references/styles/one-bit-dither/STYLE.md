# 1-bit 点阵

目录 ID：`one-bit-dither`。状态：制作配方，按镜验证。

## 本镜怎么画

两种墨色、固定像素格与表面抖动网纹。转动物体时网纹跟随表面，密度提示明暗。

素材与数据：形体蒙版、表面坐标与二值阈值。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

共享轮廓，按阈值逐级换墨，最终只保留两色。亚像素缩放会让纹理爬动。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- motion-showreel：明暗化成可读的二值纹理。铅笔盒旋转台——盒盖转向光源，网点随盒盖改变疏密。
