# 分色机械图解

目录 ID：`precise-mechanism`。状态：制作配方，按镜验证。

## 本镜怎么画

结构分色、可见转轴和简化机械阴影。以一个输入角解算各部件，让色组指明力的传递。

素材与数据：核对的传动关系、轴心与部件编号。
可选技术：threejs / svg-html。

## 怎样接镜和验收

保留轴心、角度和转速，只换线宽与材质。独立播放的齿轮动画容易脱齿。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：轴与关节约束能展示联动。手摇卷线器——转动手柄，卷轴从同一输入角得到转动。
- product-tutorial：分系统着色可追踪传动。给抽屉装缓冲器——推轨沿固定轴线闭合，控制组颜色标出阻尼器首次接触的位置。
