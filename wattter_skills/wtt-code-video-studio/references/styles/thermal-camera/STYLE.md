# 热成像

目录 ID：`thermal-camera`。状态：制作配方，按镜验证。

## 本镜怎么画

低分辨率温度场、固定伪彩与测点标尺。热源移开后按同一数据场更新温度和色值。

素材与数据：实测温度或标明示意的模型、标定范围。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

测点始终落在原位置，温度范围保持一致。自动重标色阶会制造虚假温差。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：同一色阶能比较传热。一杯热茶留下的杯印——移开茶杯，桌面温区按同一标尺逐渐缩小。
- data-report：带单位的标尺能支持读数。两块试样的降温曲线——锁住色标和测点，在相同时间比较两个有来源的温度读数。
