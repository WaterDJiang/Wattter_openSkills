# 表格动画

目录 ID：`spreadsheet`。状态：制作配方，按镜验证。

## 本镜怎么画

行列坐标、单元值和条件色。改变输入后逐格更新真实公式结果，再框出变化区。

素材与数据：原始表、公式和单位。
可选技术：svg-html / canvas2d。

## 怎样接镜和验收

保留活动单元格坐标，由数字轮廓过渡到色块。涂格图案不能冒充计算结果。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- data-report：逐格有值可追溯结论。雨天的借伞台——每日借还数更新后，库存列随公式计算改变。
