# 搞笑历史卡通

目录 ID：`comic-history`。状态：制作配方，按镜验证。

## 本镜怎么画

刻印地图、可揭开的纸层与表情反应格。让纸页的折叠和盖章标出时间变化，人物留在同一位置。

素材与数据：核实年代与地点，准备一致的原创人物与纸层，可用生图。
可选技术：canvas2d / svg-html。
参考制作路线用到图像生成；本片可使用已有授权分层素材，核对角色和道具锚点。

## 怎样接镜和验收

人物站位及地标不动，以翻页边作遮挡。喜剧反应不能替代史实依据。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- cultural-story：纸张动作能表现制度的前后变化。一座桥的三个名字——档案员翻过三层名牌，固定桥墩贯穿三个年代。
