# 包豪斯几何

目录 ID：`bauhaus-shapes`。状态：制作配方，按镜验证。

## 本镜怎么画

有限原色与圆、方、弧的比例关系。用等面积分割与组合解释数量，保持计量尺度。

素材与数据：同单位的量和基数。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

以同面积外轮廓及重心为锚，连续改动色面。用直径代替面积会夸大数量差。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：几何拆合能展示守恒关系。一块操场怎么分——矩形场地沿网格分开，三种用途重新拼回同一边界。
- data-report：面积编码能直接比较份额。一天里的三段用水高峰——把经核对的各时段用水量变成同尺度面积，最后复合成全天总量。
