# 黑白漫画分格

目录 ID：`manga-panels`。状态：制作配方，按镜验证。

## 本镜怎么画

墨线、网点、格框与留白。从全页到局部，以格框开合切分动作节奏。

素材与数据：同一角色与道具的参考图，可用生图生成分层素材。
可选技术：canvas2d / svg-html。
参考制作路线用到图像生成；本片可使用已有授权分层素材，核对角色和道具锚点。

## 怎样接镜和验收

相邻格共用视线和道具握点，格框作遮幅。换格后手型或道具朝向不一致会跳戏。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- product-launch：跨格特写适合呈现操作瞬间。旋钮的一格——手指在相邻两格保持同一握点，第三格用产品读数给出调节结果。
- comedy-short：格与格之间的停顿可以承接反应。慢半拍的合照——第一格按快门，第二格沿同一手指推近，末格才露出眨眼。
