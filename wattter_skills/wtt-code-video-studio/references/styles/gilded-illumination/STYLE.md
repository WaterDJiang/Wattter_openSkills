# 金箔彩绘

目录 ID：`gilded-illumination`。状态：制作配方，按镜验证。

## 本镜怎么画

哑光颜料、细密装饰和独立金箔遮罩。光源移过时仅金箔纹样反亮，其他色层保持平面。

素材与数据：纹样出处或原创线稿、金箔区域。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

固定纹样边缘与入射角，反光沿原方向离场。全屏泛光会抹去金箔与颜料的差别。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- allegory：高光可突出关键物件。夜航的罗盘——罗盘刻度逐一接到灯光，针尖持续指向同一方位。
- cultural-story：局部金箔能引导阅读纹样。一处修复过的花纹——相机固定在原件一角，按记录区分原金箔与后补区域。
