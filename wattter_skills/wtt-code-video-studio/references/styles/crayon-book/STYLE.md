# 蜡笔儿童绘本（Crayon Picture Book）

状态：方法配方已收录；本库尚未针对本条完成独立原创成片验证。此前6个样片只证明各自报告范围。

## 适用与核心语法

- 用途：story / knowledge / creative，根据本片内容决定，不按主题固定。
- 画面：纸齿承接蜡笔断续线，透明水洗显露留白。
- 原生动作：按笔画绘制形体，角色动作与绘画揭示分开。
- 素材输入：按本片重写主体/场景/数据；有真实参数时登记依据，教学示意明确标识。
- 实现路线：canvas2d / svg-html；先检查当前环境，新增依赖固定版本与许可，制作风险镜头验证后扩片。
- 必查：纸纹跟随纸面，轻微线沸不改变角色身份。
