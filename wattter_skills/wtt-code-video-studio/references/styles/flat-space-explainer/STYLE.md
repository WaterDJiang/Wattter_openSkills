# 扁平尺度漫游

目录 ID：`flat-space-explainer`。状态：制作配方，按镜验证。

## 本镜怎么画

平涂层级、比例尺与固定定位符。每次推近先圈定下一层对象，再以该点为中心变焦。

素材与数据：各层尺寸、单位与定位关系。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

共享缩放中心与相机速度，比例尺随层级过渡。不同单位若无说明会被误当连续实测。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：尺度变化能交代局部在整体的位置。从邮票到纸纤维——邮票角点留在原位，边缘逐步放大为纸纤维示意。
