# 彩铅科普插画

目录 ID：`colored-pencil`。状态：制作配方，按镜验证。

## 本镜怎么画

纸色作高光，排线跟随物体表面曲率。笔触先交代外形，再推入局部剖面补出层次。

素材与数据：可核对的对象结构和切面。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

沿剖切线保留轮廓，用纹理替换平涂。纹理过密会淹没解剖边界。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：叠笔和剖视适合逐层辨认结构。一粒稻谷的外衣——剖面切开后，排线改变方向区分外壳和内部。
