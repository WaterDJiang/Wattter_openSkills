# 雷达扫描纪录片

目录 ID：`dark-documentary`。状态：制作配方，按镜验证。

## 本镜怎么画

暗场、扫描前缘、按采样时间衰减的回迹。波束经过才显示有依据的目标，留出阅读回迹的时间。

素材与数据：观测出处、时标；重建要标示意。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

令上一镜指针成为扫描起始角。装饰波形易被当成实测数据。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- documentary：扫描出现的次序适合逐条揭示证据。旧天线的第一圈——扫过刻度时，让记录上的同一时刻进入画面。
