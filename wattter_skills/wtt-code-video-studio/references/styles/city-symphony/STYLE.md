# 延时交响（Time-lapse Symphony）

状态：方法配方已收录；本库尚未针对本条完成独立原创成片验证。此前6个样片只证明各自报告范围。

## 适用与核心语法

- 用途：documentary，根据本片内容决定，不按主题固定。
- 画面：城市真实延时素材组成节奏结构。
- 原生动作：先核对音乐网格，再安排加速、停顿和慢镜对比。
- 素材输入：用户提供或许可明确的原始影像/扫描/文件，登记日期、来源及剪辑解释依据。
- 实现路线：canvas2d / svg-html；先检查当前环境，新增依赖固定版本与许可，制作风险镜头验证后扩片。
- 必查：可压缩观测时间，但不要将音乐节拍当事件真实时间。
