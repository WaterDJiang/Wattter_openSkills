# 平板速写讲解

目录 ID：`ipad-sketch`。状态：制作配方，按镜验证。

## 本镜怎么画

单页铅笔底稿、少量标色与局部放大。沿纸上路径移动视窗，已有步骤留在原位置。

素材与数据：步骤、草图和纸页布局。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

维持纸页坐标，在同一个对象上切换笔刷。重新排页会丢失步骤方位。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- recipe-process：同一张画布能保留原料到成品的关联。揉面的一张笔记——从粉堆线稿沿箭头走到面团，用局部颜色显示变化。
