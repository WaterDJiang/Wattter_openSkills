# 示波器数学

目录 ID：`oscilloscope-math`。状态：制作配方，按镜验证。

## 本镜怎么画

刻度网格、余辉轨迹与采样游标。参数驱动曲线和读数，停帧可验算同一点。

素材与数据：函数或有单位的采样数据。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

游标、相位与采样时钟在换画法时继续前进。装饰波形不可标成实测值。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：同一函数可同时驱动轨迹与读数。摆锤的影子——摆锤的水平投影成为曲线上的同一采样点。
- interactive-lab：参数变化能立即反馈到游标。拨动频率旋钮——拖动参数时游标、读数与相位轨迹从同一公式同步重绘。
