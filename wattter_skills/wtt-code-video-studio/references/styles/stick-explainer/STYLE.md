# 火柴人讲解

目录 ID：`stick-explainer`。状态：制作配方，按镜验证。

## 本镜怎么画

等粗线肢体、圆头和可读姿态。用共用骨架连续变换重心与关节，保留角色身份。

素材与数据：人物关系、站位和关键姿势。
可选技术：canvas2d / svg-html。

## 怎样接镜和验收

传递骨架坐标以及手部接触点。没有五官时尤其依赖姿态和朝向。
在动作开始、变化中点和落定处查看主体与关键读数。实现见[连续动作与画法交接](../../style-continuity.md)。

## 用法与原创镜头构想

- concept-explainer：用人物关系演示抽象协作。传话为什么变慢——队列中每个人转身后再说，方向变化形成延迟。
- comedy-short：姿态时差足以传递反应。两个人的让路舞——两人在走廊同时向左再同时向右，第三拍一个人停住才错开。
