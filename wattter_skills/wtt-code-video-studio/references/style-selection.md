# 方向选择与后续四帧审片

视频先有内容，再选方向；五方向决定表现形式，四帧确认决定是否开始完整渲染。用户已指定/已选风格或明确“你来定”，记录依据后免五选；纯文字、只写剧本及旧片局部修正不机械重新选择。

## 五方向之前

保存script.md：目标受众、核心内容、旁白/可见动作、估时与依据。新主题按[编剧](story-and-timing.md#内容结构候选与取舍)比较至多三种结构并择优；已有锁定剧本直接沿用。init只准备工程，不代表选用了默认画法，不提前导出模板。

按具体用法检索：

```sh
python3 scripts/catalog.py list --use-case 个人宣传 --view summary
python3 scripts/catalog.py show desktop-flythrough --use-case 个人宣传
```

可组合purpose/query，用法交叉可合并去重；空结果放宽，不能说题材无法做。完整[映射表](use-case-mapping.md)供人总览，不是普通任务必读。primary/conditional是适配条件，不是评分；构想不是成片证据。先看候选STYLE，选定后才读完整SOURCE及[保真方法](style-fidelity.md)。

### 先识别空间因果，再推荐画风

内容需要讲“在哪里、沿什么路径、地形为何改变选择、区域如何随时间变化”时，优先匹配`geographic-explainer`：战役、迁徙、贸易路线、疆域/交通演变或传播路径。按目标识别，不靠出现“地图/城市/历史”几个词硬套；城市秋景偏`travel-postcard`，人物传记可沿故事/纪实，电路/组织关系图不当真实地理。

```sh
python3 scripts/catalog.py list --use-case 地理推演 --view summary
python3 scripts/catalog.py cases --use-case 地理推演
```

五方向前只读[地理叙事](geographic-storytelling.md)的路线判断，明确真实地理/虚构示意、区域尺度、事件和是否需要真实三维；详细库选型在方向确定后展开。地理是用法，可叠加纪实/知识/历史，不等于一种画风，也不必默认选Three.js。

候选可比较真实地形沙盘、卫星俯视纪实、古地图版画、水墨山河、三维全息等表现；按本片内容、证据和素材可得性调整，不把这五个名字固定成菜单。用同一关键节点比较：例如一次渡河如何让观众看出山口、补给和控制区变化，而非只换底色。推荐说明来源、示意边界和逐片适配工作量；未渲染构想仍标concept。已有明确方向照原决定执行，仍需真实四帧确认。

## 五种完整方向，1首选+4备选

同一个关键镜头比较真实差别，按本片目标、动作、素材与受众筛选，不固定五名字，不取查询前五项。每行写具体用法ID、内容动作→媒介机制→可见结果、声音、依赖/实测状态和缺口：

| 选项 | 类型/策略/画风 | 同一关键镜头如何发生 | 素材、声音及限制 |
|---|---|---|---|
| A 推荐 | 本片首选，不预先采用 | 主体/动作/材质 | 已有条件、待小样验证项 |
| B | 明显不同的方向 | 比较同一个情节 | 同上 |
| C | 第三种方向 | 同上 | 同上 |
| D | 第四种方向 | 同上 | 同上 |
| E | 第五种方向 | 同上 | 同上 |

可给自定义、更多方向或有目的的混合；可行不足五项说明约束。MG是表现形式，Three.js是技术，不与纪录片等类型混为五选。没有实测不填虚假耗时/后端状态。必要的方向草图与剧本同包，变更台词/顺序的区别明示；不拿草图代替后续真实四帧。

优先用能放五项的问题工具询问，可自由输入；按钮不足就在正文完整列A—E并收文字，不截为三项、不分多轮。没有回复保持pending，不把预选、超时、沉默或上一支片的偏好当本片决定。可继续不依赖方向的资料/环境工作。

## 唯一的方向记录

style-choice.md只记录方向，不记录四帧批准：

```text
status: pending | selected | delegated
script: script.md
options: style-options.md
selected_direction: 实际所选，未定留空
primary_style: 目录ID或自定义方向
supporting_styles: 辅助形式及使用镜头
user_basis: 用户本片选择或委托原话
implementation_scope: 实际路线、依赖及待验证项
```

选B就实施B；改变内容/效果实质取舍时只确认受影响部分。brief/storyboard引用这份记录，将选择落实到色板、造型、材质、动作、镜头及声音，不各自写一套批准。已定内容和未变音轨不无故重写。

## 选定后实际怎么推进

读完整方法，按本片写代码，先做代表帧和高风险动作自查，再按[四帧审阅](preview-review.md)产真实2×2拼图、展示并等待用户确认。未确认不完整render；用户确认后记录该版本原话与指纹，继续混音/渲染/最终审阅，不再设脚本、配音等审批站。普通“直接跑完”或“继续”不能代替尚未作出的方向决定或四帧确认。

旧片改字号/遮挡沿既有方向与当前工程，不回查完整风格库；画面变化使旧拼图批准失效，出新版给用户确认。纯代码变化不触发素材变更确认；完全一致重跑复用有效四帧记录。两种审阅不混为一套。
