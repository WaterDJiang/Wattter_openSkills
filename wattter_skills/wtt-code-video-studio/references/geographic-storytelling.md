# 地理叙事、地形与战役推演

用于历史/虚构战事、事件复盘、迁徙、贸易和交通路线。用途沿知识/故事/纪实/数据选择；画法是地形地图、插画地图或三维地理。不增加第七大类或开场模式选择。微缩文旅场景仍走[地图明信片](seasonal-map.md)。

本页是实施配方；新增库仅官方功能已研究，未新增预装地图渲染器。库功能、输入、来源和路线唯一维护在[技术目录](frontend-libraries.md)及其JSON，不把“库支持”说成“本Skill自动实现”。

## 先确定画面要求

- **主要俯视地图、路线与区域变色**：从terrain-2d开始。地形可用已配准高清晕渲影像，Canvas画区域/城市/箭头；D3-geo处理投影，按需选TopoJSON/Turf。无需为阴影立体感强行使用真实三维。
- **连续大范围缩放、倾斜地形和地图瓦片**：map-engine。MapLibre主选，OpenLayers适合多投影/GIS及高程晕渲；轻量二维可用Leaflet，但不能当成等价三维替代。
- **需要山谷遮挡、绕城池、机械/桌面三维构图**：terrain-3d，Three.js管理真实网格、相机、灯光、贴图与模型。高程或建模数据仍需另备。
- **地球→区域、跨洲路线**：globe-3d，CesiumJS。先确认地形、影像、3D Tiles来源与就绪策略，避免为几座城市的平面推演引入全球引擎。
- **大量同时运动轨迹**：trajectory-data，deck.gl提供轨迹/区域/文字等GPU图层。战事规则、占领顺序和箭头样式仍由本片定义。
- **虚构地图、插画和分层视差**：illustrated-2p5d。可用图片生成创作资产，再用PixiJS/Canvas合成；手绘生成艺术可选p5.js。对话中只展示与剧本有关的选项，不把库列表作为风格问卷。

```sh
python3 scripts/catalog.py libraries --route terrain-2d --view summary
python3 scripts/catalog.py libraries --query 地形 --view summary
python3 scripts/catalog.py libraries --route terrain-3d
```

## 图片生成与三维构图各补什么

图片生成可做概念构图、纸纹、风格插画、城池外观和分层背景；需要生成时调用当前会话实际可用的图像能力，不假设某个生图Skill/服务已安装。确认前不自动生成一套资产。真实地图先锁地理几何，纹理与美术围绕几何处理；地名、边界和箭头保持独立矢量层。生成图无法作为精确经纬度、DEM、古代疆域或实际道路的证据；风格化重绘后仍核对地标与控制点。

“3D构图”先确定物体体量、相机、焦距/正交范围、遮挡和光线。Three.js可以用基础几何搭景，或加载有许可的glTF模型；图片可作为材质或平面层，但不能据此得到建筑背面和真实高程。只有视差需求时用平面分层；真正环绕/遮挡需要几何。图生3D结果若另行取得，作为外部模型登记，不声称本Skill已自带图生3D。

## 按内容制备数据

在本片brief中记录路线、可见机制、坐标和素材来源，再在项目内制备具名数据文件；这些是本片scenes读取的数据，不是pipeline自动支持的新film字段。

| 数据 | 至少记录 | 约束 |
|---|---|---|
| 地理 | CRS/轴顺序、范围、底图与DEM、地点ID/坐标、区域多边形、河流 | 矢量、栅格与高程同投影/范围；经纬度不是任意像素坐标 |
| 路线 | 单位ID、控制点、方向、长度、来源/示意 | 现代寻路不当古代路线；曲线沿地理/叙事需要定义 |
| 事件 | ID、剧情时间、视频起止帧、参与对象、行动与结果 | 剧情“第八天”与视频第八秒分开；事实、推断、虚构分开 |
| 镜头 | 关注对象、中心/范围、缩放或pitch/bearing、起止帧 | 同一世界持续定位；全局frame与场景localFrame不混用 |
| 标注 | 对象ID、优先级、出现区间、屏幕偏移、引文出处 | 文字保持屏幕字号，避开底部字幕/侧卡 |

来源缺失时使用原创示意并标明；不把随机地形叫真实地貌。库只提供算法或渲染，古地图、坐标、DEM、瓦片/服务和声音仍需取得并沿[素材审阅](material-review.md)锁定。Google/百度按[地点研究](map-research.md)检查网络；WGS84、GCJ-02、BD-09分别识别，不把Proj4当通用纠偏按钮。地图服务可显示不代表可批量离线缓存或分发，保留实际许可/归属文字。

## 确定性接入与渲染

沿[帧契约](visual-recipes.md)：renderFrame(i)从绝对帧重建状态，prepareScenes只预载和缓存资源。已有起步runtime是Canvas2D；Three/MapLibre/Cesium/deck等可能需要独立canvas/容器和合成层。必须为本片调整页面/截图舞台与渲染适配，不能把它们直接填进默认drawScene就称已接入。

- 只保留一个帧时钟。GSAP暂停seek；p5 noLoop；Pixi停止ticker；Three停止自动loop；地图相机直接设置目标值，不能依赖实时flyTo/惯性/Date.now。
- 从时间和事件表重新计算当前全部控制区/部队，不只在某帧回调里“改一次归属”。前进、后退、乱序请求相同帧应得相同画面。路径箭头按长度显露，头部沿切线；大型区域几何运算预处理。
- 瓦片、DEM、纹理、模型、glyph、sprite与字体都需真实就绪。单次requestRender/triggerRepaint不等于可截图。在线地图先核对访问，再沿许可本地化可固定资源；等待框架完成当前渲染和数据请求，超时失败，不用固定sleep掩盖缺图。
- 地图实体随相机，HUD不随相机；标签按投影后位置排布，必要时按缩放层级隐藏次要文字。多画布合成检查透明度、颜色、裁切、GPU上下文和字体。
- 采用时固定库版本/lockfile与LICENSE。数据/服务/字体许可单独记录；研究目录中的null版本不代表允许使用latest CDN。GPU与LOD一致性仅在固定环境实测，不承诺跨机器像素完全一致。
- Remotion可替换宿主；它的时钟、异步资源、素材锁、四帧确认及最终导出另适配。库附带示例成功不代替本片门禁。旁白/音乐与写实片段沿现有[视频素材流程](footage.md)接入。

## 参考片复现的来源说明

交付分别说明底图/DEM/矢量的实际数据源、代码自绘的区域/标注/动画、生成图片的使用位置，以及是否直接用了参考片的帧或声音。真实地形经脚本转为纸色纹理仍是外部底图，不能称纯代码生成全部地貌；没有使用生图就不声称AI绘图。参考片音轨只在用户授权且许可/用途明确时使用，登记来源；明确要求个人声音时沿现有defaultVoice合成，不默认沿用原说话人。示意疆域/河流与考证事实分开。实际来源随素材清单保留，回复用一两句讲清即可。

## 最小验收

先做总览→推近→两路行军→局部占领变色→回总览的短工程。检查1080p下地图锚点对齐误差不超过2px；标签无互压/遮字幕；帧i→j→i一致；日期与台词/事件一致；纹理/瓦片无空白。再检查运动序列，展示真实代码四帧拼图，用户确认后才渲整片。

没有历史坐标证据就标示意；没有实际GPU/地图小样就只标recipe/research-only。长片先测代表镜头耗时、高清资源和磁盘预算，再确定分章策略。此验收是后续每片执行要求，不表示本轮库研究已渲出地图。
