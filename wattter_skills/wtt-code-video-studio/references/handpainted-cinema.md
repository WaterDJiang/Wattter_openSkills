# 手绘电影式角色动画

用于角色故事、自然幻想、品牌世界观和诗意讲解，仍归“故事与观点/视觉与创意”，不新增一级模式或开场选择。**默认采用本库《晚风来信》V2的纯Canvas工艺基线**：有形体受光的笔触、分层空间、人物衣料明暗、接地步态、道具附着与叙事镜头。用户指定其他画法/色调时优先沿用。

## 已随Skill提供的实现

[原创源码与使用说明](../assets/handpainted-cinema/README.md)已包含V2的forest.js、courier.js、scene.js、独立预览页、示例film与渲染/姿态/配乐工具。它们是可运行工程参考，不是只收录库名或指向安装时缺失的outputs目录。仅Canvas 2D路线有本库实际成片与移植验证，p5.js/Three.js仍按新项目另测。

```sh
python3 "$SKILL_DIR/scripts/handpainted.py" "$NEW_PROJECT_DIR"
```

此命令**代替通用pipeline.py init**，内部复用同一初始化和声音doctor；不要两个初始化连续跑同一目录。它只复制到尚不存在的新工程，不合成声音、不seal、不宣称美术通过。旧项目不自动升级。

示例是12秒原创信使放飞纸鸟；实际用户内容需先发展剧本、原创角色/场景、动作和时长，再改相应代码。不是每个主题都画森林、穿同一件衣服或固定12秒；原“内容决定时长、实际旁白校时”保持。

## 默认工艺

- **先形体后笔触**：画树冠/建筑/服装等轮廓与明暗体积，再在各自形状内布不规则色块。颜色由局部位置和主光方向决定，叶团有枝条归属；不把椭圆/随机点均匀铺满画面。
- **材质有方向**：树干纵向并有收分/分叉，草丛根植土壤，水面横向及反射独立裁切，衣料笔触沿褶皱。微细节依附对象，而非同一噪点覆盖所有层。
- **暗前景—清楚中景—低对比远景**：前景树干/蕨草框景，中景让角色和动作可见，远林保留透光间隙、根部自然渐隐。树根与岸线/地面连接；不能悬空、硬截断或落在水里。其他题材重新设计对应景层，不强制森林构图。
- **角色有轮廓、体积和生活细节**：头脸、头发/帽子、衣褶、口袋/包、鞋等按人物设定设计，统一主光，避免全身同一平涂块。主体表演必须能辨认，背景的精细程度不能代替人物动作。
- **脚接地、手带道具**：落地阶段固定脚的世界坐标，用膝/髋补偿身体起伏；关节/附着物读取同一状态，释放前道具读取手腕，释放后才进入独立轨迹。原姿态检查只验证示例角色，新角色须改检查依据。
- **完整动作事件**：按剧本安排预备—动作—跟随—停留，目光/头部、眨眼、呼吸、围巾/衣摆作次级动作。手抬起来、鸟飞出去的结果要看得见；检查飞行路径是否被前景挡住。
- **镜头服务焦点**：按内容用建立、局部线索、完整动作与落点编排，可用缓推和分层视差；不是强制所有故事多角度、固定镜头数或只动背景。2.5D层片不称真实3D，复杂空间翻转/穿插另选引擎并实测。
- **笔触缓存、帧号驱动**：固定seed的背景/纸纹离屏生成并缓存，每帧从整数帧号重建姿态、镜头和光线，重置Canvas样式与裁剪，不依赖真实时间/累积ticker/每帧Math.random。

## 颜色角色：V2森林示例

下列值已实际用于示例源码，不是额外未接入的配置。新题材按故事/场景重配，保留主光与明暗关系；不固定所有影片都为绿色森林。

| 角色 | V2示例色值 |
|---|---|
| 暖亮天空/透光远景 | #A5BCB0 → #F5E9BD → #E7D7A0 |
| 深色前景树/草 | #153C36、#173D3B、#214C40 |

不要用雾层抹平所有景层，或用高光/颗粒替代结构。标题优先放在本来就有净空/对比的区域，不能为字幕遮暗关键动作。

## 制作与验收顺序

- 已选此风格则直接沿用，必要构图与声音安排合入现有决策包；代码/动作自查后展示[四帧拼图](preview-review.md)，用户确认后才完整导出，不新增其他逐站确认。
- 从自有源码示例起步或按剧情重写；用keyframes输出代表静帧，实际看原尺寸局部与640宽，按主体/受光/材质/景层/焦点评审。有参考时按同画幅对照，未达到本次目标就先改画面。
- 静帧后用motion_preview.cjs按本片事件帧窗口生成最高风险动作短样，确认脚步、关节、遮挡和道具/动作结果。静帧漂亮不等于动画通过，数值姿态检查也不是美术评分。
- 正式旁白/声音按本片需要安排：有defaultVoice且需要旁白时默认沿用，不由“电影感”自动删旁白。示例无对白/音乐只作复现，不固定到正式剧本。
- 按原素材审阅确定/锁定音频和外部素材；重跑先check，变更用候选/diff/确认。工具对已有锁/音频拒绝示例覆盖，不能用compose/seal重建绕过。
- 将实际声音、剧本和动作一起编译timeline，preview自动出四帧并按用户原话记录批准；render_handpainted.cjs完整导帧前也检查同一批准。改变时长/画幅须同步绘图帧数、事件、布局和音频；仅改film或ffmpeg时长会被示例渲染器拒绝，不能截断/重放凑长。
- 实际导出后沿[视频质量](video-quality.md)对最终MP4取首中尾、缩小图与连续动作，再review。分别记录工程、视觉/参考目标、试听、用户采用；缺失不写通过。

## 边界

V2仍有人物/树冠的程序几何感；用户指定采用其方法作为新基线，不等于原参考全部画质已复现。新主题、复杂角色表演、p5.js/Three.js均须新证据，不能凭示例类推。

参考HTML若只有播放器/内嵌成片，不视为生成画面的源码，也不推断全部由程序绘制。保留纯代码路线；引入AI位图/生成视频必须明说方法变化。原参考的媒体、主角、剧情、音乐不进入公开Skill。单HTML播放只在用户需要时内嵌媒体，并说明体积增加；播放器屏幕随机颗粒若需入片，须改为固定seed/帧号后实际验收。
