# 地点声音选材

用于真实地点的地图明信片、城市/乡村介绍和文旅视频。音乐与环境声共同表达地点、季节和片中生活；不为所有城市套同一首八音盒，也不把“民族乐器/亚洲音乐”标签当作当地特色。选材由执行者使用可用搜索工具完成；本库没有自动识别地域音乐、试听或全网下载的后端。

## 先确定本片听见什么

- 地点消歧：城市/县镇/村名、国家与上级行政区、片中范围、季节/时段。同名地点不混用；“秋季”也要核对当地气候与物候，不能直接套落叶或虫鸣。
- 分开设计音乐、环境声、动作音效和旁白。音乐提供情绪/节奏，环境声提供空间/生活线索，动作音与画面事件对齐；不要求每片都有全部声部。保留有效defaultVoice，选音乐不改配音音色。
- 写2—4个待核实的声音线索：本地音乐传统/乐器/节奏、当地语言与生活声、交通/港口/街区、自然地景。查当地文旅、文化馆、博物馆、演奏机构或录音者的一手资料确认关联；旅游标签、城市刻板印象和搜索命中不能作为结论。
- 大城市按本片所处城区与叙事选择特征，不把整座城市缩成一首网红歌曲。小众地点从当地的文化归属、生活方式、地形水系和季节找线索，不用知名度决定是否研究。

## 检索与逐级回退

先盘点用户拥有或已授权的音频。外部选材同时查地方特征依据和具体录音许可，不能只搜索“城市名＋BGM”。按用户语言及当地语言/英文别名检索，必要时核对旧地名。以下是查找次序，不是新增的用户模式选择：

| 匹配层级 | 查什么 | 成片与记录如何表述 |
|---|---|---|
| `local` 本地 | 该地点/片区的真实录音，或有证据关联当地的曲目/音乐实践 | 区分“本地实录”与“关联当地的音乐”；作曲家籍贯或标题含地名不证明录音地点 |
| `cultural-region` 文化区域 | 本地缺少可用材料时，查所属文化圈/同一传统的器乐与生活声 | 记录覆盖范围、关联依据和实际录制地；不能说来自本城 |
| `province` 省域/大区域 | 文化圈仍缺材料时，检索省域或所在大区域；行政相邻本身不证明风格相同 | 有文化关联才作为地域音乐；缺依据时只能是普通氛围候选 |
| `landscape` 相似地景 | 河岸、港湾、山林、农田等声景，核对季节、生态、交通和时段 | 标“氛围音效/非当地实录”；不以相似气候推断音乐文化，不把海浪用于安静内河 |
| `original` 原创 | 参考已核实的节奏/音色方向新作，或低干扰的原创配乐 | 标原创/合成示意；未经实测的高胡等合成不能称真实乐器演奏，不照抄受保护旋律 |

至少覆盖“地名及别名＋录音/field recording”“地方传统＋器乐/录音”“许可明确的音频库＋已核实的声音线索”这些相关方向；没有相关传统或平台不可用时记原因，不为凑数量编记录。每次放宽范围写明在哪一级、为什么。网络失败可换可达来源或用户已有资料，不能把未访问、验证码或只见搜索摘要写成已核实。

本地没有材料不应一直阻塞制作。完成有界检索后，在已授权范围内采用有明确标注的兜底并继续；只有付费、关键内容/风格改变、或已锁素材变更授权未决时，暂停受影响部分。无须为每一级回退提问。

## 候选筛选与声音计划

先排除用途不允许或授权不明的候选，再比较：地点/文化依据 → 本片画面与季节 → 情绪/密度 → 时长/循环可编辑性 → 音质与成本。曲名、BPM、下载次数不能代替试听。安静明信片通常避开突兀歌词、强鼓点和大段广播，但剧情需要时按内容安排。

新项目复制[计划模板](../assets/map-postcard/sound-plan.example.json)为`sound-plan.json`，由执行者填写；它是检索和创作记录，不是第二份素材锁。模板保留pending，不能直接当成已选曲。必填内容：

- `place`：地点、上级区域、季节/时段、片中范围；`intent`：情绪、密度、旁白/环境声/循环需求。
- `identityClues`：线索、依据URL/用户材料、实际核对状态；音乐关联与录音地分别记录。
- `searchLog`：查询词、平台、访问结果、发现/缺口、回退层级和原因。没有搜索结果也是有效记录，不自动给许可证盖章。
- `candidates`：id、title、role（music/ambience/effect）、matchLevel、sourcePlace或unknown、sourceUrl/用户引用、作者、地理/文化依据、声画/季节适配、具体许可及证据URL/文件、视频同步/剪辑/商用/原文件再分发是否允许、署名要求、费用与取得状态、拟取片段、循环方法、试听状态。未知项保留unknown/pending，不填true伪装已核对。
- `selectedIds`、`fallbackReason`与`listening`：实际采用对象、取舍、试听者/方法/观察；没有已授权且适用的候选就不能写selected。原创对象记录生成方法/采样来源，不能伪造外部来源URL。

可推荐1个首选和至多2个有意义的备选，说明声画差异与费用；它们合入已有脚本/构图决策包，**不再增加一轮开场选音乐问卷**。用户已指定或委托代选就直接按约定选；不能把用户未答、页面预选或超时当授权。

## 许可、候选与开源

- 公开可听、可下载、免版税、可商用、可剪辑同步进视频、可分发原音频是不同权限。传统曲调与具体编曲/演奏/录音分别核对，不因曲子古老就把现代录音当公版；网页文章的CC许可不自动覆盖嵌入音频。
- 逐曲核对原页面/许可文本与实际用途，记录核对日期、版本及证据。优先可编辑且用途允许的CC0/CC BY、用户自有音频或明确授权库；有条件许可逐条落实。包含第三方音乐、可辨识个人对话或广播的环境录音，平台标签不能替代其具体使用依据。
- 免费优先；付费只列具体候选与当时费用，已有相应授权则继续，否则先确认采购，不开订阅/计费。音乐库下载或许可证书可依网络换通道，不能从无关转载绕过授权。
- 最终使用的原音频、必要许可证据、剪辑/混音衍生素材按[素材审阅](material-review.md)进入assets.json和版本锁，sound-plan.json不能替代或重建旧锁。已锁片只在候选目录下载/剪辑，先展示diff；明确指定替换对象与目标的用户指令可直接作为授权，其他变更按原审阅执行。
- 开源时区分成片许可与工程原文件分发许可。不能再分发的原音频及受限历史不放公开包；以来源、许可取得步骤和用户本地路径说明替代，公开源码包明确可能需要自备素材，完整私有工程继续保留版本历史。可公开的素材按原许可署名，不混称全部原创。

## 合成与验收

按本片真实时长选有乐句意义的片段；循环点尽量落在节拍/乐句边界，必要时交叠尾音并留前后余量。环境层低音量铺底，明显船声/脚步等与画面对应，禁止有船就机械加大喇叭。旁白需要时让位，未实现自动ducking不宣称自动完成。

沿用原timeline、混音和音频技术检查。实际试听最终MP4，检查转场、环境声与音乐比例、旁白清晰度以及连续两遍播放的接缝；只查波形、解码、响度或图像MAD不等同听感通过。不能试听则记not_checked，不伪造合格。map_music.py仅是固定20秒原创振荡器示范/无外部素材兜底，不是地方乐器渲染器；时长变化需相应制作新音频。

## 迁移示例：检索方向，不是城市默认答案

以下仅演示如何提出线索；不是已核实的曲库、地方事实表或固定城市配乐，实际每次都要研究和试听：

- 大城市水岸片：查本地器乐实践与片中水岸声景，优先所画片区；不能仅用“亚洲风”标签。
- 大城市老街片：查当地语言、生活节奏或音乐实践，避免把热闹叫卖塞进无人静街；不直接抓取流行歌曲当背景。
- 不知名河谷县镇：先核对所属文化区域与河流/山地生活，再找区域器乐和适配的河岸环境声；仅找到外地溪流就明确标氛围素材，不说当地河流实录。
- 缺少可复用录音的村落：记检索缺口，以当地已证实的季节/地景安排声音；可用原创配乐加非当地氛围层，不编“祖传民谣”或虚假录音地。
