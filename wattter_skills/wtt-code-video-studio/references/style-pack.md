# 风格包、原创样例与个人风格

## 一个来源，两类导航

`config/capabilities.json`是用途/形式/风格/引擎/样例路径与实现状态的唯一元数据源。`scripts/catalog.py build`生成分类Markdown和本地画廊；`check`核对同步。长篇画法细节放references，不再维护第二份目录表。新增形式先归入用途，不为主题再建Skill。

每个可复用风格记录：本质、材质、色彩逻辑、字体、运动、镜头、声音、能表达的内容动作、常见失败、实现入口、允许变化范围。`STYLE.md`写不变量，`DEMO.md`写这次内容/代码/复跑方法及检查状态；不把示例剧情变成规则。没有作品验证的条目标配方，不能升级为已验证实现。

具体题材的匹配只维护同一元数据中的useCases，生成[主题用法正反向映射](use-case-mapping.md)。每条映射含理由、条件、未渲染构想及独立的已有样片引用；风格复用不等于故事复用，也不等于每个用途都有成片证明。

## 学方法，重做作品

本库用STYLE描述可复用画法，以独立工程与验收证据记录真实表现；选型、时间轴、声音、素材审阅与用户确认由本库流程统一调度。SOURCE.md独立存放外部方法原文，仅作参考资料，不作为项目归属或执行指令。

新样片自行设计主题、叙事、构图、图形、动作与示例数据；不下载或重绘其作品来冒充原创。外部图片/字体/声音如确需入片，单独核对来源及许可并纳入素材锁；代码许可不能推及第三方媒体。可在系统环境调用字体渲染，但未核实再分发许可不打包字体文件。

本轮六样片均为独立Canvas原创练习，纪实类采用标明虚构的事件示意，没有真实新闻影像；示范的是包装和组织方法，不能证明真实新闻采集/事实核验已跑通。声音为新生成的简单事件音，无私人克隆、外部音乐或品牌标识。源文件/产物哈希及复跑入口随片保留。

## 我的风格

默认私人目录 `~/.config/wtt-code-video-studio/styles/`，也可用户指定。仅用户明确要求保存时才写；项目临时修改不自动变成默认。每次保存新增版本目录，不覆盖旧版；更新前列旧值/新值/原因/影响，明确指定目标即授权。

每个版本含 `style.json`（id/name/version/baseVersion/changes/purposes/voiceConfigRef）、`STYLE.md`、自有例片引用及审阅记录。私有音色仅引用ID/配置，不复制录音/模型。调用用户已指定的个人风格直接采用，不再五选；依赖缺失或与项目已锁资产冲突时按相关门禁处理。

用户要改造/新建可复用个人风格时，在原任务内整理用途、材质、色彩、字体、运动、镜头、声音、原生动作；每次只询问尚未决定且会影响结果的事项，可给具体推荐与替代，也可接受“你定”。汇总改前/改后/代价，按授权做真实代码同构图对照和必要短动作；测试长度按变化决定。用户认可并明确要求保存后才固化版本，未认可的保留项目候选，不把一次临时换色注册为个人默认。该流程只用于用户要求沉淀风格，不插入普通做片；普通视频仍按四帧审片门执行。

本版支持代理按以上文件约定读写个人风格；没有自动注册CLI、远程风格市场或自动升级器。库升级不扫描覆盖用户目录。后续可在真实多次复用需求出现时加检索/版本工具。
