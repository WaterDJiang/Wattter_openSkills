# 已批准画面只换声音

只适用于已完成通用pipeline成片的后期修订：镜头、字幕、帧数和时序全部不变。原片缺少有效四帧批准/渲染/合成回执，或任何画面/字幕/时长需改变时，回到[四帧流程](preview-review.md)。地图等独立导出器尚未接入本工具，不手写回执冒充通用工程。

## 保留原工程，审阅新声音

- 原工程与final.mp4保留，不改film/timeline/render/finalization中的哈希；新建独立修订目录。已有新声音先留素材候选，沿[素材审阅](material-review.md)输出旧值、新值、原因与影响。用户明确指定“把这支片声音换成已配置个人音色”等对象和目标即授权，仍保存diff和原话，不重复询问。
- 修订目录必须继承原素材锁历史：复制旧素材和完整.asset-review后，再提议/接受新素材形成后继锁；不得删历史重新seal规避变更。实际入片的新母带、各句WAV/旁车、复用画面文件及来源说明都登记。私人模型/参考录音仍留用户私有目录，不随项目公开。
- 逐句使用[已有音色](voice.md)真实合成，按原句起点核对实际长度，再混成与原片等长的48kHz母带。短句之间补停顿；超出原窗口不能裁词或加速。锁定原文时保留原文并重试合适表演；改写文字需用户内容授权，改字幕/时序后重新审四帧。保留失败take。
- 母带只包含本次选择的声音/音乐/效果，不自动沿用参考视频的说话人。明确记录是否保留原声，不能把原声说成个人合成。

## 执行流复制与全帧验收

例：original-film为旧工程，voice-v2为已完成素材diff审阅、锁定与母带准备的独立修订工程。在含新版tools的工程内运行：

```sh
python3 tools/audio_revision.py \
  --original /path/to/original-film --project /path/to/voice-v2 \
  --picture media/approved-picture.mp4 --audio audio/new-master.wav \
  --out final-voice-v2.mp4 --report audio-revision-v2.json \
  --message '用户明确指定本次替换对象与目标的真实原话'
```

picture是修订目录内登记的原画面文件（可从原silent.mp4复制），audio为等长母带；示例message不代表已发生批准。两者先沿素材审阅锁定，不能用一条message代替素材授权。文件与报告存在时拒绝覆盖，重试用新名称。

工具读取原工程当前素材、源码/时间轴、混音、四帧批准、渲染与finalization绑定；原批准失效就阻断。修订历史中必须保留原锁的同一manifest哈希，后继版本须有diff和用户授权，重新seal的新历史拒绝执行。执行前比较原silent与复用画面的压缩视频流SHA及全部解码帧MD5/时序，然后FFmpeg显式只映射0:v和1:a，`-c:v copy`复用画面。新母带按I=-16、TP=-1.5、LRA=9处理并输出AAC，旧视频中的音轨不映射。执行后再比较全部帧和视频流，查帧数、H.264/AAC、音画时长、完整解码与峰值，复核输入和锁未变化。

报告独立绑定原成片、原四帧批准、新素材锁、新母带及最终文件哈希；失败写passed=false与错误，留候选和原版。成功只代表纯音轨修订的技术证据，不写原pipeline验收回执，不假造新四帧确认或重标旧视觉验收。主观听感和用户采用仍pending；有条件实际试听后另记录。再次交付先重新核对当前文件哈希和素材锁，过期报告不能当当前结果。

此流程不重新绘制已有作品；将来增加与台词联动的口型、角色高亮、字幕时间变化或改变混剪镜头，均离开纯音轨范围。
