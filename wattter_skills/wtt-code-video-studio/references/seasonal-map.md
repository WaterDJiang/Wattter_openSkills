# 季节地图明信片

用途：视觉与创意、文旅/城市产品介绍、地理知识示意。支持按片设计俯视、等距/斜俯视与同场景多视角，配色不固定低饱和；与真实地铁示意和GIS测量分别使用。纯示意地图不可声称真实街区拓扑；用户要真实地图则先核对道路/地标/比例与数据许可。配色/视角/投影组件与专项验收见[地图美术与相机](map-art-direction.md)。

## 地点研究先于构图

真实地点先按[地点研究与构图](map-research.md)检查Google/百度实际可用性，核对地方特色建筑和季节，再出原创构图SVG、来源与取舍说明。已选本配方不重复五选；没有实际取得地图预览就记录未取得。平台截图不默认转绘，地理与建筑依据需可复用。构图确认或既有授权落实后重写本片场景，不能只给通用模板换地名。

## 输入与默认

地名中英文、季节、乡村/城市、意境中英文、经纬度与来源、声音意图。本配方默认20秒、1080×1080、30fps、600帧，世界高1440；这是此配方默认，不改变全Skill内容决定时长。已明确指定本配方不再五选；未定方向时可把它作为一个完整候选。

正式地点的音乐与环境声按[地点声音选材](location-sound.md)研究并保存sound-plan.json，匹配当地/文化区域/季节/片中生活；大城市找可辨特征，小众县镇逐级查区域和地景。找不到可用当地录音可用有标注的兜底，不能冒称当地实录。公开可听不代表可配乐或可开源分发，声音安排并入原构图方案，不另问开场音乐模式。八音盒/8bit不再是所有正式地点的默认音乐。

原2D模板config默认为“示例小镇”，坐标留空。正式地名需要核对英文写法和坐标，使用有符号数以支持南纬/西经；无依据不编数字。春夏秋冬有各自色板，米白#FDFDF9留边，新地图可优先推荐鲜明粉彩；斜俯视用侧顶面色差表现体积，不强制写实阴影。原模板代码保持俯视行为，新视角需显式接入投影组件并重画地标，不是改config就自动生成城市3D。

## 画面与循环规则

以下camY/世界周期为原俯视下移路线的约束；单视角多版本或单片多视角按[相机规则](map-art-direction.md)设计。同一世界的相机轨迹可以代替固定下移，但需验证首尾姿态和物体相位闭合，不能只对白场测接缝。

- frame(i)从绝对整数帧绘制完整画面，浏览器和Node调用同一map.js；以固定seed预生成树、云和边缘喷点，不使用逐帧随机或累积积分。
- camY=(i mod 600)/600×1440，向下匀速走一整个世界高。道路/河流由整数谐波sin(2πy/H)构成，首尾位置与一阶导数对齐。地块/标线纹理的重复间隔也必须整除H；跨边界对象补画。
- 动态周期按整数圈数表达，不要求所有物体同速。汽车/船沿周期道路河流移动；行人正弦往返；飞机300帧一趟；风车20秒3整圈。云横向1或2圈，纵向0.55视差的图层高必须是0.55×H=792，独立按该高度回绕；仅乘0.55却仍按H拼接会跳变。
- 指定开合版时：1秒中心点扩成方形，尾2秒收缩并散点消失，首尾在米白纸面衔接；它会有短暂空白。用户要连续滚动不断片则保留同一世界循环、在config设置 `"reveal": false` 关闭开合，固定字幕仍保留。沿用用户已给方向，不增加开场模式问卷。
- 字幕固定底部三行、留安全区，地图层和标签不一起滚动。较长地名/意境重新排版，不压缩成不可读小字。

## 可运行模板与步骤

将[map-postcard目录](../assets/map-postcard/)复制到**新项目**，修改config.json。模板仅由本库自写图形组成，不依赖外部图片。Node使用canvas包；安装固定版本并保留package-lock。`CANVAS_MODULE`只用于已装模块定位，不作为本机硬编码。

```sh
npm init -y
npm install --save-exact canvas@3.2.0
node export.cjs --out ./render-v001
python3 /实际Skill路径/scripts/map_music.py ./render-v001/music.wav --style music-box
ffmpeg -n -framerate 30 -start_number 0 -i ./render-v001/frames/frame-%04d.png -i ./render-v001/music.wav -frames:v 600 -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart ./render-v001/final.mp4
```

以上音乐命令仅演示无外部素材的新项目路线，不代表已为用户的地点完成声音选材。正式制作按sound-plan选定授权音频，经原管线混音/素材审阅后再合成；用户明确要八音盒/8bit或采用原创兜底时可沿用此命令。Python配乐为20秒/48000Hz原创振荡器音乐，`--style 8bit`可替换；跨末尾音符尾音以mod回写开头，不粗暴切断尾音。PCM周期与AAC播放器编码延迟是两件事，实际成片循环还要试听，不能仅声称WAV周期就保证任何播放器无缝。

浏览器预览：从复制目录运行`python3 -m http.server 8765 --bind 127.0.0.1`，打开index.html。`frame(i)`或滑杆可精确查看，`play()`开始播放；预览时钟只选帧，不参与绘制状态。

## 校验与资产门禁

`node export.cjs --out ./check-v001 --check-only`提供独立校验，不导出600张PNG。输出seam-check.json及5张预览。阈值为RGB归一化MAD **严格小于12/255**；同时检查0与599未遮罩画面、0与600完整周期、乱序重绘、道路河流位置/导数、非空主体与中段运动。未通过退出非零，不标“无缝通过”；首尾都白不能替代未遮罩检查。

编码后运行 `python3 /实际Skill路径/scripts/check_loop.py ./render-v001/final.mp4 --out ./render-v001/encoded-loop.json` 核对真实MP4首尾、尺寸、600帧及30fps。

导出器拒绝已存在目录，ffmpeg用-n。进入正式film工程后，音乐与派生视频/PNG按素材审阅登记来源、自制依据和SHA；已锁素材修改只能先输出到.asset-review/candidates，不使用本模板绕过原锁。Node新片导出为专项路径，最终仍须核对编码参数、全部解码、最终首尾与动作、声音试听；timeline如需其他镜头则通过已有footage接入。Node与浏览器字体栅格化不承诺逐像素一致，确定性只在固定运行环境比较。

模板校验通过说明代码路线可运行，不表示所有地点/季节/文字排版都已验收。延长片长需重新计算N、相位、音符与采样长度，不只改ffmpeg时长。
