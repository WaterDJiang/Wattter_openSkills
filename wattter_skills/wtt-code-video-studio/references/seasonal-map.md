# 季节地图明信片

用途：视觉创意、文旅/城市介绍、地理知识示意。默认同一世界在一支片内俯视→左斜俯视→右斜俯视→回俯视，连续移动、旋转和小幅推近；用户指定固定视角时沿用。示意地图与真实GIS测量分别处理，不能把原创方块小镇称为真实街区。

## 地点研究与声音

真实地点先按[地点研究与构图](map-research.md)检查Google/百度在当前网络的可用性，核对地标、道路、季节和地理依据，再自绘构图。没有实际取得地图预览则记录未取得；截图不可默认转绘，来源与取舍入档。已选本配方不重复五选，但所有新片仍须展示四帧拼图、等待确认。

正式音乐/环境声按[地点声音](location-sound.md)匹配当地、文化区域、季节和片中生活，并存 `sound-plan.json`。小众地点逐级查区域和地景；公开可听不等于可配乐或开源。未取得可用录音时可明确采用原创合成兜底，不能冒称当地实录。无对白示范无需下载语音模型或个人音色。

## 配置与美术

输入地名中英文、季节、乡村/城市、意境中英文、坐标及来源、声音意图。模板示例为20秒、1080×1080、60fps、1200帧的孟菲斯微缩小镇，采用 `palette:memphis`、`reveal:true`。API无参仍保持 vivid / 30fps / 600帧 / `reveal:false`，兼容旧项目。这里的20秒是配方示例，其他内容按叙事决定时长。

Memphis 使用留白、圆角颗粒画框、清晰描边、无模糊的硬投影，以及大色块上的点、条纹、折线。七色与深靛是示例，允许同色系、邻近色、低饱和或中性色加强调色；图形语言与色卡分别决定。模型根据地方地貌/水色/建筑、季节、主题氛围选色，在现有brief/地点研究写依据，再编成固定 `paletteOverrides`，不逐帧换色、不新增配色问卷。完整功能键与示例见[地图美术与相机](map-art-direction.md)。vivid/soft也是可覆盖的起点，地标仍按片自绘；配色随四帧展示并确认。

模板坐标留空，真实地名、英文写法与坐标均要核对。没有经地理映射的真实路线时，底部经纬度固定或显示“示意地图”；相机变动不等于地理坐标变动。只有有来源、含坐标的真实路径才能插值显示动态经纬度，并将路径纳入素材/源码审阅。

## 确定性、相机与小剧情

- `N = fps × durationSeconds`；`frame(i)` 从整数绝对帧完整重画，seed只在初始化生成几何/颗粒，不逐帧随机、累积积分或读取真实时钟。30/60fps使用同一 `t=(i mod N)/N`，同一秒动作一致。
- 空间模板使用1080×900示意场地和同世界高度投影，不能旋转旧画布冒充另一个建筑视角。相机首尾闭合，地图物件身份/位置连续，标签保持屏幕字号。
- `scroll-top-down` 单独保留1440高世界：`camY=(i mod N)/N×1440`。路/河中心线用整数谐波保证位置与一阶导数首尾对齐，跨边界物件补画；云纵向0.55视差对应792高独立回绕。
- 车辆/船/人/飞机/风车/云各用整周期相位。飞机每片两趟、风车每片三圈；不要把旧300帧周期直接搬到60fps而加倍速度。
- Memphis 至少有两个可见微事件并配合音效：示例0.335N车在斑马线前让行、0.64N双鸟掠过。`sound-events.json` 同时写帧号和 `seconds=frame/fps`，音乐工具校验二者；音效与画面不能各维护一个时钟。
- Memphis 默认前1秒中心颗粒长成画面、尾2秒收回散点；vivid/soft默认连续展示，显式 `reveal:true` 可开合。不开额外开场模式问卷。
- 底部安全区三行：地点中英 / 季节与意境中英 / 坐标或示意说明。文案过长改写或重排，不无限缩小字号。

## 四帧门与完整制作

运行与编码命令在[模板README](../assets/map-postcard/README.md)。先把模板复制到新项目，安装固定 `canvas@3.2.0`，保留锁文件；已有依赖通过 `CANVAS_MODULE` 定位。复制出Skill时带上共用 `scripts/preview_review.py`，不自造另一个批准机制。

```sh
node export.cjs --out ./preview-v001
```

默认仅生成四帧、带帧号/秒的2×2拼图、源码/config/helper快照、事件表与 `seam-check.json`；不生成完整帧目录。样帧应覆盖建立、关键动作和两个斜角，必要时用 `--review-frames` 指定四个代表帧，不拿开合白场凑数。代理展示实际拼图，用户明确确认当前版本后才记录原话并 `--render-approved`。

批准绑定源码、配置、时码、四帧和拼图。完整出口先核对冻结文件与批准，再按批准帧号重绘核对；变化进入新候选预览。素材锁仍是独立审阅机制，不能用新拼图覆盖已锁素材。无批准、普通“继续”、绘图源码/配置/样帧改变均阻断完整渲染。已确认且内容一致不重复问。

Node与浏览器使用同一 `map.js/world.js/presentation.js/legacy-scroll.js`，浏览器 `__filmMeta` 暴露真实N/fps、`renderFrame(i)`确定性绘图。Node逐帧脚手架已接入本门；需要无头Chrome时沿通用渲染路线，不以更换导出器绕过确认。

## 验收边界

`--check-only` 仍出同一四帧门。RGB归一化MAD须严格小于12/255；检查0/N−1未遮罩画面、0/N完整周期MAD=0、7个乱序帧、相机闭环、路河位置/导数、非空主体与中段运动。白场首尾不能代替未遮罩检查。报告保存运行环境、解析配置、功能色和全部依赖SHA256。

编码后使用实际 `--frames N --fps FPS` 运行 `check_loop.py`，再做全部解码、代表动作/边缘检查和声音试听；PCM回绕不保证所有AAC播放器都无缝。技术通过、实际看帧、听感、用户确认分别记录。模板验证不代表任意地点的地标、构图、美术已达标；旧作品和旧快照不重跑、不覆盖。
