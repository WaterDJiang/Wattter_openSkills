# sand：可复用规则

- 本质：从散沙到可辨山形的形体重组。
- 材质与渲染：Canvas确定性绘制，重设画布后按绝对帧重建。
- 色彩逻辑：赭褐颗粒、沙金底、柔色圆日，无外部纹理。
- 字体：系统无衬线；标题/关键标签/说明分层，不打包未核实字体。
- 运动：固定seed与粒子身份；聚散依帧函数，不逐帧随机重铺。
- 镜头：本例固定全景便于看清变化；新题材可推近/跟随，必须保留定位参照。
- 声音：本例原创合成短音提示动作；正式内容有旁白时人声优先，不固定沿用本例音高或次数。
- 内容动作：从散沙到可辨山形的形体重组。
- 失败征兆：只改颜色不改构图；标签挤压；每帧随机导致闪烁；用小字代替主体证据。
- 实现入口：[场景源码](scenes.js)，通过scene.id路由；本例状态见[DEMO](DEMO.md)。
- 可变化：主题、对象、色板、时长与声音均可变；保留可读性、状态同源和帧确定性。
