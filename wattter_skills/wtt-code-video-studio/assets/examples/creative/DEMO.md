# 风把山，写进沙里

8秒 · 960×540 · 20fps · Canvas2D · 原创代码事件音 · 无旁白。

## 本次内容

原创沙粒山景片头，风的意象不声称流体物理仿真。

0–0.7秒松散沙粒；0.7–5.5秒固定身份的粒子归位成双峰；3.8–5.9秒圆日升起；后段保留完整景观。
