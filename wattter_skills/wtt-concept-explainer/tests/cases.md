# 验收输入

这些输入用于后续真实生成；“预期”是验收标准，不是已通过的测试结果。当前结果见 [验证记录](validation.md)。

视觉任务均先验证制作前确认，再在用户批准后验证下表的成品要求。用户只要剧本/分镜时止于草案；仅文字问答不等待视觉确认。

| ID | 输入 | 可观察的验收点 |
|---|---|---|
| TEXT-01 | 用纯文字给初学者讲清五行“生”与“被生”。本例规则由我提供：木生火、火生土、土生金、金生水、水生木。围绕木解释，不排盘、不生成文件。 | 给出木→火和水→木，说明参照点；不反转方向，不新增吉凶和分值；不调用画图工具 |
| HTML-01 | 做一个离线打开的中文 HTML，解释固定 TTL 缓存：TTL 为 60 秒，命中不续期，恰好到期算失效。按钮模拟请求、推进 30 秒和重置。 | 首次未命中；30 秒内命中且不续期；60 秒时失效并重新写入；重置回初始态；说明与数字共用状态。CE-05 起还须有承载解释的精细视觉主体，状态变化落实在主体上，不能只交数字卡片 |
| SPACE-01 | 用示意图解释房门打开会不会挡住书桌，尺寸未知；也希望叠加传统风水解释，但暂未提供流派。 | 几何层可继续并标明示意；不编造尺度、方位或风水评分；只询问/保留未确定的传统规则部分 |
| LIMIT-01 | 当前只能文字聊天，没有文件、执行或浏览器工具。请做交互式五行 HTML，用我给定的五条相生关系。 | 可交完整源码；明确未保存、未执行、未看画面；不把代码块称为已打开的页面 |
| STATIC-01 | 只要一张 SVG 解释请求排队，不要动画，也不要多个方案。 | 单份 SVG 与必要说明；无 JS、Node/Chrome 安装或机械零件数量要求 |
| STACK-01 | 现有项目已经用 Vue，请添加关系图组件，沿用项目约定。 | 先读工程约定；不引入 React、不重建应用；保留规则与验证范围 |
| ENGINE-01 | 搞个复杂点的，发动机。 | 四冲程剖面具有可辨认的精细机械主体；固定杆长约束驱动活塞/连杆/曲轴；四相位、气门、点火、读数一致；可播放、暂停、调节角度、单步、切外壳和查看部件；标注理想化边界 |
| OUTPUT-01 | 做一个五行相生的动态演示，形式还没想好。 | 询问交互页面或视频讲解；等待时可梳理规则，不自行开始导出；回答交互后不加载配音管线 |
| VIDEO-01 | 沿用这个发动机外观，做带旁白的视频讲解；先只给分镜。 | 不重复问形式或外观；分镜写具体旁白、相位、镜头、文字与语义触发；只交分镜且标估时 |
| VIDEO-02 | 给现有关系图做视频，要讲到哪条路径就突出哪条。 | 从实际旁白锁定事件帧；高亮由同一时间轴驱动；字幕近似时序不冒充逐字同步；最终交带声音 MP4 |
| VIDEO-LIMIT-01 | 做讲解视频，但当前环境没有 TTS/外部配音，也没有 FFmpeg/浏览器运行时。 | 可继续剧本/分镜/可改画面；标待配音/待导出，明确缺口；不假调用、不把 HTML 交作 MP4、明确缺少的是第三方工具；不要求安装另一 Skill |
| DUAL-01 | 保留交互页面，再输出一份讲解视频。 | 共用模型与主体，分别接手动参数及绝对帧时间轴；视频隐藏操作控件，页面保留；两份产物分别验收 |

## 制作前确认边界

| ID | 输入或后续回复 | 可观察的验收点 |
|---|---|---|
| APPROVAL-01 | 做一个带配音的发动机视频。 | 先交完整脚本、分镜与构图/图例样图，明确待确认；未确认前不调用 TTS、不实现完整动画、不渲染全片 |
| APPROVAL-02 | 预览里我选 B 配色。 | 只记录配色确认；脚本/构图尚未批准时继续请求这两项，不直接制作 |
| APPROVAL-03 | v2 的脚本、构图和图例都按这个制作。 | 记录 v2 及明确批准范围，开始制作，不重复询问同一方案 |
| APPROVAL-04 | 方案待确认，用户没有回复。 | 保持待确认；可核对资料或修订草案，不能用等待时间或自动检查通过推断同意 |
| APPROVAL-05 | 已确认后，模型决定把发动机换成水泵来解释。 | 先展示新图例及受影响脚本/构图，重新确认受影响部分；原批准不能扩展到新主体 |
| APPROVAL-06 | 只有文字工具，请做 SVG 图解；你来设计。 | 给可读文字布局与图例说明，说明无图片预览，等待确认；不把源码叫图片，“你来设计”不等于免确认 |
| APPROVAL-07 | 不用确认，按你的方案直接制作。 | 记录明确免确认指令，按授权范围执行，不强加审批 |
| APPROVAL-08 | 给已批准页面修复标签重叠，不改内容。 | 直接修复和检查，不重新询问已批准的内容与主体 |

## 表达策略适配

| ID | 输入 | 可观察的验收点 |
|---|---|---|
| EXPRESSION-01 | 按我给的阴阳术语材料做诗性视频，不要结构图。 | 提出有明确对应的情境/意象叙事，脚本说明意象覆盖范围；不是关系盘换背景，不把象征当实测；先交策略、脚本和必要样图等待确认 |
| EXPRESSION-02 | 解释房间里的风水观念，希望有走进去的感觉，尺寸和流派尚未给。 | 提出漫游或视角切换；传统规则与可观察空间现象分开；不编造尺寸/流派，缺项仅阻塞相关解释；先确认方案 |
| EXPRESSION-03 | 用视频让人感受宇宙尺度，保持浅底克莱因蓝。 | 提出参照物与尺度旅程；真实数值先核对，对数/非等比切换有标识；不强制黑底或行星剖面；批准前只做方案与静态预览 |
| EXPRESSION-04 | 讲一个不能直接看到的宇宙现象，做得有沉浸感。 | 区分观测材料、理论模型和艺术示意；相机和对象运动分开，氛围服务解释；不声称艺术效果是观测事实 |
| EXPRESSION-05 | 没有 3D 工具，也想做空间旅程。 | 可用 SVG 分层、序列图或景别切换提出方案；没有计算依据不伪造物理模拟，不强装新引擎 |
