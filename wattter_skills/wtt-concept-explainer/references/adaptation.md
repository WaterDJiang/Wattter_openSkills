# 按概念适配

这些例子帮助选择解释方式，不是通用算法或必须复制的版式。先定学习问题，再选结构拆解、叙事体验、空间探索、尺度变换或对照推演；题材名称不自动决定形式。每条路线先进入制作前确认，以下设计示例不是已验证的成品。

## 技术机制：缓存过期

- 学习问题：同一个请求何时命中，何时需要重新取值？
- 状态：当前时间、缓存值、写入时间、有效期；规则先说明是固定有效期还是访问后续期。
- 表达：请求 → 判断 → 缓存或数据源；按钮控制请求和时间推进，结果展示分支与原因。
- 关键边界：恰好到期；命中是否修改写入时间；取回数据后是否重建缓存。
- 可把缓存做成可替换存储匣、把有效期做成机械刻度盘、用独立路径区分本地复用与回源。底座、接头、标尺等让结构可读；只删除没有解释或构造作用的装饰，不删主体。

## 传统体系：五行关系与八字

- 先确定本次只解释术语/关系，还是展示材料中已有的推导。读取用户给定规则；没有规则时核对所采用的来源或明确待确认项，不编造权重。
- 讲五行关系可用节点网络：每次突出一种关系，箭头明确从谁指向谁；切换观察中心时同步解释。
- 视觉请求可将网络做成有层次的关系盘：节点有独立形态，路径沿清晰轨道，方向用箭头和行进反馈共同显示；关系与文字仍可直接读。无需凭空加机器或只用五个默认圆框。
- 讲八字结构可用四柱与层级卡片；讲时间层可用时间轴叠加。关系与推导依赖具体口径时，把口径写在说明里。
- 生克关系不自动等于强弱评分、性格结论或吉凶概率。只演示关系时不添加出生数据输入、排盘接口或预测结果。
- 用户明确要求个人排盘时，这是额外领域任务：使用已核验的排盘能力或准确材料；不靠可视化模型猜算历法。

## 传统意象：从关系盘扩展到体验与叙事

- 解释阴阳等成对概念，可从用户材料中选定一组对照情境，用光影、显隐、节奏变化帮助观察；旁边明确每种意象对应什么含义。意象只覆盖选定侧面，不把物理明暗直接等同完整理论。
- 五行题材可采用自然场景、短故事或意象转换，让用户按顺序认识概念；确需讲关系时再叠加局部箭头与文字，不要求整片停留在五节点圆盘。生克顺序和术语依据指定来源，不用任意转场暗示新关系。
- 八字题材可采用“逐层阅读一个文本案例”的叙事，依次展示材料、观察角度和所用规则；四柱卡片只是可能的辅助。历法与推导仍依赖核验材料，不凭动画补全个人预测。
- 可以有诗性和氛围，但要能回答“这一幕解释了什么”。象征流线标为意象；传统的“气”不能画成已经实测的物理流场，文化隐喻也不借量子或宇宙画面充当科学证明。

## 空间概念：风水与房间布局

- 先区分要讲的是位置关系、某一传统规则，还是实际采光、通风与使用动线。
- 不需要精确测量时做标明“示意”的平面图；方位、尺度未知时不自行认定。
- 同一空间可以有独立观察层：传统规则解释、开门/行走路径、实测光照等。没有测量就不显示“采光改善 30%”之类数值。
- 可以用前后对照、从入口行走的第一人称体验、全景与局部切换或可探索房间，让观众感知遮挡、距离和视线；只需一个关系时两张图即可，多种摆放才做拖动。
- 图层切换只改变观察方式，不应偷偷改变房间尺寸或物体位置。

## 宇宙题材：尺度、空间、时间与观察

先确定要讲的是尺度、运动、观测、历史演化还是思想实验，不直接套行星结构拆解。具体事实、图像和数值使用前核对可靠来源；此处仅提供表达路线。

| 学习问题 | 可选路线 | 画面需要交代 |
|---|---|---|
| 为什么尺度难以想象 | 从熟悉参照物逐级缩放、并置比较，再进入更大空间 | 当前尺度与参照物；对数缩放或示意切换明确标注，天体大小和间距是否同尺度 |
| 换个观察位置会怎样 | 同一场景切换观察者视角，保留定位小图或参照点 | 相机移动与对象自身运动分开，避免把视角变化误作真实运动 |
| 极长时间如何理解 | 时间旅程、阶段叠化、可拖动时间带 | 当前时代、时间压缩或非匀速播放；不让过渡特效伪装未经支持的演化过程 |
| 肉眼无法直接看到的现象怎样讲 | 观测材料与模型示意并置，按证据逐层解释 | 哪些是观测、理论模型、假设或艺术想象；伪彩色、不可见波段和模拟图注明性质 |
| 改变条件会发生什么 | 有依据的思想实验或参数对照，先展示条件再展示结果 | 模型假设、边界和参数来源；无计算依据时做定性说明，不生成假精确读数 |

宇宙感可由留白、远近层次、空间移动、稀疏参照物和节奏形成，不必黑底星空。沿用克莱因蓝与浅色背景；若提出局部深色空间或新风格，放入样图确认，不按题材自行覆盖已选配色。没有 3D 工具也可用分层 SVG、静态序列或多景别镜头表达，不强装物理引擎。

## 商业与社会概念：反馈循环

- 列出变量及箭头方向，并注明假设；反馈存在不等于必然持续增长。
- 用一次事件逐步高亮路径，展示中间条件；回路图配一个反例，说明何时不能闭合。
- 缺少参数时做定性解释，不用随意填入的数字生成似乎精确的增长预测。

## 工具变化时保持什么

从文字换成 Mermaid、SVG 或 HTML，保留原来的要素、关系方向、条件、规则来源和边界；只改变呈现方式。

例如交互网络变成纸面图：将“点选节点”改成几张局部关系图或图例；保留同样的解释。不要因为失去动画就删掉关键条件。

从纯文本迁移到能执行代码的工具时，先落实已有解释，再补运行验证。能够读取 Skill 文件仅说明能加载，不代表已在该模型上验证生成质量。
