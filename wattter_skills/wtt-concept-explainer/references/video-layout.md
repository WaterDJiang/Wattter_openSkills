# 视频图文排布：产品叙事

用于视频讲解与自动讲解网页。默认借鉴苹果产品发布及产品主页的图文层级：简短主张、大幅主体、充足留白，信息随讲述展开。它是内容排布方式，不限制概念题材、主体形式或渲染工具。用户指定其他视觉风格时沿用用户要求。

- 每镜先写一句要让观众看懂的主张，再安排主体和必要证据；一个镜头不同时承担完整流程、全部零件、参数表和结论。
- 主标题用短句，近黑/白字作主层级；默认克莱因蓝保留作当前语义焦点，避免全屏蓝字争抢注意。现有默认配色继续使用，采用黑底特写时明确背景及文字角色。
- 总览可采用上文下图；局部可采用侧文大图或全幅主体。按形状和动作选布局，不规定所有镜头左右分栏，不要求固定镜头数或黑白交替。
- 主体占据视觉重心，留白服务阅读与动作；允许裁掉非关键上下文，不裁掉本镜需要观察的通道、连接、运动终点与参照物。
- 默认取消系列页眉、页码、常驻流程卡、全部部件标签、底部大横条；确需定位时使用简短且低干扰的提示。来源和关键限定保留在相关镜头或可读说明中，不删除事实边界。
- 标注按语义逐个进入，解释结束后退出；标题、标签与旁白字幕不同时复述整句话。字幕区域与主体避让，字号与对比仍按[视频质量](video-quality.md)核验。
- 动作先定位、再变化、后停留；主体运动与镜头共同解释机制，不以静态图片慢推、标题渐入或无关粒子替代本应发生的机制动作。
- 预览实际首中尾与连续片段，并在目标最小播放宽度检查；图片方向认可不等于最终动画或三维模型已通过。

示例只说明排布：总览定位对象 → 局部展示当前变化 → 整体回应问题。传统体系、尺度、关系网络等题材继续沿用自身解释策略，不套用汽车或机械剖面。

## 机械、空间与路径类镜头

观众应一直知道“正在看整体的哪个位置、上一步怎样接到这里”。按需要组织定位、推近、动作、追踪和返回；不为每句旁白重新摆一组孤立部件，也不强制所有题材一镜到底。

| 镜头任务 | 具体决定 |
|---|---|
| 定位整体 | 先让观众认出主体、朝向和本段目标部位，再开始推近；保留车头、相邻零件或其他稳定参照。 |
| 连续推近 | 从同一主体的原位置推进相机/视窗，明确焦点与起止景别；平移、缩放和旋转保持连接可追踪，不任意翻转朝向或重排零件。二维图也可通过共用坐标的视窗实现，不为连续性强制三维。 |
| 看清动作 | 推近后留出辨认时间，再按语义开合、流动或受力；关键瞬间先稳住镜头，动作后保留观察终态的时间，避免高速推镜、全部标签进入和主要动作同时争抢注意。时长由动作与实际旁白决定。 |
| 沿连接接力 | 沿管路、传动杆、信号路径或其他真实关系移动到下一焦点；连线和标记共用主体投影，在转折处仍能看出起终点。需要回答整体结果时再退回全景。 |
| 弱化外围 | 可淡化外壳、背部零件及非重点结构，保留必要邻近轮廓；淡化后的多层表面仍要检查遮挡，不能留下大块灰影抢占焦点。剖切或拆解改变结构呈现时交代对应位置。 |
| 放大与文字避让 | 沿推进全程检查主体、标签、字幕及视窗边界；文字需要净空时先调整相机落点或文字位置，必要时对外围加稳定遮罩。遮罩不能遮掉当前关键连接，局部画布边缘不能形成突兀矩形切口，路径标记不能漂到模型视窗之外。 |
| 解释性切镜 | 旁白分句不自动切画面。确需独立剖面、换观察方向或不同时间状态时，先定位对应部位，再切换并保留参照。暂停、慢放或内部过程回看要注明教学含义，不能把冻结状态当作真实平衡。 |

把焦点目标、保留参照、推进路径、动作与停留、下一焦点及避让区写入现有`storyboard.md`，不另建一份镜头清单。标题切换先退出再进入，避免在同一位置交叉叠字；说明标签按当前语义显隐，端点随主体变换。

实现时让相机/视窗轨迹读取整段绝对帧号，跨配音句段继续推进，不重置模型位置或比例。独立部件图的交叉溶解只是一种转场，不能称为同一主体的连续推近。可结合场景尺度检查相邻帧变化，阈值由本片的画幅、尺度和预期速度决定，不把某个样例的世界坐标阈值复制到所有题材。

检查整机、推进中、局部和交接处的实际画面与连续片段；既看目标部件，也看定位参照、标签和文字净空。长推进超出工具默认动作窗口时补充覆盖完整轨迹的证据，具体见[视频质量](video-quality.md)。
