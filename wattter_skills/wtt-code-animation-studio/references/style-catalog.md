# 可组合的视觉风格目录

用途：编剧后形成风格候选，以及用户选择后的逐镜实现。先读 [选择流程](style-selection.md)。这里列的是可供 agent 设计与实现的视觉配方，**不是全部预装完成的渲染器**。每种风格都能承载角色、风景、文字或图解，主体与风格独立。

## 如何用目录

- 从剧本的关键动作、信息密度、情绪与受众出发挑选，不用网络热度代替适用性。先尊重用户提供的风格约束。
- 下列 ID 仅用于候选方案和选择记录；不是可直接写入起步模板 `visual.style` 的完整枚举。当前模板只实作 `flat/sand/particles`；新增风格要写对应场景代码后验证。
- 默认给用户 1 个推荐方向 + 2 个有实际差别的备选。每个方向可以是“主风格 + 辅助表现形式”，不要把整张目录当作必答问卷。
- 候选须有可执行路径。额外依赖与明显成本变化简短说明；当前环境无法完成的方向不伪装成可立即交付的选项。不要要求用户选择 Canvas/p5.js 等内部技术名。

## 十种视觉风格

| ID / 风格 | 视觉特征 | 适用的内容线索 | 主要风险与当前边界 |
|---|---|---|---|
| flat / 扁平插画 | 清晰轮廓、有限配色、简洁明暗 | 产品流程、动作教学、需快速辨认关系 | 容易变成图标幻灯片；模板有基础实现，具体内容仍须重画 |
| ink-paper / 手绘墨线与纸纹 | 不完全规整的线、排线、纸张颗粒 | 人物小故事、生活体验、需要亲近感的讲解 | 线条抖动不能破坏轮廓；需按片实现 |
| riso-halftone / 复古印刷与网点 | 少量色版叠印、半色调、轻微套色偏移 | 旅行、城市、回忆、编辑式叙事 | 网点在视频压缩后易闪烁；不是精确复刻实体印刷机，需按片实现 |
| pixel / 复古像素 | 有限调色板、清晰方格、离散姿态 | 游戏感故事、探索、规则与状态变化 | 小字和复杂表情受限，需按片实现 |
| watercolor-brush / 水彩与颜料笔触 | 透明叠色、纸纹、柔软边缘、可见笔触 | 自然、诗歌、温柔叙事、绘画感音乐片 | 逐帧随机铺色易闪烁；高质量笔触可能较慢，需按片实现 |
| sand / 沙画 | 沙粒密度、明暗轮廓、擦除与显露 | 渐变、消逝、历史与记忆，或用户指定沙画 | 不等于黄底加随机点；模板有基础沙粒角色，复杂场景仍须实现 |
| chalk / 黑板粉笔 | 深色板面、粉状断续线、擦拭痕迹 | 教学推演、简单角色动作、一步步解释 | 细线、公式和小字易糊，需按片实现 |
| particles / 粒子构成 | 点集构成主体，可汇聚、散开或流动 | 从分散到整体、连接、转变等可视动作 | 不是满屏星点替代主体；模板有点集角色与聚合效果 |
| glass-mosaic / 玻璃与金箔马赛克 | 固定拼片、接缝、有限高光、局部反射感 | 重组、修复、多部分构成整体、装饰性叙事 | 光泽不能遮盖信息；2D 近似与真实折射分开说明，需按片实现 |
| clay-stopmotion / 黏土定格外观 | 圆润体块、哑光表面、手塑痕迹、定格节奏 | 触感强的小故事、玩具角色、机械/生物拟物演示 | 区分 2D 黏土感、WebGL 三维和 Blender 制作；当前没有现成黏土后端 |

## 两种可叠加的表现形式

**motion-graphics / MG 动效**：几何、动态文字、图表和符号随信息推进，可叠加扁平、印刷或其他风格。用于产品介绍、机制说明、数据关系；不能把“所有文字飞入”当作解释。人物也能作为贯穿线索，不与角色动画对立。

**mixed-worlds / 同一主体跨画风**：为明确的章节、处境或情绪变化切换视觉风格。先让用户选择主风格、允许的辅助风格和切换目的；保留角色身份和动作连续性。不是每个镜头随机挑一个标签，也不强迫所有短片混搭。

## 配方与可见验收

### 手绘墨线与纸纹

- 以共享角色轮廓/骨架生成线稿；线宽和排线疏密跟随形体。纸纹固定到画布，线条轻微变化由 seed 和离散时间索引决定。
- 可使用 Canvas 路径与预生成纹理，或按需采用 p5.js 绘图。不要每帧重新随机画一张脸。
- 代表镜头：角色举起一封信，线条和纸纹保留，手与信的位置随动作变化。
- 检查：肢体比例连续；纸纹不抢字幕；静止段不无故闪动。

### 复古印刷与网点

- 主体先形成色块和明暗层，再以固定网格/点阵或排线表示色阶；少量色版采用一致叠色关系与稳定的偏移。
- 网点作为材质跟随对象或明确锁在画布，不任意漂移。先用小样检查编码后的摩尔纹；必要时增大颗粒、降低对比或调整采样尺寸。
- 代表镜头：车厢内部保持稳定，窗外景物分层移动，叠色和网点随同一光照逻辑变化。
- 检查：网点不闪烁，前后景可辨；不要仅盖一层噪声就称完成印刷风。

### 复古像素

- 在低分辨率离屏画布绘制，再按整数倍放大并禁用平滑；角色姿态和物体位置量化到像素网格。
- 导出帧率与风格节奏分开：允许姿态按较低频率更新，但不能用无意义停帧拖长片子。字幕可在主画布清晰排版。
- 代表镜头：旅人跨过三块踏石，身体、脚和落地位置有可辨识的像素姿态。
- 检查：不同物体像素尺寸一致；角色不会半像素抖动；字幕不被低分辨率毁坏。

### 水彩与颜料笔触

- 主体遮罩控制透明色层与笔触区域，边缘变化固定到局部几何；预计算纸纹、笔刷片与颜料纹理。
- Canvas 可先做有限色层与柔边；需要复杂笔触时再研究 p5.brush 等库的当前文档、许可和实际性能。不以添加库名代替风格实现。
- 代表镜头：同一人物走过树影，衣服与背景各保留自己的色层，动作由角色几何驱动。
- 检查：角色面部和关键道具清楚，色层不每帧重随机；先测代表镜头再估全片成本。

### 沙画

- 从主体几何生成离屏遮罩，用固定位置、大小、亮度的沙粒铺出形体；密度与明暗分层。
- 动作改变主体几何或变换，沙粒跟随；擦除/显露是可选效果，沙画角色也能整镜保持完整并行走或跳跃。
- 代表镜头：一个沙画角色伸手，手上的沙逐渐聚成一棵树，而人物身份保持一致。
- 检查：轮廓可读；无随机噪声闪烁；不能只画沙地，角色却始终是普通实心图形。

### 黑板粉笔

- 用断续但可读的多层描边与固定粉末纹理构造线条；板面和擦除残迹独立缓存。
- 路径可随解释逐段显露，也可作为完整角色随动作变形。复杂公式优先保证字形和笔画间距。
- 代表镜头：粉笔人物推动杠杆，支点与力臂标记跟随真实的画面关系出现。
- 检查：暗底亮线对比足够；擦拭不抹掉需要保留的内容；线条在最终视频尺寸下清楚。

### 粒子构成

- 从主体轮廓/内部采样稳定点集；粒子身份与目标点固定，动作与聚散进度分别计算。
- 代表镜头：同一角色先保持粒子身体行动，再散开并重组成同一角色。只在剧情需要时使用聚散。
- 检查：身体和表情仍可识别；密度不遮挡文字；切换风格不改变身份。实现公式见 [画法选型](visual-recipes.md)。

### 玻璃与金箔马赛克

- 将主体分为固定多边形拼片，维护拼片 ID、位置和邻接关系；接缝、亮暗、有限高光形成材质感。
- 可用 Canvas/SVG 做平面拼片与模拟光泽；明确需要空间翻转、深度遮挡或折射时，再评估 WebGL 路线。
- 代表镜头：一只鸟由碎片拼合，展开翅膀后各片仍属于相同形体。
- 检查：拼片不是逐帧重分割；高光不淹没主体；平面近似不称为真实玻璃物理。

### 黏土定格外观

- 用户选择时说明拟用哪一级：2D 哑光体块近似、前端三维黏土感，或真正 Blender 工作流。仅外观相似不代表使用了实体定格制作。
- 2D 可用圆润几何、有限阴影和固定表面纹理；三维需建模/材质/灯光与帧驱动。动作采用少量清晰姿态及有目的的停顿，不能只降低帧率。
- 代表镜头：玩偶把一块黏土捏成小桥，体块变化和接触动作可见。
- 检查：重量感和接触点成立，纹理跟随表面。Blender 不在当前浏览器导出管线内；如用户要该路线，明确工具切换并另行验证，不能偷偷改成 2D。

### 扁平插画与 MG

- 用清楚的形状层级、留白与有限颜色承载信息。MG 将数值、连线和形变绑定到内容因果，文字与图形同一时间轴。
- 代表镜头：角色提交一个请求，节点依次处理、分流并显示结果；观众能从运动理解流程。
- 检查：一镜一个主要新信息；不要只是字幕配装饰；小屏也能分清标签与对象。

## 实现状态与来源边界

已有工程验证覆盖扁平/沙画/粒子示例及其动作组合；本目录的其他方向是指导 agent 按本片实现的配方，没有逐风格真实成片验证。推荐时按这一边界说明，不能把外部热门案例当成本 Skill 的已交付效果。

可供后续研究的作者公开项目：[ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase)、[riso-windowseat](https://github.com/sevenevesai/riso-windowseat)。使用其代码或资产前实际检查许可、依赖与运行行为；本目录不要求安装或复制它们。热度数字会过期，不写入执行规则。
