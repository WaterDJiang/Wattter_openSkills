# 卡片文件与交接契约

## 文件按使用对象汇总

每个角色、场景、视频片段各一张卡，全片共用一份总索引。选用了故事关键帧时另交一张全片关键帧卡。**独立生成任务不等于独立MD。** 同一对象的角度、细节、状态和声音放在卡内，不因多一次生图/配音任务就增加文件。

卡片主体只放短小节标题和提示词/采集指令；片段卡开头增加精简“参考对应”，就地解释本段人物、场景、画面及输入用法。允许 `## 基础形象`、`## 多角度身份板`、`## 首帧`、`## 视频` 等复制边界，不加长介绍、元数据、来源、状态表、检查清单或重复说明。用户复制所需小节正文，不把整张多任务卡一次提交。每块给足生成必要信息，不写“同上/见前文”让用户拼接；执行所需参考媒体与槽位由索引维护，片段卡同步本段必要对应，不要求用户仅凭编号猜用法。

**一张卡不是一张拼图，也不是一次生成请求。** 角色单图和多角度板各执行一次，板内各角度共用一张图。每个角色仍独立成卡，不将全片所有角色合成一份大文档。

## 默认目录与命名

```text
03_制作/
  00_制作索引.md
  关键帧卡.md（全片有选用的F时）
  角色卡/
    C01_角色A_角色卡.md
    C02_角色B_角色卡.md
  场景卡/
    L01_书店_场景卡.md
  片段卡/
    G01_发现信_片段卡.md
    G02_询问_片段卡.md
  共用素材卡.md（确有无法归入上述卡的共用内容时才建）
  媒体/（真实生成或用户提供后才放入文件）
```

人名和剧情仅示例。命名沿用作品目录要求，如 `YYYYMMDD_C01_角色A_角色卡.md`；无日期要求不强加日期。保留既有C/L/P/A/F/S/G编号：C/L通常对应卡文件，P/A/F及派生编号可对应卡内小节，S是成片镜号，G是制作/生成段。ID数量不决定MD数量，不为每个ID建文件或空目录。

片段是可独立制作使用的一段视频，通常一张卡对应一个G。用户已经命名的片段可沿用其文件名，索引登记G，不强制重新编号。默认文件数约为 `1＋角色数＋场景数＋片段数`，按需加一张全片关键帧卡及一张共用素材卡；这不是媒体数量或固定文件上限，不为压数量删内容或改切镜。

## 最小图片清单

- **角色**：完整制作每角色只交一张个人基准图、一张基于它的多角度板。六宫格或九宫格都算一张。需要侧脸时复用板内视图；走动、转身、表情和换装过程写入视频。已采用图可抵相应项。
- **场景**：以同一物理空间为单位，第一张环境图定布局、地标和光源；从它直接派生镜头必需的不同视角，最多三张。底图也能当机位图。一场合计最多四张环境图，跨段共享；日夜、裁切和段号都不另起额度。若有五个以上拍摄机位，优先保留会露出新空间、改变遮挡或方向的视角，其余机位照分镜写入视频，照样保留切点。
- **道具**：桌椅、箱子、常规衣饰和持物直接进入人物、场景或视频描述。只有外形或标记必须被观众认出、对剧情有决定作用且现有参考看不清时，才安排道具图；优先放所属卡的小节，确需独立调用才单列物品卡。
- **关键帧**：只在换场或明显换机位时评估。若人物图和场景图已经足够，直接用于视频；需要额外明确新视角的构图时，才合成一张F。F属于人物与环境同框的故事参考，环境图的四张上限按L计。同一机位的连续动作留在一个视频块，可全段零F。

## 各类卡片放什么

| 卡片 | 按需收录的提示词块 | 归属边界 |
| --- | --- | --- |
| 角色卡 | BASE个人单图、BOARD多角度板；按需附音色文字 | 完整制作主要角色默认准备身份板；明确简化或已有合格素材可省新制，所有派生留同卡 |
| 场景卡 | BASE核心底图与固定空间锚点、正反打/实际机位、日夜变化、固定陈设与道具、环境底噪 | 最多三个不同角度，各自直接引用第一张底图；所需机位与BASE相同可直接复用，不合成一张多机位输入图 |
| 关键帧卡 | 每个选定的F一个短标题；新制放静帧提示词，复用/抽帧放来源或采集指令 | 全片共用，每个F只写一次 |
| 片段卡 | 本段参考对应、完整视频提示词、本段独立配音/音效、只在本段用的道具/界面/字幕卡 | 同期对白和声音直接写视频提示词；只有另行配音/制图才补独立块，避免同一任务重复两次 |

特殊道具按上面的最小清单处理。全片配乐、共用品牌/界面等按需归入 `共用素材卡.md`。

角色固定音色只在角色卡维护其规范；执行配音/视频的小节仍给足该任务所需音色特征，索引关联规范版本，变更时标相关块待复核。不要把一次情绪表演变成永久音色设定。

卡内保持 `## 基准形象`、`## 多角度身份板`、`## 核心底图`、`## K1 机位` 等短标题；具体派生提示词直接写参考图和不变量，模板见[基准与派生顺序](prompts.md#基准与派生顺序)。不要为BASE、BOARD再建新MD。索引记录 `派生ID→根BASE/直接参考及采用版本→卡内小节→实际媒体`，明确新制、复用或待就绪；片段卡只摘录本段需要的具体视图。

新制BOARD在一个身份板小节内要求一张固定六宫格或九宫格图片，默认六宫格；逐格内容及布局约束见[身份板模板](prompts.md#人物基准与身份板)。不把六格拆成六个MD或六个独立出图任务，也不把整张角色卡所有任务并入身份板。需单视角输入时选用或裁取板内合格视图。

## 片段、镜头与执行块

划分生成段G时，把相邻两段接着读一遍。同一场景、机位连续，后一个动作直接回应前一个动作，就合成一条能看到结果的视频提示词。一次抬手、一次停顿、一次表情变化都可以写在句内。约10秒用于估算这场表演需要多久；短戏在落点结束，能一次生成的12秒连续戏保留整段。

换地点或跳时、行动转入独立事件、明显换机位且要重新建立空间时，再选分界。例如柜台前递信、接稳、松手可以连拍；跳到次日在车站拆信，可从车站另起一段。既定的正反打若在同一场对话里且模式可一次完成，切点写在同一条词内。用户指定的段界优先沿用。

- **一镜一段**：一张片段卡，索引映射S01→G01→卡内“视频”块。
- **多镜一段**：只建一张G片段卡，视频提示词写清各镜切点、动作和声音；各S在索引映射到此块，不另建S设计提示词文件。
- 最终视频块先写共用设定与实际参考用途，再按S时间顺序将画面、动作、对白/声音及切点写在一起，末尾仅保留必要连续性约束；单镜写一条连续时间线。七项信息是内部检查，不再另交七段式版本。一个块内可用短段落标签，复制范围仍是整个“视频”小节。
- **一镜多段**：连续镜头超过已核实的单次时长上限或用户指定分段时，在动作交接、对白落句等自然位置拆请求。索引沿用原S，记录各G的覆盖与接点；下一条词从上一段留下的站位、持物、动作方向及仍在延续的声音接起。
- **用户已定长片段拆成多个请求**：保留一张用户片段卡，在卡内用 `## G01 视频`、`## G02 视频` 等分块；索引逐G链接具体块和输入，避免文件再次碎片化。
- 每个视频执行请求只有一个权威提示词块；索引明确哪些块用于生图、视频、配音或采集。以“卡路径＋小节”为执行入口，不能把整卡、原S设计和G任务重复提交。
- 提示词内写总时长、完整原句、必要声音和硬同步点。单镜动作按先后连写，多镜另标各镜区间与既定切点。场记坐标、后期轨号、成片与裁剪映射及实际采用信息放索引。未知通道能力在索引待核。
- 索引的S/G映射同时注明同镜续接、切镜或时空转换；移动镜头简记相机起止与接点运动状态。此设计由导演提供，独立接手时制作补齐；不增加独立运镜卡或逐帧MD。卡内相机与主体的完整时间线放视频块，静帧只呈现对应瞬间。
- 用户原分镜单元内有切镜时，保留“原单元→实际S及时间→所属G”映射，不丢原名与原单元总时长；每张预演图注明控制哪个S、哪种信息，不将一个单元的参考图自动当作所有内含镜头的端点。多镜拆请求时仍沿用用户片段卡并分G小节，未拆时不额外重复逐S请求。

## 全片关键帧卡

从镜头表指出具体的换场或明显机位变化，以及换过去必须看清的空间关系。对白、走位、接触、表情和同轴小幅推近都由视频表现。仅切段时可复用前段实际剪点作输入；若模式要求端点，优先使用已有图或抽帧，缺少合适输入就选能用角色与环境参考的模式，或标明该模式待就绪。没有选定F就省略整张卡。

先对照已有图，同一瞬间同一构图复用同一F；同镜接力可取上一段实际采用剪点的帧。其余才新制。在 `关键帧卡.md` 按叙事顺序写 `## F编号 画面名称`。新制小节只有可复制的静帧词，点名身份根图、当前机位、适用的已采用前图及各自作用，写出这一次保留和变化的可见状态。复用小节链接采用图，抽帧小节写源G和剪点条件。多个G同用一幅画时只链接同一小节。

### 图与图的依赖

在总索引按生成顺序登记。角色身份板指向该角色的采用基准，写明允许变化；场景机位图指向该场景的采用底图，写明新机位与固定地标。第一张同框F用相应角色版本与目标机位建立站位；后续F再指出直接承接哪一张采用图或哪个实际剪点。来源写到卡内小节；有实图时补媒体、版本，抽帧补源段与时间码。已有基准直接映射。

每个F用一行：`F与G/S时点｜参考来源和职责（区分上传、仅核对）｜承接的状态 → 剧情允许的变化｜新制/复用/抽帧及采用版本`。只填影响画面的关系。例如“猫仍以左后脚撑在西墙前；鼠由腹部受力变为落入原箱，箱壁鼓开”。同一物件有多张图时，分别指定哪张定**位置**、哪张定**此刻状态**；引用空景只取布局，不能把已打开的门或已鼓起的箱子还原。

- **同一机位**：时刻与构图也相同就复用同一图。姿势或道具状态变化写在视频的动作时间线；跨请求需要接力时取已采用剪点。基础定妆姿势不作为新的剧情起点。
- **换机位或切特写**：同一时刻仅收窄取景且像素够用时可裁切。真实换机位按目标机位图重新构图，前图只给人物与地标的关系、持物手和动作相位。人走过或相机绕过才改变相应关系；画面左右可随视角改变。
- **隔镜回场**：为暂时出画的人或物找最近能看清它的已采用画面。中间有剧情变化时以分镜补上变化；没有变化则沿用上次状态。跨场只继承剧情带过去的人物、服装或持物，新场地使用自己的空间基准。
- **前置未就绪或互相冲突**：文字包可列计划依赖。需要上段剪点先做源段；没有实际图时不得假称已绑定，也不能让G依赖从自身待生成视频截取的F。若两张采用图对同一时刻、同一属性说法矛盾，先修正来源或选定有效版本，再生成受影响的图。替换上游图后沿实际引用关系复核后续F和G。

## 片段卡的参考对应

按本段输入顺序逐图链接到关键帧卡的 F 小节或既有参考资产；有采用图片时给出媒体入口。视频只写图的作用、对应时点和图间动作。没有选用F时，参考对应只列实际需要的角色/空间等输入，纯文本模式直接写视频。

全能参考模式按实际拖入顺序列图，每项写“拖入序号｜F或已有预演图及入口｜S/剧情时点｜可见状态”。一张片段卡可容纳多个镜头和多张关键画面。身份、空间等辅助参考若也要上传，列明用途及实际序号。总索引记录G总时长和唯一视频块。

每张片段卡开头用简短列表写本段实际用到的 `ID = 名称/具体状态 — 用途`，链接到角色/场景卡的具体小节；已有采用媒体时附实际图片入口，尚无媒体不造路径。本段有多机位/服装时明确所选版本，不能只写“用L01”。管理状态仍留在索引，参考对应不复制审核或费用表。

按实际内容组织，例如：

- `C01 = 林禾；身份根图C01_BASE，多角度参考C01_BOARD`，链接角色卡对应小节；注明本段采用BASE、BOARD还是已核对的单视角。
- `C02 = 陈叔；身份根图C02_BASE，多角度参考C02_BOARD`，同样明确本段采用视图。
- `L01_K1 = 基于L01_BASE的旧书店柜台南侧朝北机位`，作为空间与光线参考；若直接复用BASE须说明，不另作一次请求。
- `F01 = C01在左、C02在右，置于L01_K1，信封P01平放台面`，如已有合格同框图，可直接采用作首画面。
- `F02 = 同一构图，C01举起信封`，可从前段采用剪点取得；后一段首帧复用时直接链接该小节/采用图，不复制提示词。

上述等式表示身份或构图关系，不是自动图片合成公式。必须区分两步：**制作F画面时**，采用C人物图、L具体机位图及必要P道具参考，按F提示词生成完整画面；**制作视频时**，按已选模式使用F首帧/尾帧或C/L等参考，并复制视频块。角色/场景MD是说明与提示词，上传给生成器的是实际采用媒体，不能上传MD代替图片。

参考对应末尾写本段简短用法：首帧模式只绑定采用首帧，尾态以文字描述；支持且选用双端模式才绑定首帧和尾帧；多参考模式按通道支持绑定人物/场景等且注明职责，不将它们冒充端点槽。能力未定时把路线标为拟用，实际准备状态以索引为准，不把所有参考无差别重复上传。

参考对应把人物、场景与C/L/F编号写清。复制正文用角色名或绑定的图号指代；无图时写足辨识特征和空间，有图时只补参考未展示或必须锁定的特征。F块说明具体人物参考与场景参考；视频块说明首末画面与其作用。平台不识别C/F内部编号，只有真实附件绑定后才能换成该工具实际支持的标签（例如某工具的图片标签）；未绑定时不凭空写“@图片1=C01”。

参考对应是总索引的本段摘要，索引仍是版本/媒体/槽位依据；ID、采用媒体或共享关系变化时两处联动更新。一个F仍只有一处权威提示词，卡内重复链接不等于重复生成任务。

## 首尾用途与独立画面

首帧/尾帧是用途，不是必须单建文件的类型。需要新制的画面放全片关键帧卡小节，每小节只描述一个瞬间；完整运动在视频块。实拍/录屏只需起止状态说明时写入拍摄指令，不默认创建首尾生图任务。

| 衔接条件 | 处理 |
| --- | --- |
| 同一时刻、接点构图/相机姿态、人物道具和光色一致 | 可共用画面；移动镜头按实际接点姿态核对，不要求全段固定机位 |
| 只延续动作，但换机位、景别或跳时空 | 按新视角写接点与画外状态；确需锁定构图时才选F |
| 静态卡面持续展示 | 首尾共用同一画面小节 |
| 静帧匹配但运动/声音未查 | 仅画面可共享，不承诺视频无缝 |

已有端点或采用剪点的共享例：G01为F01→F02、G02为F02→F03。F02只在全片关键帧卡写一次，两个G的参考对应都链接此处。在总索引将G01尾帧、G02首帧都链接到同一小节及同一采用媒体。视频块仍完整描述各段起始状态，不能只写“接上一段”。

索引按需列：`S/G｜首/尾用途｜F ID｜所属卡片#小节｜新制/复用/抽帧｜采用媒体与版本｜槽位`。所有F均有唯一归属；不同状态或需同时采用不同版本时另用F ID，但可放同卡不同小节。仅文字相似不能证明实际媒体可共用。抽帧接力的剪点、来源及下游复核按[执行规则](execution.md#连续段抽帧接力)处理。

## 总索引与兼容

`00_制作索引.md`是默认总说明文件，按需组织，短任务不强制填满表格：

- **怎么用**：路线、共用画幅/风格、制作先后；打开哪张卡、复制哪个小节、上传哪些媒体。说明按块执行，不能整卡一次提交。
- **卡片目录与资产映射**：每张卡的入口、C/L/P/A/F等ID到小节、基础依赖和参考职责；相对链接含有效小节锚点，标题唯一、简短、稳定。可用 `## F02 双掌悬停` 作为精确定位标题。
- **片段执行表**：S/G关系、视频请求唯一入口、首尾共享、附件/槽位与准备状态、素材/成片/保留区间。未绑定和缺件如实写明。
- **版本与检查**：源设计版本、根BASE/BOARD/机位采用关系、卡及被采用小节/媒体版本、实际检查结果/未检项、用户采用依据；共用状态写一次，逐项只写差异。根图变化标关联派生、F及S/G待复核；局部块变化只标相关依赖，不因同卡重做全部内容。
- **剪辑交接**：顺序、实际或计划保留区间、对白/字幕原文、声画衔接、配乐、缺件与问题。无媒体时称文字交接计划。

索引不复述全部提示词。默认不另建90/91/99说明MD；执行账目/校验摘要放索引，原始日志可作附件链接，未执行不造空账本。单独报告或某块单独导出仅按明确要求处理。

已有分散在G卡内的F仍可按旧索引使用。要求迁移时另存新版本，把仍采用的F汇入关键帧卡，更新索引、片段链接与图序；退出用图的节拍保留在视频动作中。迁移其余旧分项时，将旧分项提示词按归属收进卡片，以索引记录 `旧ID/旧路径→新卡#小节`；原来源、状态、媒体与检查信息搬入索引，旧文件保留。已有F/S/G编号和日期前缀不重排；旧每镜设计保留在导演材料/历史中，不能作为重复执行请求。

交付检查：卡片粒度符合角色/场景/片段→各块可单独复制且内容完整→片段参考对应与索引一致、C/L/F关系明确→索引覆盖所有卡、ID和执行块→相对链接及锚点有效→共享F/视频请求只有一处权威入口→原句、时间和空间一致→媒体及状态有依据。不要通过合并文件掩盖原有内容丢失，也不要为了减少MD擅自把多次生成拼成一次请求。
