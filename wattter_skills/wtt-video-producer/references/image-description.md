# 图片资产的视觉描述

先说清这一张图必须让人认出什么。若“精致”“温暖”“有压迫感”仍有多种画法，就把它换成能在成图上指出来的特征。已有基准图能说明的造型、色调和布景用参考指代。下面按实际难题选词，选中的词直接写成一句生成指令。

| 要控制什么 | 可选术语 | 可以直接写进提示词的具体关系 |
| --- | --- | --- |
| 认出人物，分清朝向 | 正面平视、正侧面、四分之三侧面 | “脸略转向画面左侧，近侧面颊完整，远侧脸缘仍可见。”单侧发缝、痣或耳饰用角色自身左右定位；角度遮住标记时允许不可见。 |
| 看清台面和手的位置 | 高角度俯拍、垂直俯视 | “从柜台南侧斜俯拍，能看见信封正面和柜台前沿。”若要像平面摆位图一样读出物件间距，再选正上方垂直俯视。 |
| 让观众知道东西多大 | 同框尺度参照、微距、局部特写 | “信封横放在陈叔胸前，宽约二十厘米，右手捏住右端。”要看纸纤维才用微距；要核人和道具的大小关系，保留双方轮廓。 |
| 看清接触，或隔开杂乱背景 | 浅景深、焦点、前景遮挡 | “焦点落在指腹和封口的接触处，后排书脊略虚。”若前景的猫和后景的箱口都承担剧情，改写“两处轮廓都清楚”。二维平涂可用轮廓分离、色块明暗完成同一目的。 |
| 让空间与留白有方向 | 前中后景、消失点、负空间（留白） | “书架在柜台之后，通道向左侧门口收拢，柜台中央留空。”换机位时按新视角判断消失点；固定机位的日夜对照才沿用同一透视。 |
| 说明光让什么显形 | 漫射光、侧光、软阴影、掠射光 | “西窗漫射光落在桌面左端，台灯底座旁的阴影边缘渐淡。”若是为了看凹凸，可写“低角度侧光掠过纸面，凸起折痕的一侧留下一线细影”。 |
| 让材料一眼可辨 | 哑光、镜面高光、纤维纹理、半透明 | “浅米色纸面哑光，封口边缘一条薄影显出两层纸。”玻璃侧重透出后方颜色与亮边，金属写反光落在哪里。只选材料和景别实际允许看见的现象。 |
| 明确色彩或画法 | 低饱和、冷暖对照、墨线、网点、宣纸留白 | “蓝灰墙面衬住暖奶油色的猫，浅灰鼠腹与深色前臂分开。”需要水墨时再用“淡墨舟影，水面留纸白”；已有平涂造型时沿用其画法。 |
| 看清道具形体和装配 | 正视图、等轴测视图、爆炸图 | “正视展示封口轮廓”；“从斜上方看盒盖，同时看见顶面和两个侧面”。只有任务要交代零件关系时，才指明沿哪条装配轴依次拉开哪些部件。 |

**人物使用有正反面的物品时**，先摆人和物，再放相机。物品写到具体的一面，如显示面、书页或手机背壳。人物的身体朝向、眼睛看的目标可以不同。最后写这个瞬间镜头看到哪一面、哪一处被挡住。只在朝向有歧义时补这些细节。

同一张书桌可以这样选图：

- 看男孩的表情：“男孩坐在桌前，显示面正对他。相机在显示器背后偏侧平视，机壳背板占画面左前景，男孩的双眼从机壳右缘外露出，视线落向显示面，嘴角扬起。”
- 看电脑上的内容：“相机从男孩右肩后方朝桌面拍，右肩和耳机边缘在右前景，屏幕发光面在前方清晰可见。男孩面向屏幕，头部略偏向屏幕中央。”

实图核对时，从人物眼睛沿视线找目标，再从机位看物品可见面。已采用参考若把屏幕翻向观众，只取它的造型或光色。需作首帧时先纠正朝向或换一张正确的图。

**一项设定，按资产用途改变写法。** 角色全身图里的棉衬衫靠外轮廓、颜色、垂坠的袖管识别。拍袖口特写时，裁到右前臂与指尖，可再写袖口折痕随手腕弯曲。拍递信关键帧时，观看重点移到手指、纸边和接收者；衬衫直接沿用角色图。若导演已定机位或风格，在这个约束内找可见线索。
