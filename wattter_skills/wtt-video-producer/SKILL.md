# 制作

把导演设计变成可直接使用的资产与视频指令。**每个角色一张卡、每个场景一张卡、每个视频片段一张卡。需交接的关键帧集中在全片一张卡。卡内用短标题分隔完整提示词，总索引集中说明用法。** 每个镜头的提示词和所需资产在索引中对应，总索引不能替代分项提示词。

## 先识别交付

- **制作包/资产提示词/视频提示词**：默认交文字文件，实际素材标已有或待生成；不自动出图、配音、生成视频或消费额度。
- **明确要求实际生成素材**：调用可用工具，将真实文件、任务、版本和检查结果补入总索引；卡内保留提示词、短标题和本段参考对应，不把提示词完成报为素材完成。
- 可直接接手外部剧本、分镜或单镜要求；缺设计时补本次必要站位、动作、声音与时长，不要求用户先运行编剧/导演或安装其他 skill。
- 继承已定原句、角色特征、风格、镜头数/连续要求、硬时限。缺工具/图只阻塞相应生成，文字包可继续。
- 写文件必读[卡片文件与交接契约](references/package.md)，写提示词读[资产与视频模板](references/prompts.md)；实际生成/审片时才读[执行与检查](references/execution.md)。

## 交付结构

在用户指定作品目录下创建 `03_制作/`；未指定时沿用当前作品目录，不能把作品写进安装 skill。没有作品目录就建本次题材命名目录，保留用户已有文件。

| 卡片 | 汇总内容 |
| --- | --- |
| 角色卡 | 每角色一份MD，一张个人基础形象图，按需附一张多角度身份板及固定音色文字 |
| 场景卡 | 每场景一份MD，按需引用场景平面图和机位图。一张环境底图，按需从它直接派生最多三个不同机位，合计1—4张；普通陈设写入场景 |
| 关键帧卡（按需） | 全片一份，按故事顺序收录选定的F；每张新图只有一个可复制的生图小节 |
| 片段卡 | 每制作片段一份MD，汇总参考对应、视频、本段独立对白/音效及局部道具界面提示词 |
| 共用素材卡（按需） | 无法归入已有卡的跨片段道具、音乐、品牌等汇总一份；已有归属直接复用 |
| 说明与交接 | 统一放00_制作索引.md；实际执行才补生成记录，不默认另建说明/报告MD |

无实际需要的类型不创建空目录或空块。角色之间、场景之间、片段之间分别成卡；同一对象的细节不再拆文件。一张卡可含多次生成任务，按小节复制，不强迫合成一张拼图或一次请求。用户已有片段划分优先沿用，拆合段按契约处理。

## 制作顺序

- 先读取有效分镜/声音/资产需求，分配或沿用稳定ID，先通读全片接点，从零张新图开始判断哪些构图确需锁定。按[最小图片清单](references/package.md#最小图片清单)先落实每位出镜角色的基础形象图和每个实际场景的场景图，缺图列对应生图小节。每处新场景用自己的图，同一场景的镜头按需复用。其他图片按需选用，动作与变化写入视频。
- 同场同机位能拍完的一次连续行动，用一个G、一条视频提示词写到结果。约10秒用于估算表演时长，具体收在戏的落点。拆合条件见[片段卡规则](references/package.md#片段、镜头与执行块)。按既定切点叙述动作，参考素材的用途和顺序记在片段卡的参考对应。
- 逐镜找出观众此刻需要理解的内容，把剧本和分镜中承载它的细节写进提示词。动作、静止状态、构图、光线、声音或停顿都可承担表达，选用与这一镜有关的即可。写法见[把表达意图落到画面和声音](references/prompts.md#把表达意图落到画面和声音)。
- 先对齐机位与主体起止、运动路径/节奏及接法，再写图与视频提示词。静帧取景必须容纳动作，视频按同一时间线推进；同镜续接沿用S并区分G，切到新机位写清新视角下的站位和动作相位。缺设计时补在索引，不用华丽运镜词掩盖空间冲突。
- 写图片资产时按[生图模板与书店示例](references/prompts.md#人物基准与身份板)逐块确定构图。角色只描述取景内的身份特征；场景用可见地标、遮挡、留空和光向交代空间。派生图依[图与图的依赖](references/package.md#图与图的依赖)选用身份、机位和动作状态来源；索引明确承接关系，正文只写会影响这张图的保留项和变化。
- 完整制作按需为主要角色补一张六宫格身份板，需要额外表演视图时用九宫格；提示词写清行列和逐格内容。已有合格角色单图、身份板和场景图直接复用。基准派生链见[参考图与派生模板](references/prompts.md#基准与派生顺序)。
- 在所属卡内写完整提示词块，只加短小节标题；不加元信息、代码围栏或检查说明，不使用“同上/参考前文”省略执行必要信息。版本和状态集中到索引；每张片段卡增加简短参考对应，写清C/L/F是谁、哪里、哪张画面及用途，链接定位到卡内小节并与索引同步。
- 每条视频提示词都须把[物理与视觉约束](references/prompts.md#每段的物理与视觉约束)写进可复制正文。正文必选出镜角色各自的基础形象图，以及各镜所在场景的场景图。一个片段跨场时在实际切场处引用新场景。逐镜把站位、朝向、动作、视线、可见表情和声音写成表演，明确动作主语和反应对象。普通预演图或关键帧在[参考对应](references/package.md#片段卡的参考对应)登记为辅助素材，正文可独立执行。单镜连续叙述，多镜按既定切点共用一个执行块。按[复制正文](references/prompts.md#复制给生成器的正文)精简重复文字。
- 动作戏的执行正文按[连续动作写法](references/prompts.md#连续动作写法)逐镜写成能连读的表演。每段独立交代起点和落点，用前一动作的结果引出下一动作。场记坐标、双时间轴和后期轨号归总索引。
- 只有文字：提示词保留必要生成信息，媒体文件、实际上传标签与执行参数未定时在索引标待绑定，不造假链接。上传准备和提示词复制分开说明，不把未绑定输入伪称已上传。
- 有生成授权：先选定角色基准图和场景核心底图，核对视觉/空间锚点；按需从基准派生身份板和机位图，检查选定的辅助图。按采用模式绑定真实角色、场景及必要的辅助素材，先用有代表性的片段试拍，合格后在范围内扩展；不得逐代把新输出当唯一身份标准。
- 参考素材用于身份、空间、音色、构图还是首尾端点须逐个注明。网页命名形象、上传编号和API槽位不能混用；规划序号不是已上传证明。
- 每次修改新建版本，保留原文件或旧版本目录。索引指出采用版本；资产变化只标其依赖镜/段待复核，不覆盖他人文件或重做全片。

## 门禁

- 逐镜核对出镜角色有对应基础形象图、每个实际场景有对应底图，清单按角色和场景去重计数。其余图片有具体用途时才安排。只有动作或表情改变的镜头直接检查视频正文。
- **文字包交付**：单独读每个视频块，沿剧情检查每处关键动作由谁或什么引起、从当前机位看见什么。凡是影响理解的数量、遮挡、方向或状态有两种读法，就在该动作旁消除歧义。索引内镜头/段→卡片小节链接和执行入口闭合，原句/时长/空间无已知冲突；未生成/未检查项在索引明确。
- 交付前逐镜遮住目的句，结合已交代的前情，只读画面与声音描述。若本镜该传达的信息只出现在目的句里，补上剧本或分镜已有的具体线索，并核对它在当前景别看得见、在给定时长听得清。
- 逐项核对实际采用的辅助图及控制帧。每项都要能打开采用图片、找到唯一生图小节，或按指定来源采集/抽帧。拟用F先核是否确需新制；必要F在全片关键帧卡补齐正文，删去的F同步更新参考顺序与视频，原动作和切点保留。
- **实际生成提交**：当前文件/版本审核、必需媒体、通道能力、真实附件映射和费用授权齐备。文字通过不能替代图片审核或费用授权。
- **素材交付**：真实输出可读且记录采用版本；静图、动态和试听分别标检查范围，未检查不能写通过。
- **剪辑交接**：素材顺序、实际或计划保留区间、对白/字幕原文、音轨/音乐安排、待补镜和已知问题可追溯。未有媒体时称“文字交接计划”，不称“可剪素材齐备”。

## 交给谁

`wtt-video-screenwriter` 可供剧本，`wtt-video-director` 可供设计；它们不是运行前提。生图/编辑使用宿主可用能力，视频按用户通道使用可用执行器，例如已安装的 `wtt-media-api`、`wtt-jimeng-api`；不复制客户端，不默认为某平台已接通。

默认终点是文字制作包或用户明确要求的素材及剪辑交接。剪映等剪辑工具完成后期；用户回传成片时可按时码审阅和定点补镜，不自动发布。
