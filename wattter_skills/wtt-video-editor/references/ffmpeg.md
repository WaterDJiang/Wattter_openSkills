# FFmpeg 剪接指令

脚本依赖 Python 3.10 或更新版本、FFmpeg 及 FFprobe。抽帧和渲染要求 FFmpeg 支持 `scale` 的 `reset_sar` 选项，渲染使用 `libx264` 和 AAC。以下命令从本 skill 目录执行。

## 探测和抽帧

```sh
python3 scripts/edit.py inspect "原始视频.mp4" --sheets "接点检查"
```

- 探测输出视频、音频、帧率、时长和色彩元数据。选帧看实际帧间时间，某些素材的名义帧率明显高于平均帧率。
- `--sheets` 输出头尾两个四列、三行的接点拼图。JSON 中 `window_start` 为窗口起点，`interval` 为格间名义秒数。时码按首画面为零点，最终切点再定向逐帧核对。已有拼图文件时换用新目录。
- 找到候选后缩小窗口并抽实际帧。例如从媒体起点 3.5 秒开始查看 0.3 秒内的源帧。

```sh
ffmpeg -hide_banner -loglevel error -n -ss 3.5 -i "原始视频.mp4" \
  -map 0:v:0 -an -t 0.3 -fps_mode passthrough "候选_%03d.png"
```

- 源区间试听可用播放器或将对应时间导成音频片段。测峰值、检测静音只能辅助定位，词句和声效落点靠听。

## 剪接单与渲染

```json
{
  "width": 1280,
  "height": 720,
  "fps": 30,
  "clips": [
    {"path": "A.mp4", "out": 3.7, "audio_fade_out": 0.03},
    {"path": "B.mp4", "in": 0.1, "out": 4.2, "audio_fade_in": 0.03},
    {
      "path": "C.mp4",
      "transition": {"type": "audio", "duration": 0.133333}
    }
  ]
}
```

- 路径相对 JSON 所在目录，亦可用绝对路径。片段按数组顺序，源 `in` 含起始、`out` 不含结束，默认采用全段。源区间以首画面为零点，秒数对齐输出帧。宽、高为偶数。帧率支持 24、25、30、48、50、60。
- 每段可用 `note` 记录切点、取景和声音处理的依据。
- `transition` 写在接入的一段。默认 `cut`，画面和声音直切，可单独配 `audio_fade_in`、`audio_fade_out`。 `audio` 的画面在重叠中点直切，两段声音在重叠区渐变。 `dissolve` 叠化，`dip` 经黑过渡，均同步交叉淡化原声。
- 非直切时，从两段保留区间的交界处各取对应重叠时长，在成片中只占一次。比如 4 秒和 3 秒重叠 0.2 秒，拼后 6.8 秒。两端都要有可牺牲的画面余量；`audio` 模式在中点切画面时，会省去前段余量的后半和后段余量的前半。
- 声音短于画面或缺轨时用静音补齐。音轨对齐到视频时轴并输出双声道 48 kHz。脚本保留显示比例，必要时补边并统一像素比。混用 HDR、非立体声混音或色彩矩阵不明且存在明显色差的素材时，先作专项处理。
- `soft_wipe_right` 使用自定义像素表达式让略倾斜的柔边由左向右铺开，声音同时交叉淡化。先试 6–10 帧，检查边缘扫过主体的时机。
- 单段可用 `"zoom": 1.08` 等比居中放大。若只放大反应镜头，将素材在内部切镜处写成两个相邻区间，后一段恢复默认 1 倍。用这种方法可保留片尾标题的完整画幅。节奏先用调整入点、出点及重叠时长处理。

```sh
python3 scripts/edit.py render "剪接单.json" "成片.mp4"
```

脚本输出每段采用的帧对齐源区间与成片时轴。检查解码及帧数后发布新文件，路径上已有文件时选择新文件名。回看有过渡的区域时，复核整个重叠区，并在剪接单记下真正的切点或起止范围。

滤镜语义见 [FFmpeg 官方滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)。
