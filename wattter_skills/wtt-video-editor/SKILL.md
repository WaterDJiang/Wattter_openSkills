# 视频剪接

用已有素材延续剧情、动作和声音，交付可播放 MP4 与注明实际源区间、成片切点和选择依据的剪接单。用户或制作交接给出的顺序、必留对白、动作、字幕、标识与硬时长优先。文件名可用于识别顺序，画面和声音以媒体实测为准。

## 找切点

- 用 [FFmpeg 剪接指令](references/ffmpeg.md) 探测素材，查看每段首尾附近的连帧和原声。先扫一遍全段，识别内部已存在的切镜、黑场、重复动作及必须保留的叙事信息。每处接点都检查人物动作相位、运动方向、站位、视线、构图、光线与环境声。
- 在尾首窗口中调入点和出点，优先用动作接动作、视线接所见，或以声音、反应镜头衔接。近乎重复的两段画面只保留一次表演。判断依据是接点前后的运动，单张相似帧只用来缩小范围。
- 同场人物或道具跳位时，优先找已有的手部、物件、遮挡、空镜或反应镜头。不同机位通过明确的动作因果或信息揭示衔接。确有时间或情绪转换时才用短叠化或过黑。双影、倒退、重复发力、对白重叠或被吞字，说明要重选切点或缩短过渡。
- 画面适合硬切、声音断得突兀时，用少量原声重叠或边缘淡化。保留关键字、呼吸和动作音效，避免跨接两句完整对白。素材缺少必需动作又无可用替代镜头时，在剪接单标明缺口；新素材生成需要用户授权。

## 出片

- 前景有飞纸、车身等掠过时，可沿运动方向用代码制作柔边擦入；用素材里已有的遮挡作掩护。人物反应较弱时可等比裁成略近的景别，检查头顶、手、字幕和 Logo 的安全空间。先与直切版比较接点连帧，保留能解释具体动作或情绪的处理。

- 记下每段采用版本及保留区间，明确每个接点的画面处理、声音处理和理由。用 [FFmpeg 剪接指令](references/ffmpeg.md) 保存 JSON 并渲染到新文件。根据片源有效帧率与目标用途选择画幅和帧率。普通 SDR 成片保留原有比例；涉及 HDR 或需要个别片段调色、复杂混音时，先定向制作中间素材。
- 渲染后查看每个切点前后约一秒的实际成片，带声复核动作、对白、音量变化、黑帧和 Logo 可读性。技术检查通过只能证明文件正常，剪接体验要靠实际复核。若只能抽帧或量测音轨，交付时注明动态和试听检查的范围。
