# 可复制的 Skill 测试集骨架

复制本目录到目标 Skill 的 `tests/evals/`，按实际业务填写。已有测试系统只补缺失字段，不平行再建一套。本目录是模板，不含真实运行结果或通用模型运行器。

## 默认比较范围

每次只比较最近相邻两版：修改前最近一版 baseline 与修改后最新版 candidate，例如 v2→v3，下一轮 v3→v4。更早版本仅归档，不参与本轮比较；最近前版缺失时报告无法对照，不用更早版本顶替。首次创建只有 candidate 时建立首次基线，不虚构对照。历史失败用例可继续保留，两端使用相同固定用例。

## 文件职责

- `cases/<case_id>/v1/`：输入、固定附件和 rubric.md（评审专用，不传给生成端）。
- `suites/v1.json`：固定用例与版本、核心/针对性标签；输入与标准的哈希。
- `versions/<skill_version>/`：完整运行资源快照与哈希清单，排除测试历史自身。
- `runs/<run_id>/`：manifest.json、原始输出、日志、状态和 comparison.md；重试用新 ID。
- `INDEX.md`：运行、参考样例和失败回归的索引，不复制原始输出。

创建骨架后，先补一项核心用例和本次针对性用例，填写输入与可判定标准；模板中的 `待填写` 不是测试通过。运行说明写本项目已验证的命令或独立会话步骤、实际模型/配置和输出路径。
