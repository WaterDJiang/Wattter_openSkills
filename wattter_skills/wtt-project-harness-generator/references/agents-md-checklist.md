# AGENTS.md 质量核验（强制子流程）

> 生成 AGENTS.md 后**必须**执行本流程，所有适用项通过才能写入文件。也可独立用于审计已有 AGENTS.md。

## 调用时机

- SKILL.md 工作流第 4 步「验证与写入」触发
- 用户要求"检查 / 审计 AGENTS.md"时独立调用
- 合并其它工具规则文件（`.cursorrules` 等）后复验

## 执行协议

1. 逐条按下表核验，每条给出 **✓ / ✗ / N/A + 一句依据**（N/A 仅用于不适用的条件项，注明原因）
2. 任一 ✗ → 回到生成步骤修正对应内容，再**整体重核**（不边写边改）
3. 无法核验的项（如无运行环境、拿不到 package.json）→ 标 **⚠** 并说明缺少的证据；先完成可核验部分，需要用户信息时再询问，**不默认通过**
4. 所有适用项 ✓、其余有明确 N/A 原因后才写入；写入前输出核验摘要

## 核验项

按"语法 → 可执行性 → 内容 → 安全 → 一致性"五组。

### 语法

| # | 检查 | 怎么验证 | 不达标 |
|---|------|---------|--------|
| 1 | 纯 Markdown，无 frontmatter | 看首行是否 `---` | 删 frontmatter |
| 2 | 无 `@import` / HTML 注释 | grep `@import`、`<!--` | 移除或改成纯链接 |
| 3 | 代码围栏配平 | 数 ` ``` ` 为偶数 | 补/删围栏 |

### 可执行性

| # | 检查 | 怎么验证 | 不达标 |
|---|------|---------|--------|
| 4 | 每条命令真实存在 | 抽代码块命令，对照 `package.json` scripts / Makefile / `pyproject.toml` 确认 | 改成确切命令或删 |
| 5 | 命令是确切指令，不是描述 | 找"运行测试""启动服务"等散文 | 换成 `pnpm test` 类 |

### 内容

| # | 检查 | 怎么验证 | 不达标 |
|---|------|---------|--------|
| 6 | 每条规则能判"怎样算违反" | 逐条读，找"高质量/注意性能/整洁"等口号 | 删或具体化到可验证 |
| 7 | 至少 1 条代码看不出的约定 / gotcha | 对比代码能直接推断的内容，看 AGENTS.md 是否有增量 | 补项目特有约束 |
| 8 | 没抄 README / 没堆全量架构 / 没列每个文件 | 与 README 比对；架构段是否超过决策结论 | 删冗余，链外部文档 |
| 9 | 不重复 LLM 常识 | 找"写注释""保持整洁""处理错误"类 | 删 |

### 安全

| # | 检查 | 怎么验证 | 不达标 |
|---|------|---------|--------|
| 10 | 无密钥 / token / 内部 URL | grep 常见模式：`AKIA`、`ghp_`、`xox`、`sk-`、`password=`、`secret=`、`10.`/`192.168.`/`127.` | 立即删，必要时提醒用户轮换 |

### 一致性

| # | 检查 | 怎么验证 | 不达标 |
|---|------|---------|--------|
| 11 | 区分现状、有效约束和迁移目标 | 核对代码与授权；迁移须有范围、过渡兼容、任务及完成条件 | 修正错误来源，不默认改文档迁就代码 |
| 12 | 行数 < 200 | `wc -l` | 按「嵌套 AGENTS.md」拆分或精简 |
| 13 | 若同时生成 CLAUDE.md：核心规则一致 | 对照两份的规则段 | 统一两份，Claude 专属语法只留 CLAUDE.md |

### 持续开发（开发项目适用，其他项目按实际流程核验或注明 N/A）

## 核验摘要格式

写入前输出，让用户看到门控结果。全过（有不适用项时报告“适用项 X/X ✓，N/A Y 项及原因”，不得计为通过）：

```
AGENTS.md 核验：19/19 ✓ → 可写入（仅在全部适用时）
✓ 语法纯 Markdown · ✓ 命令可跑 · ✓ 规则可判违反 · ✓ 有项目特有 gotcha · ✓ 无密钥 · ✓ 与代码一致 · ✓ 152 行
```

有未过项：

```
AGENTS.md 核验：17/19，2 项不达标 → 回炉，不写入
✗ #4 命令 "make test" 不存在 → 改为 "pnpm test"
✗ #11 文档称 zustand、代码用 redux 且无迁移依据 → 修正文档现状描述
```

## CLAUDE.md 复用

同一套检查（除 #1 #2 的 AGENTS 专属语法）适用于 CLAUDE.md。CLAUDE.md 额外检查：行数 < 200，超出已拆到 `.claude/rules/` 或 `@import`；Claude 专属语法（`@import`、路径规则）此时是**允许**的，不按 #2 判 ✗。
