# Horizon Outdoor Co. — 原始财务材料清单（raw-data/)

本目录包含 4 份模拟的、互相勾稽的财务材料，每份都是 Skill 可以处理的"常规办公格式"：

| 文件 | 格式 | 内容摘要 | 模拟业务场景 |
|------|------|----------|--------------|
| `01-P&L月度明细-FY2024-FY2026.xlsx` | Excel | 月度净销售额 + COGS + 主要费用 + 年度关键比率 | 管理报表（未经审计），模拟月度经营例会用的口径 |
| `02-渠道与SKU-交叉维度-FY2025.xlsx` | Excel | 渠道拆分 + SKU 系列 + 履约节点 + Channel×SKU 交叉矩阵 + CRM | 季度业务复盘 + 年度渠道复盘的明细数据 |
| `03-资产负债表与现金流量-FY2024-FY2026.xlsx` | Excel | BS + CF + 财务比率 + DTC 运营 KPI | 模拟年度审计/管理报表的三表全套 |
| `04-FY2025年度董事会报告.pdf` | PDF | 8 页董事会报告：执行摘要 + 毛利率驱动 + 渠道结构 + 现金流 + 风险 + Action | 模拟对外披露的董事会讨论稿 |

## 各文件用途与 Skill 对应入口

**01-P&L月度明细**：24 个月度 + 3 个年度；该文件测试 Skill 的 **Step 2 数据审计**（period 一致性、合计与分项勾稽、单位核对）和 **P&L Common-size** 图表。

**02-渠道与SKU-交叉维度**：包含 `Channel × SKU` 交叉矩阵，测试 Skill 的 **Step 3 交叉维度硬规则**——任何有 ≥2 个分类维度的数据，HTML 必须至少包含 1 张交叉维度图（heatmap）。

**03-资产负债表与现金流量**：测试 Skill 的 **资产负债表结构堆叠图 + 现金流量条形图 + 比率趋势** 三组核心图表。

**04-FY2025年度董事会报告.pdf**：用作董事会报告引用源；Skill 需要先从 PDF 提取关键论点，再在 HTML 中复现。

## 模拟数据真实性说明

- 数字在四份材料之间互相勾稽（毛利率 57.1% / 净利率 14.6% / FCF $3.46M 出现在四份文件中的同一口径）。
- 行业术语（FCF margin、AOV、CAC payback、Cohort、Net Revenue Retention）匹配实际跨境电商行业惯用法。
- 客户名已脱敏（Amazon US、Shopify D2C、Walmart Marketplace、TikTok Shop、Wholesale 是渠道，非具体买家）。
- 商业模式（RMB 锁价 + 越南代工 + FBA 履约）符合中等规模 DTC 户外品牌的常见财务画像。

## 不指向任何真实公司

本目录中所有公司名、产品名、客户名、利率、价格均为 Skill 调试而虚构；不指向任何真实存在的公司、产品线或交易关系。
