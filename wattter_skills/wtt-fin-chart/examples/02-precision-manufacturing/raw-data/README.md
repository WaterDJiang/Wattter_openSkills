# 明远精密 (MingYuan Precision) — 原始财务材料清单（raw-data/)

本目录包含 4 份模拟的、互相勾稽的财务材料，每份都是 Skill 可以处理的"常规办公格式"：

| 文件 | 格式 | 内容摘要 | 模拟业务场景 |
|------|------|----------|--------------|
| `01-季度利润表-FY2023-FY2025.xlsx` | Excel | 11 个季度 P&L + 月度营收 + 成本结构 + 季度毛利率 + 原材料价格 | 季度经营分析会 + 月度财务例会 |
| `02-客户与交叉维度-FY2024.xlsx` | Excel | TOP10 客户 + 客户×行业 + 客户×工艺 + DSO + 采购集中度 + 订单储备 + 行业/工艺维度 + 产能/研发 KPI | 季度业务复盘 + IPO 准备期客户尽调材料 |
| `03-三表与财务比率-FY2023-FY2025.xlsx` | Excel | 资产负债表 + 现金流量表 + 财务比率 + 应收账款账龄 + 固定资产明细 + 有息负债结构 + ESG | 模拟年度审计 + 季度报表全套 |
| `04-FY2025IPO前投资分析报告.pdf` | PDF | 8 页 IPO 前投资分析：执行摘要 + 行业结构 + 客户切换 + 现金流 + 风险 + 估值锚 + Action | 模拟对外报送的 IPO Pre-submission 文件 |

## 各文件用途与 Skill 对应入口

**01-季度利润表**：季度 + 月度双维度，测试 Skill 的 **Step 2 数据审计**（相同 fiscal calendar、一致单位、毛利率分母核对）+ **Quarterly small multiple** 图表。

**02-客户与交叉维度**：包含 2 个交叉矩阵（客户 × 行业、客户 × 工艺）+ 5 个 1D 维度（TOP10 客户 / 行业 / 工艺 / 订单储备 / 采购集中度 / 产能 KPI），测试 Skill 的 **交叉维度硬规则**——任何有 ≥2 个分类维度的数据，HTML 必须至少包含 1 张 heatmap + 1 张 top-pair 或 drilldown 表。

**03-三表与财务比率**：测试 Skill 的 **P&L + BS + CF + 比率 trend** 四组核心图表。该 workbook 还在最底部留了一个真实的 **应收账款账龄结构表**（4 个时间段 × 3 个年度），可以演示 Skill 的"账龄堆叠柱状图"能力。

**04-FY2025IPO前投资分析报告.pdf**：用作 Pre-IPO 投资分析引用源；测试 Skill 从 PDF 提取观点后再生成 HTML 的能力。

## 模拟数据真实性说明

- 数字在四份材料之间互相勾稽（毛利率 30.2% / 净利率 12.2% / FCF ¥-40.1M 出现在四份文件中的同一口径）。
- 行业术语（OEE / Yield / CCC / ROIC / 应收账款账龄 / 利息保障倍数）匹配实际制造业（特别是精密结构件子行业）的惯用法。
- 客户名已脱敏（A-J 标识），行业归属按客户主营业务归类。
- 财务特征（高新技术企业 + 专精特新、出口业务"免抵退"、松山湖二厂扩张、IPO 辅导备案）符合东莞精密结构件子行业典型画像。

## 不指向任何真实公司

本目录中所有公司名、厂区、地址、利率、银行授信、客户名均为 Skill 调试而虚构；不指向任何真实存在的公司、银行或交易关系。
