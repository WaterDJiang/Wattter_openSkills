# 风格 D：使用真实字体稳定排字

封面默认沐瑶随心手写体，正文默认喜脉喜欢体；同一文章按每张图片的用途分别选择，不能因文章含封面就让正文也去下载沐瑶。用户明确另选字体时按其要求核对本地原文件；无字图不要求字体。

## 本地字体定位与保存

`SKILL_DIR` 指本次实际加载的技能目录，不能用当前工作目录猜测。先运行[解析器](../scripts/resolve_font.py)，从JSON的 `font_path` 加载真实TTF：

```sh
python3 "$SKILL_DIR/scripts/resolve_font.py" --usage cover --text '本次完整标题'
python3 "$SKILL_DIR/scripts/resolve_font.py" --usage body --text '正文说明文字'
```

- 沐瑶查找顺序：独立用户目录 `~/.local/share/wattter-skills/fonts/MuyaoPleased.ttf` → 当前技能内旧路径 `assets/fonts/local/MuyaoPleased.ttf`。喜脉只需随附的 [FontQuSmile-Regular.ttf](../assets/fonts/FontQuSmile-Regular.ttf)。脚本只访问本地，核验SHA-256；可选 `--text` 用fontTools检查全部非空白字符，退出2表示缺失、损坏或缺字，不得忽略错误继续渲染。
- 沐瑶命中旧路径或用户已有原文件时，用下面的登记命令保存一次。独立目录不随运行树更新而消失；不安装系统字体、不纳入Git或公开分发包。

```sh
python3 "$SKILL_DIR/scripts/resolve_font.py" --usage cover --install-cover-from '/实际本机路径/沐瑶随心手写体.ttf'
```

- 只有上述本地位置和用户提供的文件均缺失，且本次确需沐瑶，才从[来源说明](../assets/fonts/MUYAO-SOURCE.md)获取一次并登记。远端原名是 `沐瑶随心手写体.ttf`，本地规范名是 `MuyaoPleased.ttf`，不能用本地名猜远端URL。无需调用GitHub目录API；403限流、404路径错误不能当作字体不存在的证据，也不能触发反复试探下载或换字体。
- 复用已有字体与来源记录，不逐图重新调研。沐瑶来源/使用边界见 [MUYAO-SOURCE.md](../assets/fonts/MUYAO-SOURCE.md)，喜脉版本/许可证见 [SOURCE.md](../assets/fonts/SOURCE.md)。字体版本或校验值变更须核对原文件再更新记录，不能为通过检查直接改哈希。

## 两种输出路径

- **实际制作含字图片且要求字体稳定（默认）**：先按既有规则确定标题原文、分行、字号、位置和文字留白区域。生图提示词只生成插图，写明“no text, reserve the specified title/label area”。然后使用可加载 TTF 的排版工具把文字渲染为独立透明文字层并合成到副本；保存无字底图、文字原文/布局参数与最终图，不覆盖源图。需要编辑图片时使用当前环境授权的图像编辑工具；只有支持真实字体排字的路径才能声称使用了此字体。
- **仅输出生图提示词**：提供插图提示词与独立排字说明，附字体路径。若用户选择生图模型直接画文字，继续提供字形参考，但明确属于字形近似，不声称模型加载了本地 TTF。

## 排字约束

- 实际按文件路径加载 TTF，不只填写可能触发系统替代字体的 family 名称。Pillow 可用 `ImageFont.truetype(str(font_path), size)`；HTML 使用 `@font-face` 指向该 TTF，并等待 `document.fonts.load()` / `document.fonts.ready` 后导出。
- 渲染前通过字体 cmap 检查全部非空白字符；发现缺字列出具体字符，不能悄悄回退到另一字体。保留完整标题，不擅自删字换词。
- 标题容量是[构图策略选择](cover-composition-strategies.md)的输入。先按真实TTF测量完整标题、语义分行与主次层级；放不下则调整图文比例或选择更合适策略，不截字、不自动换字体。
- 封面先读取[标题强调](platform-cover-layouts.md#标题强调与图文关系)，按原序片段分别加载真实字号、测量墨迹及外伸；保存每段文案、字号、边界、角色与阅读顺序。先核对拼回原文，再排字；不能只记录一个全局字号。焦点与承接层的实际墨迹高度应有可见差异，承接层仍需在目标小图里可读；不依赖自动font-weight回退或用描边伪粗。分层后的最终文字层重新过字图检查。
- 用真实字体测量文字边界，算入手写笔画的外伸与行距。先按内容确定图文构图、检查无字底图的实际负空间，再排字；平台封面位置、字号与对比按 [平台构图模式](platform-cover-layouts.md) 执行，真实字体测量后适配容器；跨渠道或未指定平台使用 D-U1 的标题容器与裁剪交集，导出时保持整体图文单元。长标题语义分行并检查目标裁剪与缩略图。非封面按原有克制短说明规则。
- 封面文字层全部使用纯黑 `#000000`，关键词也不着蓝；克莱因蓝只用于插图。非封面沿用原灰字规则。
- 全身无遮挡、留白和克莱因蓝规则继续有效；不要再附“禁止电脑字体”等与真实手写字体排字相冲突的约束。
- 导出后逐字核对原文、字形、溢出及裁切。字体文件可读不等于图片已排字；只有实际加载字体、完成渲染并检查结果后才报告完成。


## 字图干扰检查：按实际图层放行

预设 `title_box` 只作起稿。生图后重新读取底图并测量实际文字墨迹（含旋转、外伸、最终缩放），不能沿用草图坐标直接判定完成。

- **几何检查**：保存同尺寸、同坐标的无字底图和透明文字层，用[检查器](../scripts/check_cover_clearance.py)检查文字笔画与实际非白图形是否重叠，以及每行实际墨迹包络外扩净空内是否存在人物、道具、路径、连线、边框。初始净空取短边2%，1920×1080约22px；按目标小图可辨识性调整并记录。倾斜文字按变换后的墨迹包络检查，不把其外接矩形角落全部判为禁区。纸片/标签可包围文字，但其真实边线不得进入净空；不把整个纸片矩形当作实心障碍。
- **人工审图**：按原尺寸及实际360px横图/160px方图分别查看文字是否与眼镜、头、手、工具、箭头、边框误连，复杂线条是否抢读字，字序和分行是否清楚。文字包围盒不重叠、像素检测通过都不能替代此步。
- **修正顺序**：先在实际负空间移动/重排标题，再调整场景位置、尺度或辅助线条；仍不足时重生成留白明确的底图或换适合的构图策略。保持完整标题、真实字体和可读字号，不用白块遮掉关键动作、不删字、不用不可读小字凑通过。修改后重新检查所有实际输出比例，不能只复核母版。
- **放行条件**：几何检查无冲突 + 人工审图通过 + 原文/人物完整 + 目标尺寸可读，才可报告该尺寸通过。检查器只返回 `geometry_pass` 或 `needs_revision`；有疑似干扰就修正或保留待复核，不能把“字体/尺寸检查通过”当作整体通过。仅提示词输出注明尚未进行图层和视觉验收。

在当前skill目录执行（依赖Pillow与NumPy）：

```sh
python3 scripts/check_cover_clearance.py --base base.png --text-layer text-layer.png --report clearance.json --overlay clearance-debug.png
```

退出0只表示几何检查通过；退出2表示须修改。输入尺寸不一致、文字层无透明通道或无实际墨迹会报错，不得静默跳过。`clearance-debug.png`仅用于查看检测框，不能作为交付封面。保存净空值、实际字区、重叠/邻近像素数、人工复核结论；阈值不保证视觉语义正确。
