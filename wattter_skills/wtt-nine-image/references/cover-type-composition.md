# 封面图文融合

## 先设计字和图之间发生的事

为每张含字候选先写一句能指导生成的画面描述，交代**哪段字在哪里、依附什么、和哪个物件发生什么关系**。接着写清字形、字重、大小、行序、承载面、光照和前后层。闭眼还能套在任何主题上的“文字和画面自然融合”须改成具体构图。

- **字是结构**：关键分句形成门面、边界、台阶或阻隔，主体向它靠近、通过或与它对齐。字的尺度、方向和物件一起决定构图。适合短观点或明确行动。
- **字在空间里**：字与对象共享同一视角和朝向，可依附墙面、格线、平台或地形。需要穿插时，指定字前物、字后物及穿过字间空隙的位置。真正需要遮挡时只用非识读边缘，所有必读字形和人物身份特征清楚。线条人使用净空内的穿插构图，按D检查人物、手脚和文字，实际笔画零碰撞。
- **字与场景同材质**：标题可成为纸层的切字、同纸压印、金属刻印、板面油墨或印在拼贴的主纸片上。写明字如何贴合或切入承载面，纸厚、边缘、纹理、光源和接触阴影如何与主物件统一。按小图检查对比度，必要时让焦点字着墨。
- **字与主体借位**：当风格或长标题需要保留干净字区，让主体的边界、格网、动作或指向共同围出文字空间，标题与主物件共享对齐轴或阅读动线。为长标题扩大可读字区，让主次层的间距和对象节奏配合。

每张候选以[方向库](cover-style-catalog.json)的 `typography` 与 `title_integration` 为起点，选一种主要关系。把它改写成本篇的对象和动作。短题可让整句成为主结构，长题用原文分句与留位配合，图里的语义强调保持原标题的否定、限定与标点。可以有更轻的辅助文字，前提是用户提供、明确授权或内容确实需要且有出处。

## 生成与精排

- 模型能正确排字时，把完整可见文案和字图关系写进同一条生图提示词。要求纸雕、材质或遮挡效果的画面要明确哪一段字共享材质与透视，在哪儿发生前后关系。
- 需要真实字库、长题精排或模型第一次出字错误时，先测字再确定底图。用预计字形边界决定承载面位置、尺寸、方向和留白。底图预先画好承载面和相关前后物件。排字复用其透视、光线和材质，确有前后关系时按对象轮廓准备蒙版，再用真实字体排入。保存原文、底图、文字层和必要的遮挡边界。没有现成蒙版时可让物件穿过字间留白，或使用自然借位保持关系。字体或排版修改后复查。
- 明确要求预留字区时交付可直接排字的底图。保留设计好的承载面和空间关系，记录预计字区、行数及使用方式。纯无字时由主体独立表达内容，不保留只为未来标题服务的空窗。

## 出图后检查

- 在原图和发布位缩略图核对完整标题、字序、语义重心、图文层次、目标裁幅和关键主体。看实际承载面、物件和字是否共享预期的方向、材质、光线或轮廓关系。选了双向穿插时，核对能否辨认预定的两个前后关系。只在空隙经过或干净分区时，按借位或共轴描述效果，双向穿插仍待修。
- 发现标题漂浮或像后贴时，先调整承载面、字物距离或前后关系，再查字形和画面。文字与图冲撞时，移动非关键层、放大净空、换构图或重生成。采用D方向时仍执行[实际字图检查](font-typesetting.md#字图干扰检查按实际图层放行)。
