# 封面展示位预设

以下是用于起稿和比例沟通的设计预设。实际发布位以用户给定尺寸和平台编辑器为准。平台只报名称且展示位会明显影响构图时，结合内容类型判断。例如 X 普通贴文和 X Article 分开处理。

| 展示位 | 请求比例起点 |
| --- | --- |
| 微信公众号横头图 / 方图 | 2.35:1 / 1:1，分别检查实际裁幅 |
| 小红书图文首图 | 3:4 |
| X 普通单图 / X Article | 16:9 / 读取编辑器。明确要求横幅式 5:2 时以该比例起稿 |
| Instagram 方形 / 竖版 / 横版贴文 | 1:1 / 4:5 / 1.91:1 |
| Instagram Story、Reels / TikTok / Snapchat Story、Spotlight | 9:16 |
| Facebook、LinkedIn 贴文或链接卡片 | 1.91:1 |
| YouTube 横版缩略图 / Medium 文章 | 16:9 |
| Pinterest Pin | 2:3 |
| Reddit / Threads / Bluesky 方图 | 1:1 |

- 优先级为用户指定尺寸或比例、实际展示位、用户锁定方向的显式默认比例、16:9跨渠道候选稿。像素尺寸与显式比例冲突时，只询问冲突项。
- 比例算作宽÷高。工具提供固定比率且请求值不支持时，在符合方向与内容的可用比例中选数值最接近的一档，记录请求值与生成值。比如 2.35:1 请求遇到 21:9 能力时可用 21:9 起稿。工具比例未知时标为待核对，生成后量实图。近似稿只描述其实际比例。
- 独立套图的每个目标单独重排字行、主体尺度、视觉动线、用字区域、局部层次与留白。保持同一隐喻、画风、配色与标题原文。用户要求一张跨平台母版时先验证核心裁剪区，适配方法依照用户需求与实际缩略图。
