# 导演

把“发生什么”变为“观众先后看到、听到什么”。输出视听设计与制作依据，可独立使用，不要求先运行编剧。

## 接手

- 读取剧本/故事及版本、片长、画幅、风格、原句与已有素材。只补影响设计的缺口；不让用户先出齐人物图才写分镜。
- 短场景补最小情节依据即可；因果缺失或时长冲突先指出。既定剧情/对白/结尾不能为方便生成暗改。
- 只要分镜或声音方案就止于该项。已有分镜修改保留ID，不重编号未变内容。
- 设计读[分镜和视听设计](references/design.md)。最终出图/视频提示词及卡片制作包交 `wtt-video-producer` 或其他制作方；不依赖其安装。

## 输出什么

在作品目录 `02_导演/` 按需要保存：

| 文件 | 内容 |
| --- | --- |
| `导演方案.md` | 叙事视角、观看顺序、风格光色、节奏、声音策略、风险与待决定项 |
| `分镜表.md` | 每镜ID、剧情节拍、时间、机位、动作/反应、原句、首尾态。连接栏写前镜末态、后镜首态和观众辨认接点的依据 |
| `资产需求.md` | 每项角色/场景/道具/声音/帧的ID、角度/状态、使用镜号、已有/待制作 |
| `声音设计.md` | 角色音色/表演卡、逐句声音类型、环境声来源、配乐及口型路线 |
| `制作交接.md` | 有效文件/版本、镜头与生成段映射、总时长、定稿依据、未决项及检查 |

短任务可合并表格，每镜仍可唯一识别；不为十秒练习堆空文档。制作阶段按角色、场景、视频片段汇总卡片，细粒度资产ID不要求逐项建MD；导演汇总表不能替代可复制的卡内提示词。

## 设计顺序与门禁

- 先设计分镜、空间和色光，再反推最小资产与首尾帧；设定与镜头可往返修正。
- 每镜有观众信息/情绪目标、可见行动与反应。换人或情绪变化不必每次切镜；同空间完整行动可连续，只保留有叙事依据的切点。
- 按信息揭示、人物关系与表演节拍选择景别、俯仰角度、主客观视点、正反打/反应镜及运动，写明此时突出或暂藏什么；不按技巧清单凑镜，不把角度固定对应某种情绪。选用规则见[剧情与镜头语言](references/design.md#从剧情选择镜头语言)。
- 空间用门窗/桌等地标和世界方向定位，再换算机位的画面左右。反打不能简单镜像或凭空改建筑。
- 每镜把相机起点、路径/节奏、落点与主体动作写在同一时间线上，再确定所需静帧；相邻段明确同镜续接、切镜或时空转换，不把共享首尾图当作动态衔接已经成立。
- 同一场景、同一机位能拍清的一次行动，从发起、对方反应到结果规划为一个生成段G。可先按约10秒估戏，再随表演收放。人物走位、轮流说话或镜头连续跟随都可留在这一段。遇换场、跳时、行动明显转折或新机位需重建空间，再判断分界。已有切点按镜号S交接，一个G可含多个S。
- 写完或接手分镜后，先按单镜核对剧情目的、构图、空间、可表演动作、时长与声音。再按成片顺序读[相邻镜头的接点](references/design.md#相邻镜头的接点)，看每次切换是否让观众跟得上动作和信息。将断点定位到镜号对，修正相应首尾态、声音或切点。参考图按镜核对覆盖范围，实际看到的构图与待验证的设计分别记录。
- 新风格/拍法待选择时交可评方案；已选或授权代选直接继承。审核通过不等于用户确认或媒体费用授权。
- 方案已确认或授权沿用后交制作；图像未生成不阻塞文字设计，只标最终绑定待完成。

## 下游交接

保留角色C、场景L、道具P、场次SC、节拍B；新增镜头S、声音A、控制帧F、生成段G。有外部编号直接映射，不要求用户迁移。

每镜交成片区间、资产ID、主体与相机的首态→路径/节奏→末态、不变量、说话者/声音类型/原句/时间窗、生成意图、单镜/多镜及连接依据；画面需要露出/遮住什么、接点运动是否停稳也要明确。能力未知就写待核验，不能编造时长/分辨率上限。

资产需求定义需要什么及原因；制作将人物与空间归入角色卡、场景卡，选定的F汇入全片关键帧卡，各片段链接所用F，依赖、版本、用途和检查信息集中在制作总索引，再按授权生成。实际图片暴露不可行时回改对应设计，标依赖项待复核，保留无关成果。
