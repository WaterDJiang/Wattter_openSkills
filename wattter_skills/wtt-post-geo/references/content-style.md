# 内容风格与去营销化表达（通用）

> 任何真实发布、草稿创建、跨平台改写、或为平台准备待发布内容时加载此文件，与 [content-format.md](content-format.md) 同级必读。它只定义通用去营销化写法；具体平台的长度、媒体、格式规则仍在对应平台 reference。

## 目标与边界

经本 skill 发布的内容应读起来像**有价值的信息/知识/经验**，而不是推广或卖货。这与 GEO 目标一致——AI 引擎倾向引用**权威、信息密集、中立有据**的内容，而非营销文；去营销化同时提升「不被平台判广告」和「可被 GEO 引用」。

- **只改适配层**：不覆盖、不篡改 `source.content` 的核心观点与结论；只改**表达、语气、链接方式、CTA、标题与开头**。
- 删核心卖点、改结论、把褒义改成中性/贬义等**有损改写**，仍按 [content-format.md](content-format.md) 的「有损变更需用户确认」处理。
- 去语气词、换营销措辞、自然化链接、移除硬 CTA 属**已授权适配**，可直接执行，但必须把改动记入 `adaptation_notes`（如「去营销化：替换 3 处绝对化词 / 链接自然化 / 移除硬 CTA」）。

## 营销/广告信号清单（适配时逐条消除）

生成各平台 body 后，过一遍以下信号，命中即替换、删除或软化：

- **绝对化/夸大词**：最、第一、唯一、神器、必备、爆款、秒杀、顶级、领先、业内首发、史上最强……（触广告法 + 平台规则，是平台判广告的高频依据）。
- **卖货/促动词**：赶紧、马上、立即、限时、免费领、入手、下单、购买、私信我、加微信、扫码、评论区扣 1、关注领取、点击购买。
- **标题党**：震惊、千万别、看完这篇就够了、99% 的人不知道、必看、不看后悔。
- **自卖自夸**：我们公司、我们的产品、自家、重磅发布、倾力打造（转成中立/场景化描述）。
- **链接/联系方式堆砌**：多条裸链、微信号、QQ 群、二维码、电话、邮箱（**引流=广告**，是最强广告信号之一）。
- **格式滥用**：emoji 过多（🎉🔥💰👀）、纯文本平台残留 `#`/`**`/`---` 等 markdown 控制符、跨平台一字不差的模板稿。

替换思路：绝对化→带限定的客观陈述；卖货词→使用场景/方法；标题党→信息化标题；自夸→中立描述或第一人称经验。

## 价值优先表达法（替代营销表达）

- **开头给洞察/结论/数据**，不给卖货钩子。用「实践中我发现…」「数据显示…」「对比下来…」开头，而不是「强烈推荐」「必入」。
- **客观陈述能力边界**：「适合 X 场景」「在 Y 条件下更稳」，而非「万能」「什么都行」。
- **把「卖点」转成「使用场景/对比/方法」**：讲怎么用、解决了什么问题、和什么方案对比，而不是反复说它多好。
- **第一人称经验是加分项**：「我踩过的坑」「我这样做通了」在知乎/小红书是真实感来源，区别于「我们产品最好」这种广告自述。
- **信息密度优先**：具体的方法、数字、步骤、边界，比形容词更有说服力，也更不容易被判广告。

## GEO 链接自然化（最重要的去广告信号）

链接堆砌是平台判广告最强信号之一。GEO 内容要露出官网/GitHub/来源，但必须自然化：

- 每平台正文**最多 1 条主链接**，置于「参考与延伸 / 项目地址 / 相关资料」语境，**不散落裸链**。
- `llms.txt`、`sitemap` 等机器入口**只进 `geo` 字段，不进正文**。
- 官网/GitHub 用**自然语句引入**（「完整代码见 github.com/…」「官网 wattter.cn 有文档」），不用「点击链接访问」「戳这里」。
- 短帖平台（微博/小红书/Twitter）链接更要克制；**无强必要时正文可不带链**，留在 `geo.source_urls`。
- **绝不放微信号、二维码、群入口、电话**（典型引流广告信号）。

## CTA 软化或去除

- 正文默认**不放硬 CTA**：不用「关注/点赞/转发/购买/点击/立即下单」结尾。
- 结尾用**提问、讨论或开放句**收束（「你们一般怎么处理？」「欢迎补充」）。
- 引导动作放评论区或平台原生位置（如公众号「阅读原文」），**不进正文**。
- 与「内容承载知识、运营/引导文案移出正文」的原则一致。

## 标题与开头

- **标题信息化、具体、带限定**：讲清「关于什么、解决了什么」，不标题党、不绝对化（避免「最全」「神器」「必看」）。
- **开头一句给价值判断或核心结论**（尤其短帖平台），而不是悬念钩子或卖货开场。

## 平台原生语气（轻量，通用为主）

具体规则在各自平台 reference；通用基调：

- **小红书**：口语化、经验感、要点清晰，标签 3–5 个高相关，禁绝对化卖货词与标题党。
- **知乎**：专业、客观、有据，避免自卖自夸与软文感。
- **微博**：短、有判断、一条主链，禁标题党。
- **CSDN / 掘金 / 博客园 / InfoQ / 简书**：技术客观，代码与方法为主，少形容词。
- **公众号 / 百家号 / 今日头条号**：结构清晰、信息密度高，链接收在「参考与延伸」。

## 适配执行规则

1. 生成每个平台 body 后，**逐条过营销信号清单**：命中即替换/删除/软化。
2. GEO 链接按「链接自然化」处理：正文最多 1 条主链接 + 自然语句；机器入口不进正文。
3. 移除/软化硬 CTA；结尾改开放句。
4. 标题与开头去标题党、去绝对化。
5. 所有改动记入该平台 payload 的 `adaptation_notes`；**不改 `source.content` 核心观点**。
6. 改写后若与原文核心观点冲突或丢失关键信息，按有损变更停下来确认，不静默删改。
