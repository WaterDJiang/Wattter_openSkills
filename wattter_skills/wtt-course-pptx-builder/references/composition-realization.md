# 将页面构图意图落实到PPT

存在逐页 `visual_description / composition` 或可读分镜画面说明时读取；Deck、Layout、Free Route均适用。它是教学表达的设计输入，不是新的正文或新的视觉值权威。

## Strategist：选型之后仍要读原意图

按 `page_id` 联读唯一屏幕正文、原画面说明与相邻页依赖。Binder用描述匹配候选，并不保证候选落实每条关系。锁版前核对主焦点、字段到区域的对应、阅读路径、揭示时机和连续对象定位。模板只有配色相似、卡片数相同仍可能不适配。

课程 Deck/Layout 把逐页实际执行决定及原意图引用写入 `page_realization.json`。其他路由可在现有 `design_spec.md` 按页记录。保持内容引用，不重抄全文。语义关系和必要可见支持不能因模板改变；具体坐标、列宽、边框和装饰可按视觉锁适配。几何调整仍应兑现原目的；若明确空间安排无法保留，说明等效实现。构图与内容含义冲突时回源澄清，不能靠视觉锁覆盖教学要求。

- 未提供新式提示的旧包仍可执行，由本角色依据正文补具体计划，不要求补新字段。
- 不为装模板删内容、拆已锁页或缩小到不可读；先改布局或选合法重建模式。确需改正文/分页时提出上游变更，保留原锁等待处理。
- 不将参考图整页嵌入冒充原生可编辑交付；图像只承担已确认的素材用途。

## Executor：逐页落实

查询本页执行锁时，一并读取本页正文、原意图与已锁逐页计划。正文只来自原页表；用对象位置、对齐、局部强调、分组与必要连接呈现其含义。完整话术/提示词应能连读，批注贴近对应片段，不能切成失去原句的散碎标签。

复杂关系先用真实文本核对空间，优先给学习对象和行动入口留足面积。相同条件保持可比；持续任务保留定位；未知/否定不可用同一符号误导。关系不需要图形时可用文本本身作主视觉。不机械复刻信息图的装饰或分区。

## 渲染后：核对承诺是否兑现

在现有审查记录（Deck为template_usage，其余复用design_spec或review）补本页SVG、实际PPTX渲染图路径与观察。先查看最容易暴露问题的代表页，再核对其余页：

- 遮住讲师备注，第一眼能定位关键对象、判断依据或开始做的位置吗？必要事实/原句/任务入口仍在当时可见处吗？
- 对照原构图提示，学员能靠空间直接找出同维度比较、条件组合或改动依据吗？是否仍要读完几段话自己建立关系？
- 完整文本在真实字号下是否可读，长句换行、批注、连线有无遮挡/错指？外框整齐或文字命中不能替代这些检查。
- 相邻页的定位与答案时机是否保留？几何适配是否改变了含义？

发现问题修实际页并重渲染；涉及内容锁则回上游。未取得PPTX实际渲染时记“视觉未验证”；SVG预览与原生编辑性检查单独报告，不能替代成品渲染。此核对并入现有Step 6/7，不另设用户确认或固定分数/图形配额。

课程Deck/Layout的上述计划与成品复核须执行[逐页结构机器闸口](page-realization.md)，不能只填写template_usage文字声明。
