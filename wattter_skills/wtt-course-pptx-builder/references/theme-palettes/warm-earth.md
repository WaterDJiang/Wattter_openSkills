# Theme palette: warm-earth

Warm, approachable, grounded. 温润、亲和、踏实。

## HEX seed

| Role | HEX | Use |
|---|---|---|
| primary | #A0522D | 标题装饰、强调色块、HTML 背景主色（赭石/棕） |
| accent | #6B8E5A | 数据高亮、HTML 几何强调块（橄榄绿） |
| bg | #FAF6F0 | 页面底色（米白） |
| surface | #F2EBE0 | 卡片底 / 浅渐变终点 |
| border | #E0D5C3 | 发丝线 / 描边 |
| text | #3D2F24 | 正文 |
| text_secondary | #7A6A5A | 注释 / 次要文字 |

## Neutral scale

`#FFFFFF` → `#FAF6F0` → `#F2EBE0` → `#E0D5C3` → `#B8A98E` → `#7A6A5A` → `#3D2F24`

## 适配场景

教育培训、文化传播、生活方式、健康/有机品牌、亲子/家庭主题、人文社科。

## HTML background style hint

推荐 `editorial-rule`（✓✓）或 `gradient-panel`（✓）；暖底 + 发丝线的编辑型克制最显温润气质。避免 `geometric-mesh` 的冷峻切割（✗）。
