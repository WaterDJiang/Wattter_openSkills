# Theme palette: dark-cinematic

Dramatic, premium, cinematic. 戏剧、高端、电影感。

## HEX seed

| Role | HEX | Use |
|---|---|---|
| primary | #0E1116 | 标题装饰、强调色块、HTML 背景主色（近黑） |
| accent | #D4AF37 | 数据高亮、HTML 几何强调块（金） |
| bg | #0E1116 | 页面底色（深底） |
| surface | #181B22 | 卡片底 / 浅渐变终点（略浅深） |
| border | #2A2F3A | 发丝线 / 描边 |
| text | #F5F5F0 | 正文（浅） |
| text_secondary | #9CA3AF | 注释 / 次要文字 |

## Neutral scale

`#0E1116` → `#181B22` → `#2A2F3A` → `#4B5563` → `#9CA3AF` → `#F5F5F0`

## 适配场景

产品发布、奢侈品、娱乐/影视、高端品牌、夜间主题、颁奖/盛典。

## HTML background style hint

推荐 `gradient-panel`（✓）或 `geometric-mesh`（✓）；金色 accent 在近黑底上最显戏剧高端。避免 `editorial-rule`（✗）——深底丧失其白底克制感。

> ⚠️ 深底色板：SVG 文字层必须使用浅色文字（`text: #F5F5F0`），HTML 模板的浅渐变在深底下变为「深 → 更深」，仍可用。
