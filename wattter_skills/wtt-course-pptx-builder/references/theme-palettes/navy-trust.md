# Theme palette: navy-trust

Stable, trustworthy, authoritative. 稳重、可信、权威。

## HEX seed

| Role | HEX | Use |
|---|---|---|
| primary | #003366 | 标题装饰、强调色块、HTML 背景主色（深海蓝） |
| accent | #C9A961 | 数据高亮、HTML 几何强调块（古金） |
| bg | #FFFFFF | 页面底色 |
| surface | #F8F9FA | 卡片底 / 浅渐变终点 |
| border | #E2E8F0 | 发丝线 / 描边 |
| text | #1A1A2E | 正文 |
| text_secondary | #64748B | 注释 / 次要文字 |

## Neutral scale

`#FFFFFF` → `#F8F9FA` → `#E2E8F0` → `#94A3B8` → `#64748B` → `#1A1A2E`

## 适配场景

咨询报告、金融年报、政务汇报、学术答辩、企业年报、法律/审计陈述。

## HTML background style hint

推荐 `gradient-panel`（✓✓）或 `editorial-rule`（✓✓）；与 `geometric-mesh`（✓）搭配偏冷峻有力。古金 accent 在深海蓝上显高级感。
