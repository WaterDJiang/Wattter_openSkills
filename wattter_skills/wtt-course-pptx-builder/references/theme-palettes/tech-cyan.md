# Theme palette: tech-cyan

Innovative, forward-looking, energetic. 创新、前瞻、有活力。

## HEX seed

| Role | HEX | Use |
|---|---|---|
| primary | #1565C0 | 标题装饰、强调色块、HTML 背景主色（科技蓝） |
| accent | #00BCD4 | 数据高亮、HTML 几何强调块（青） |
| bg | #F8FAFC | 页面底色（冷白） |
| surface | #EEF2F7 | 卡片底 / 浅渐变终点 |
| border | #D6E0EC | 发丝线 / 描边 |
| text | #0F172A | 正文 |
| text_secondary | #64748B | 注释 / 次要文字 |

## Neutral scale

`#FFFFFF` → `#F8FAFC` → `#EEF2F7` → `#D6E0EC` → `#94A3B8` → `#64748B` → `#0F172A`

## 适配场景

科技产品发布、SaaS 方案、AI/架构介绍、互联网行业报告、技术分享。

## HTML background style hint

推荐 `geometric-mesh`（✓✓）或 `gradient-panel`（✓✓）；青色 accent 在科技蓝上强化数字感与活力。避免 `editorial-rule` 的过度克制削弱科技调性。
