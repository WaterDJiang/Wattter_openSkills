# AI 课程蓝金实战 — Design Specification

## I. Template Overview

这是从现有“平安知鸟”Deck 的视觉语言衍生出的独立课程模板，不代表原机构。沿用 1280×720 画布、蓝色大面与暖金曲线、白底留白、扁平浅蓝面板、左上金色竖线和楷体标题；所有品牌 Logo 和机构署名均不进入本包。结构页有气势，知识页保持安静，练习页留给学员操作和讲师点评。

使用节奏：封面 → 目录 → 章节 → 原理/机制 → 流程或双路选择 → Prompt 示范、操作演示或澄清对话 → 练习任务/画布 → 对比/评价/纠错 → 迁移计划 → 结尾。模板提供页面结构和占位，不预设某门课程的具体事实。

## III. Typography

标题、正文与中文标签使用 `STKaiti, KaiTi`，保持原模板的课程气质。Prompt 编辑器与演示工具名这两处字符密集区使用 `Menlo, Consolas, monospace`，便于辨认英文键名和标点；这是本包的局部例外，不扩展到普通正文。内容正文通常为 20–24px，页面标题 52px。长文本先拆页或压缩语句，不把实操说明缩成微小字。

09 与 16–18 是投影用页型，使用 `Hiragino Sans GB`，原生 PPTX 导出采用微软雅黑。逐页契约应记录该字体例外。页标题 55px，主要正文通常 32–43px，辅助标签 21–24px。

## IV. Signature Design Elements

- 封面、章首页、中场休息与封底按页型从本包选用蓝金整页背景。结构页采用手绘简笔画：自然微抖的深蓝或浅色描边、蓝白浅填色、少量暖金回形针和强调线，主体对应资料、对话、核验等场景；保留轻微纸感和手绘轮廓。无 Logo。
- 内容页左上用暖金线与章节签定位。09、16–18 使用横线。
- 原理使用三层可解释结构；机制使用“输入→模型→输出→人工核验”反馈环；流程使用四段连线。
- 实操页有操作界面占位、步骤旁栏、计时任务、四区练习画布和结果评价表。08 的界面占位用真实截图或可编辑 UI 图形。17 的工作台用于展示提示词文本。
- 背景库包含三张通用底图和九张财税篇底图。课程文字始终作为独立可编辑元素叠在底图上。

### 新页的选用与容量

| 页型 | 绑定条件与落位 |
|---|---|
| 09 练习任务 | `flow_linear`，三个操作。标题约 15 个全角字，步骤每行约 21 字。保留目标、材料、步骤和交付。时长来自课程源；短时长可放大数字并另排单位。源材料没有时长时，取消计时标题和时长占位，将验收要求移至右栏，仍保留独立交付区。 |
| 16 双路选择 | `tree`，两条条件分支，分层方向。决策点约 7 个全角字，右侧每条路径约 15 字。分支数只计处理路径，根节点不计入。 |
| 17 四字段提示词示范 | `points_4`，四个并列字段，左右方向。各字段约 18 个全角字，放大区每行约 7 字。引线连到实际被放大的字段。仅复述提示词已有条件。07 用于五要素讲解，08 用于操作界面。 |
| 18 反向追问对话 | `points_3`，同一轮的三个并列问题，左右方向。用户原话可分三行，每行约 12 个全角字，三个问题各占一行。使用真实对话时注明来源，教学演示标注示意。 |

### 图表结构与专用教学页的选择

`04`–`14` 和 `16`–`18` 是有明确教学任务和固定槽位的专用页。选用时同时匹配用途、内容形态与 `item_count`。普通模块架构、通用流程、A/B 对比、数据表和时间轴可从全局 `templates/charts/` 选更贴合关系的结构。

| 内容关系与证据 | 优先考虑的全局结构 | 包内页仍适用的情况 |
|---|---|---|
| 横向系统层级，每层有模块说明 | `layered_architecture` | 正在讲 AI 原理的三个概念层级时用 `04` |
| 各阶段有明确交付物的流水线 | `pipeline_with_stages` | 正在讲四步 AI 工作流程时用 `06` |
| 评估、反馈与再生成形成循环 | `circular_stages` | 用真实失败输出演示纠错动作时用 `13` |
| 围绕一项 AI 核心能力展示多个场景 | `hub_spoke` | 需要逐一拆解 Prompt 五要素时用 `07` |
| 多分支追溯幻觉或质量问题根因 | `fishbone_diagram` | 只复盘一例失败输出时用 `13` |
| 按价值与实施难度筛选 AI 任务 | `matrix_2x2` | 需要布置一次具体练习时用 `09` |
| 多项任务有真实的前后测量值 | `dumbbell_chart` | 仅作定性方法对照时用 `11` |
| 有真实的多轮效果数据 | `line_chart` | 需要填写过程与人工核验时用 `10` |

全局 chart 只借关系、坐标、标签与系列编码。其默认白底页头、英文占位字、字体、彩色系列和阴影均不直接进入本 Deck；按上方封闭蓝金色板、楷体文字、内容页头和课堂可读字号逐页重绘。图表内容过密时缩减文字或拆页，不缩小到难读。数值图必须来自课程的真实数据，缺数据时改用定性结构，不制造示意数值。全局 chart 不携带 Logo，也不添加机构署名。

## VI. Assets

[背景目录](background_catalog.json)记录 12 张 16:9 底图的页型、主题、关键词和文字区。

| 页型 | 可选场景 | 文字落位 |
|---|---|---|
| 封面 | 手绘电脑与任务资料、财税月结账表 | 左侧浅色，x=72–620，深蓝或次字色。 |
| 章节过渡 | 翻开笔记、收件、提示词、核对、汇报、补件、定时检查 | 右侧深蓝，x=520–1190，白字、浅蓝或暖金。 |
| 中场休息 | 沙漏与笔记本 | 左上放页名，中央偏左放时长，右侧留给沙漏。 |
| 封底 | 完成清单与笔记本、回岗行动清单 | 左侧浅色，x=72–600，深蓝或次字色。 |

同一门课先为语义匹配的页预留图片，再给其余同页型页面分配通用图。每张 PNG 在整套课件里只出现一次。适配图片用完后，改用本包配色与可编辑形状铺底。非标准交接材料也按同一规则选图，先排完整课背景清单，再锁逐页资产。

将选中的 PNG 锁为包内 `background` 角色和 `brand_shell` 模式，并作为首层铺满 `1280×720`。按 `background_variant.text_area` 或上表安排前景文字。封面、封底大标题建议单行不超过 7 个全角字，章节单行不超过 9 个。更长的标题在同一留白区分行，并相应移动副标题。项目明确自定义背景时，记录原因和来源。

底图由内置 ImageGen 生成。原始提示词见[通用三张](生成提示词.md)和[财税篇九张](财税篇生成提示词.md)。

## VII. Placeholder Overrides

本包的 AI 专题页使用语义字段，例如 `LAYER_0N_*`、`INPUT_*`、`MODEL_*`、`OUTPUT_*`、`STEP_N/DETAIL_N`、`ROLE_TEXT`、`DEMO_0N_*`、`PRACTICE_*`、`CRITERION_0N/PASS_0N/REVISE_0N`、`TIME_N/ACTION_N/PROOF_N`。它们仅表示内容槽位，不要求逐字替换；Executor 按页面设计关系重写真实内容。单个卡片标题保持短句，较长示例放进练习画布或拆为连续页。
