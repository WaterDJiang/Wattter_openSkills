# 故事开发与写作

## 六项剧本判断

| 判断 | 写作时落实到哪里 | 回读时怎样发现问题 |
| --- | --- | --- |
| 具体目标 | 故事方案写主角此刻想办成的事、为什么现在行动，以及怎样看出事情办成了。涉及他人时写清他要向谁争取什么。 | “他想证明自己”还可以对应许多故事。放到这一场，他具体要让谁答应哪件事？ |
| 有分量的选择 | 给阻力一个具体来源。写人物原本能怎么做，选择眼下这条路将失去、冒险或放弃什么。代价可以小到一句话说出口便收不回来。 | 如果人物选另一条路，局面会有什么不同？若两种做法结果相同，回看阻力是否真的影响了决定。 |
| 事件因果 | 分场把“得到线索→如何理解→采取行动→造成后果”写通。分别追踪人物与观众看到、听到或已知的依据。 | 前一场的哪件事使这一场发生？角色推断正确、误会或故意隐瞒，观众各凭哪条线索理解他的行为？ |
| 人物声音 | 由关系和说话目的决定称呼、用词、句式、停顿和回避。让不同人物面对同一压力时各有应对。 | 遮住姓名，交换两人的关键台词试读。如果仍然合适，先改他们各自向对方争取什么，再改措辞。 |
| 可表演的情绪 | 把关键情绪落到触发它的事件和随后的动作、声音或停顿。“手已碰到门把，听见屋里叫他，又把手收回”给犹豫安排了表演。 | 演员知道何时开始反应、动作发生什么变化吗？观众能从现场见到或听到这一变化吗？ |
| 回应开头 | 故事方案写下开场引出的具体问题，结尾用选择、结果或关系变化回应。连载标出本集进展和下集悬念，完整短片交代核心问题的结果或情绪落点，独立单元让本次事件及后果可独立理解。 | 将开头与结尾连读。哪件事已有答案或实质推进？哪些疑问是作品有意保留的？ |

## 故事方案

一句话可用“一个处在不利处境的人，因为一个变化，必须完成具体目标，否则失去某物”。不利可以是处境而非身份；不强迫每部片都有金手指。

用一句话说清希望观众从哪件事看懂什么，再选一个能引出这个问题的开场。转折依靠物件时，先写它从哪里来、人物当时能否看见或够到。包袱落在旁人身上时，把反应分别系到他们各自收到的线索。例如父亲听到敲窗声先转头，奶奶顺着他的目光认出窗外的人，奶奶起身带响椅脚，女孩听见才从书上抬眼。若戏里众人本就同时听到警报，可以一起回头。

比较方向时看观众跟谁、冲突、爽点/情感点、继续看的信息缺口、适合连载或完整短片。已有方向就只发展该方向；候选都不成立时说明缺目标、代价还是持续冲突。

```text
根据【想法/受众】，先交故事方案，不直接写整部剧本。
写清主角为什么现在行动、要办成什么、谁或什么挡住他。他选哪种办法，要承担什么代价，这个选择怎样改变局面？写出开头引出的疑问，以及结尾回应它的事件。
判断适合连续短剧、完整短片还是独立单元，说明理由。
需要比较时给【数量】个有实质差异的方向；已有方向则沿用。
```

## 人物

按剧情需要写身份/年龄/职业、外部目标、隐藏需求、错误信念或局限、性格反差、关系如何变。只用有作用的缺陷，不给每个角色填无关履历。视觉识别点如旧外套、疤、习惯动作；自身左右与画面左右分开。避免套名，用户已命名不擅换。

```text
为【故事】写主要人物小传：身份与处境、外部目标、隐藏需求、缺陷/局限、性格反差、关键关系及变化。
加能被看见的稳定识别点，以及角色在关键关系里怎样请求、拒绝或回避。用本场的一句台词或一个动作体现差别。每项都说明怎样影响本故事。
```

## 连续短剧：总盘→分集→单集

改编或续写某一集时，可直接用下面的提示。结果放在本集大纲或剧本的开头和结尾。

```text
把【故事原文】改成一集【目标片长】的可拍剧本卡。续集承接【上集采用版结尾】，已有角色、关系及不可改原句见【定稿设定】。
开头用一句话写谁想办成什么、被什么拦住。接着按发生顺序写动作、原句和估算时长，让观众从一次选择或反应看出转折。
结尾写实际发生的变化，点明谁亲眼看见、谁只听见、谁仍不知情，留下下集要接的动作或疑问。保留原文尚未揭晓的事实。
将各段用时相加。若超时，指出可压缩的节拍及其影响；缺少决定因果的前提，标在对应节拍。
```

例如城门老卒听到粮车里传来一声咳嗽，压住车辕，暂缓放行。下集可接他掀帘查验。到这个时刻他只知道车里有动静，车内人的身份还没有揭开。若上集尚在剪辑，先用确认稿标注预定状态，待采用版回传再复核。

总盘含卖点、类型、核心人物与对手、持续冲突、关系变化、秘密/底牌、兑现方式、升级路径、结局方向及画幅适配。不能写到第十集才发现主线无力。

分集一行可写：`集号｜承接｜核心事件｜实际兑现｜新代价/升级｜结尾未完成项与类型`。不让同一冲突换名字循环。三至五集升级、八至十五集大转折仅是长连载参考，按总集数调整。

```text
为【故事、集数、单集时长】先整理故事总盘。
方向确认后写分集大纲，每集标承接、核心事件、已发生的兑现、新代价和卡点。
检查主角是否一直顺、对手是否一直蠢、悬念是否重复、本集是否只有预告没有推进。
```

首集可用“强处境/冲突→主角处境→冲突加压→转机信号→卡点”排节拍。90秒的3/27/40/15/5秒只是示例，不按比例硬套10秒或完整短片；世界观只给理解当前事件必需的部分。

```text
基于【故事】排【秒数】的首集节拍，先不扩写台词。
逐段写起止秒、可见事件、观众获得的信息、情绪变化；给动作与反应留时间。
使用适合本题材的开场、加压、转机与结尾，不把模板比例当硬标准。
```

开头可选冲突、疑问、危机、身份或反差；结尾可选危险未落、信息未全、反击起手、更大危机、身份逼近或两难选择。避免连续重复同一种卡点；每集仍要有进展。打脸题材检查压迫依据、硬证据/行动和旁观者态度变化；无围观场面不硬加群众。

## 完整短片：目标与情绪闭合

开发句式：困境中的人想完成简单目标；目标逼出秘密/欲望；他在有压力的规则下选择；表层得失改变了他与自己或他人的关系。

压力可来自时限、公开场合、不可逆选择、制度、关系或自身信念，不必须有恶人。给对手可理解的立场，配角各有具体作用。

七步：开场图像、目标确立、第一阻碍、中点反转、逼迫选择、高潮行动、余味图像。很短的片可合并，不为凑七场拆碎行动。

视听母题可为物件、空间、声音或动作，从细节到压力，再到结尾意义变化。潜台词让表面话题承载未说出的目标，用动作、停顿和物件分配权力，不让角色念主题。

```text
把【想法】开发为【片长】完整短片，先出总盘：
卖点、类型、主角外部目标/隐藏需求/错误信念、压力来源、戏剧规则、关键反转改变了什么。
用适合片长的七步结构组织，给视听母题和首尾呼应，说明结尾完成了什么。
总盘明确后拆分场，不能只留下一集钩子。
```

## 可拍剧本与台词

写喜剧或反转短片时，先试读四个节拍。观众起初以为会怎样？哪个动作或细节让这个预期更可信？什么新事实或一句话使先前的举动有了另一层意思？最后由谁的反应、停顿或选择把笑点落住？从已有情节里找依据，尤其留意包袱第一次揭开的时点。几个节拍可以在同一次对话或同一镜内完成。

```text
根据【总盘/大纲】写【片长/集号】剧本。
列出场角色；场头用“SC01 场景名 [内/外] [日/夜]”。
写每场前核对开场所知和场尾变化。人物在何处取得让他改变主意的线索？依据已在前文出现就直接写反应，需要新线索时让它在反应前进入剧情。只有观众获知秘密的场次，写清人物仍不知道什么。
动作以△开头，只写能被看见/听见的事件。
每句对白独立编号，标说话者、说/内心独白/画外音、语气与原句；音效单列。
按可表演时间排事件，标估算依据，不加摄影参数。
```

每句承担行动、关系或信息功能。连载可更直接，短片可用潜台词；都要能辨认人物处境，不能换谁说都一样。强情绪留梯度，删无用寒暄、空泛抒情及重复画面的解释。

```text
仅精修【指定台词】，动作、镜头与既定事实不变。
使每句有行动目的和关系姿态，减少同义重复，保持人物各自声音。
标出修改及理由；缺关键反应或证据时另列范围外建议，不直接改动作。
```
