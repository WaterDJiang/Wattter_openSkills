# 审校与交付

## 三轮审稿

只要求审稿就交问题；要求修订则在范围内另存新版，不覆写原稿。每项给场次/节拍、原句或事实、观众影响、具体改法、必须修/应修/可选。

| 轮次 | 检查 |
| --- | --- |
| 编剧 | 用[六项剧本判断](writing.md#六项剧本判断)回读。把主角的选择与代价、开场问题与结尾结果分别对读。遮住人物名试读关键对白，找出戏剧目的雷同或情绪缺少可表演动作的位置。 |
| 场记 | 对照反应之前人物和观众各自得到的线索，指出来源场次或节拍。再查出入场、时空、持物、服装、台词与反应时间。 |
| 制作 | 多人同步、手部接触、打斗、倒影、可读文字、水火等风险；给实现或简化建议，不直接删剧情 |

连载专项：慢热、兑现不足、剧情循环、万能兜底、无成本能力、对手降智、主角零代价、无跨集动力、标签拼接、网文腔、水词、过慢铺陈、卡点雷同。“闭环”只对缺乏连载动力提问，不能否定完整短片/独立单元。

短片专项：开场有无好奇、目标是否可见、是否有压力、反转是否改变理解、结尾是否完成情绪而非解释主题。不强制反转数量。

喜剧稿可先遮住结尾，指出观众此刻最可能相信什么，再读包袱和最后一个反应。若观众只能靠结尾的解释才理解笑点，回到前文找一处可以铺垫的动作或措辞。保留定稿台词，只审稿时将改法列为建议。

审到人物突然得出结论时，先回查前文。已有铺垫就引用原位置。全文确实缺依据时，指出断在哪两个节拍之间，优先利用场内已有物件、动作或一句原话修复。只拿到片段时，注明依赖哪条前情，将补写作为条件性建议。按本次授权保留定稿台词、事实和未揭示的秘密。

```text
对【剧本】按编剧、场记、制作三轮分别审查。
根据【连载/完整短片/独立单元】选专项，不混用结尾标准。
定位影响理解的场次，写出开场人物与观众各知道什么、场尾谁作了什么选择或观众理解怎样改变，并给出正文依据。将发现的问题归入对应轮次，按影响程度报告。
输出“位置｜证据/问题｜观众影响｜修改办法｜严重度”。
本次【只审不改/按指定范围另存修订稿】；未知信息列待确认，不补造事实。
```

## 交接可读性

`剧本.md` 头部给作品/集号、版本、草稿/待确认/已确认、目标时长、形态、硬约束和源材料。已确认需有会话或现有定稿依据，不能由自检推导。

正文按场次列行动与对白，每句原文保留标点。拍法由导演设计；给必要场景、道具尺度和人物识别点，不替导演锁无依据的镜头数量。

| 交接项目 | 内容 |
| --- | --- |
| 角色/场景/道具 | 稳定ID、名称、剧情必要特征与状态 |
| 节拍/对白 | ID、场次、说话者、声音类型、原句、可见行动 |
| 时间 | 目标、各场估算、对白与动作如何重叠、尚待实读项 |
| 版本/决定 | 定稿依据、不可改项、未决定项、修改影响 |

分别成文的故事/人物/剧本用相对链接关联。下一环节能凭正文接手，关键动机不能只留在聊天里。
